# Vidu Video

Shotloom 协议插件。协议操作与模型预设随插件一起安装，连接地址和 API Key 在厂商连接中配置。

A Shotloom protocol plugin. Operations and model presets are installed from this package. Configure endpoint and API key in a provider connection.

## Operations / 操作

- `generate` — 文生视频
- `animate` — 图生视频
- `generate-q3` — 文生视频
- `animate-q3` — 图生视频
