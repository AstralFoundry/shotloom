# 原生充值与 Web／APP 静默会话（2026-11-19）

APP 恢复安全存储凭据后立即打开首页，后台强制验证会话。网络失败不再被当作退出登录；401 和账号不匹配仍阻止操作。系统安全存储读取期间仅显示品牌图标。

Web 原有 30 秒内存缓存不能跨刷新复用，因此刷新仍会先显示登录校验。本轮在标签页 sessionStorage 仅保存用户 ID 提示，刷新时先展示工作台并静默验证。WebView 延用 APP 注入的账号提示，切换标签保留已有画布；所有接口继续通过 Cookie／原生凭据鉴权，账号绑定校验未放宽。401 清除提示，并在保留未保存工作台的前提下显示登录恢复。首次没有提示的访问仍需要鉴权，首次项目和资源初始化仍会显示“正在准备画布”。

充值页改为原生，保留金额范围、汇率读取和 HTTPS 支付链接校验。系统浏览器承载支付；连点只创建一次订单，可继续当前页面已创建的付款链接。返回 APP、切回前台、关闭浏览器或手动刷新时读取真实余额，不根据回调查询参数发放积分。

网关只支持应用级返回地址，不能由每次下单指定。本轮仅将 Shotloom 应用 5 的 waffo_pancake_return_url 从官网首页改为 https://shotloom.0xfiang.com/payment/return，其他应用设置未变。返回页提供 shotloom-preview://payment/return 和网页版账户两个固定入口，忽略外部 redirect 和伪造付款状态。
