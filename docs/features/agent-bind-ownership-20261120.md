# Agent 历史会话绑定修复

发布日期：2026-11-20。发布号：`20261120-agent-bind-de0c847`。

代码提交：`de0c847bed0ac7fb38124779f52d0317420e260f`，已推送至 `AstralFoundry/shotloom` 的 `supabase` 分支。

## 原因与修复

官方会话控制器可先于产品绑定恢复历史会话。产品随后独立恢复同一会话，重复申请持久化写入权，抛出 `SessionAlreadyOwnedError`，绑定接口返回 500。

绑定改为使用官方控制器的恢复入口，共享已有会话及进行中的恢复操作。所有具有可信产品绑定的恢复会话均装配产品规则与工具，避免重复注册，并继续刷新工具目录、Skill 和模型选择。

## 验证

- Harness 的 43 项测试在隔离 Linux 容器中通过；包括新增的顺序与并发冷恢复、工具与 Skill 刷新及跨项目绑定拒绝测试。
- Harness 编译及服务端类型检查通过。
- 使用候选镜像运行真实 Supabase HTTP 传输测试通过，覆盖身份隔离、绑定、归档、SSE 和退出后的连接失效。
- 切换后经公网验证登录态连接、SSE、首次绑定、重绑及并发重绑，接口均返回 200；测试账号及其数据库记录已删除。
- 未调用付费模型，未修改数据库结构。
