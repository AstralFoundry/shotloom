# 原生 APP 会话与画布启动优化（2026-11-18）

## 交付范围

最终 Android 0.9.10 / versionCode 11，包名 `com.shotloom.app.preview`，沿用现有签名，支持覆盖同签名 Preview。服务端发布 `20261118-session-preload-101`，包含 Web 启动链路和原生资源预热接口。

原生登录成功后在首页后台换取 Web 的 HttpOnly Cookie，并缓存当前版本画布启动所需的静态 JavaScript/CSS。同一 token 完成预热后直接进入项目 URL；预热超时或 Cookie 失效使用一次性交接回退。原生首页不等待预热完成；立即打开画布仍可能等待网络。客户端不持久化 Web 会话到 localStorage，不缓存一次性交接码。

Web 会话检查共享在途请求，成功结果最多在内存复用 30 秒，账号切换和失效时清除。强制验证绕过成功缓存，服务端每次请求仍验证会话和账号绑定。原生注入仅传 userId/语言显示提示，不能替代服务端鉴权。

内嵌画布就绪前只等待偏好设置、项目与资源引用初始化；模型、额度、技能、配方和项目库刷新退出首屏阻塞链。工作台与 AntdProvider 并行加载，预热只下载静态依赖，不执行画布。后台任务轮询使用任务中保存的模型契约及 Cookie 访问服务端 relay，无需等待新的模型目录。
