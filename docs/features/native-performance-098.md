# 原生客户端 0.9.8 延迟与登录修复

安卓版本为 0.9.8，versionCode 为 9；沿用原应用签名，可覆盖安装。

模型服务的 401 不再直接注销 Shotloom 会话。普通请求、模型中继和 Agent 事件连接统一通过 `/auth/me` 核实会话；并发失败共用检查，网络失败不会被认定为登录过期。同账号重新授权后，旧检查的回执不会再次使会话失效。服务端仍逐次校验受保护请求，账号切换仍阻止保存。

画布初始化仍要求成功读取账号偏好设置。余额或模型列表失败时，保留偏好与权限设置，记录并提示上游错误，让项目和画布继续加载；失败的模型列表不会保留旧的可用模型声明。模型调用仍需要有效授权。

通知、反馈和管理反馈的路由仅登记一份鉴权中间件，根路径和子路径均受保护。线上跟踪的九次支持接口请求均为三次 Supabase 请求，列表此前为五次；本轮没有改数据库结构或添加远程 KV。

原生读缓存继续按会话实例隔离，保留请求合并和一分钟有效期。写操作只失效相关接口，画布保存携带修改路径同步失效项目投影。失效前开始的读取不能重新填入缓存。退出登录清理全部投影。

页面切换复用已验证的用户资料，回到前台和手动刷新仍核实真实会话。已有缓存内容先展示、后台刷新；偏好设置在启动时后台加载，不再阻塞项目首页。

验证覆盖真实应用组件树、请求传输、Cookie 会话错误、缓存并发回执和服务端 HTTP/Postgres 边界。产品测试 902 项、原生测试 26 项、服务端离线测试 20 项通过；四项依赖独立环境的在线测试未运行。线上 API 复测和安卓模拟器证据保存在本地 `output/native-098/`，不把不同时刻的网络耗时差异视为稳定提速承诺。
