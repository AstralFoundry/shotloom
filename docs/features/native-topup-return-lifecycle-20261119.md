# 原生支付返回与页面生命周期修复（2026-11-19）

Android 0.9.13 / versionCode 14 修复充值页两个生命周期问题。

- 系统回收 APP 后通过支付链接冷启动，导航解析保留 Home → Topup，允许返回首页。
- 创建订单期间切换到其他页面，仍保存已创建的付款链接并解除忙碌状态；失焦时不自动打开浏览器。返回充值页后可继续同一订单，避免重复下单。
- 组件卸载后不更新页面或打开浏览器。余额仍以服务端查询为准，不根据返回链接声明付款成功。

验证：新增两个可复现原问题的回归用例，原生完整测试 39 项通过，TypeScript 检查通过。测试使用真实链接解析器和导航路由器，并让界面测试区分失焦与卸载。

发布包与线上下载入口在构建完成后补充。未进行真实付款或 Android／iOS 真机验收。
