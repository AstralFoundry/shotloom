# 剧本资产视频一条龙创作

改编自 Open AI Canvas 同名内置技能（原作者：娜乌斯嘉）。以用户提供的内容与授权为准，将创意推进为可生成、可核验的短片。用户可以指定要审阅的阶段、跳过生成或使用已有素材。若仅要求某个单项产物，按该范围工作。

用 `plan_write` 维护 Production Plan、依赖、顺序和真实 `runtimeRefs`。在画布中用 `canvas_list_nodes`、`canvas_get_node` 核对素材与结果。使用 `canvas_create_node`、`canvas_update_node` 和 `canvas_connect_nodes` 保存阶段产物、生成配置和真实输入边。说明影响下游的决定，在用户指定的审阅点暂停。关键设定缺失或有实质不同选择时，用 `ask_user_question` 集中提问。已经明确的设定和授权继续沿用。

## 使用完整原版

启动本技能后，先通过 `skill` 读取 [参考完整原文](references/upstream-skill.md)。七阶段流程、阶段审阅方式、剧本场次大纲模板、场次内精细切分模板和微片段运镜模板均在原文中。按用户选择的范围使用相应阶段与模板。

在 Shotloom 执行时，以本文件的工具与权限约定为准。原文的子技能启停、写文件、表单、Dreamina、模型 ID、素材 output ID 与积分机制属于参考项目。使用 Shotloom 的 `skill`、制作计划、画布节点、真实素材与任务回执；有模型、时长、并发或费用选择时以当前目录、用户授权与真实任务能力为准。用户要求按原流程逐阶段审阅时，保留相应确认点；已有明确授权时按约定范围持续推进。

## 1. 标准剧本

根据输入确定处理方式。完整剧本只整理结构，保留台词、动作结果、场序和结局。小说保留已有台词，将叙述转成可拍的景别与动作。大纲可扩写动作和对白，沿用核心剧情、人物关系及结局。用幕、场次、场地、内外景、时间和估计时长组织文本。场内用「画面」行写景别和动作，用「角色名」行保留对白和状态。记录稿件来源，并在继续设计前确定已有或明确约定的视觉风格。

## 2. 提取视觉资产

按人物、场景、关键道具分类，建立稳定资产标识。记录每项的出场场次、原文事实、连续性约束和生成提示词。复用符合要求的现有素材。人物和道具可用三视图与特征细节，场景可用全景、空间布局和关键机位，按下游所需决定。区分原文事实与新增设计，影响后续一致性的选择在计划里说明。

## 3. 制作设定图

为缺少可用参考图的资产创建图片生成节点。参考图要能辨认角色身份与服装、场景方位与出入口、道具形态与状态。保存真实结果与资产标识的对应关系。用户反馈需调整时只重做指定资产，并检查受影响的分镜。跳过生图时使用用户已有图，标明尚未解决的素材缺口。

## 4. 切分分镜片段

为每段记录场次、起止状态、原文对白、动作、需要的资产和与下一段的衔接。切分后逐段对照剧本核对对白、动作结果和关键叙事细节。连续短对话可以共用一段，较长台词在自然停顿处拆开。参考项目约 15 秒的片段设计可作起点，按对白可读性、动作节拍和所选模型的实际时长选项调整。

## 5. 运镜与参考图匹配

用编号微片段组织视频提示词，逐段写时长、空间、人物姿态与动作、景别、机位或运镜，随后写当前段原台词。保持轴线、视线、动作接点和角色身份连续。可用过肩、主观镜头、眼神特写或反应镜头表达有实际叙事作用的细节。画面文字、对白、环境声和音乐按项目规格写清。

列出每段匹配的真实参考图及其职责，例如身份、空间、道具或首尾帧。把可用参考图放回画布并通过真实输入边连接，核查模型所支持的 `inputMode`、`role` 和 `slot`。资产匹配仍有影响画面的歧义时先解决。缺少必需的参考图时，可完成计划、提示词和节点配置，待补齐素材后生成这些片段。

## 6. 视频生成

按用户已确定的画幅、时长和交付要求选择当前目录里支持对应参考图输入的模型。遵守运行权限、费用和任务限制。只用 `canvas_start_generation` 启动已具备条件的节点，用 `inspect_tasks` 核验真实终态。按依赖和工具支持安排批次，失败时按回执修复对应工作项。只做计划时交付已落地的配置和依赖。

## 7. 核验与交付

按故事顺序核对已完成片段、人物与资产一致性、对白和衔接。汇总剧本、资产设计、设定图、分镜、运镜提示词、参考图匹配表和真实视频结果。用户要求整片时，按已授权范围通过现有剪辑能力组装、检查并导出，依据真实文件回执报告完成。若只完成了素材、分镜视频或部分任务，明确标出交付到哪一步。
