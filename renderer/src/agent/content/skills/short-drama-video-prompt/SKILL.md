# 短剧视频提示词导演

这份 Skill 只回答两件事：视频 Prompt 怎么写，以及怎么落到 Shotloom 的真实模型能力和输入边上。模型、模式、时长、槽位和编号一律以 `inspect_model_catalog`、真实输入边和系统自动注入的 `@图片N` 清单为准，不凭记忆或平台习惯猜测。

Prompt 模板本身可以脱离 Shotloom 使用；涉及工具名、字段、输入槽位和编号的段落只适用于 Shotloom。换到别的平台时，保留模板结构，把 `@图片N` 和参数换成该平台真实存在的输入协议。

## Prompt 装配规则

按本镜风险选择帧驱动（短稿）、单段完整或段落驱动，不以字数、镜头数或风格词决定复杂度。共同骨架是：

1. **可理解的视觉钩子**：先确定本镜观众要立即看懂的主体、反差、动作升级或关系变化；产品/广告镜头才写产品特征。
2. **素材职责**：每个真实参考只负责一类事实，写清锁定项和不继承项；不把所有资产塞进每个节点。
3. **空间与固定块**：在连续镜头里固定位置、屏幕方向、光源、服装、道具持有人和摄影影调；同项目逐字复用固定块。
4. **可拍动作链**：起始状态 → 动作路径/地标 → 接触或受力 → 结果 → 反应延迟；复杂动作补充惯性、碰撞、材质和重心变化。
5. **镜头块与声音**：段落驱动每镜按时间码写机位/构图、动作表演、逐字台词、环境声/动作声/人物声和切点；帧驱动（短稿）按变化时间段写，单镜不写切点；单段完整可以只写一个完整镜头块。没有声音时明确“无 BGM”或“仅同期声”。
6. **段尾与风险控制**：写明最后的站位、朝向、焦点、道具、光线和动作进度；只列本镜最可能的身份、空间、媒介或物理漂移。

外部平台占位符、节点 ID 和“延续上一段”不是 Shotloom 的 Prompt 引用协议；Prompt 里必须写真实 `@图片N` / `@视频N` / `@音频N`，或改写为真实起始帧、视频边和显式承接状态。

## 什么时候加载

只要本轮要创建、配置、修改或重写视频生成节点，或把剧本、分镜、关键帧、参考素材转成视频 Prompt，就先加载本 Skill。`script-storyboard`、`script-to-video`、`video-production` 和普通画布 Agent 都应在写入视频节点前加载它。

本 Skill 只负责视频 Prompt 的内容组织与写法，不替代主流程的剧本事实、画布写入、模型选择和生成核验。人物身份板细节取自 `character-board`，场景/道具/分镜静帧的图片 Prompt 取自 `visual-prompt-craft`。

## 第一步：选帧驱动（短稿）、单段完整还是段落驱动

三种写法都成立。选择依据不是字数偏好，而是**一致性风险落在哪一层**：

| 路线 | 什么时候用 | 视频 Prompt 形态 | 参考与时长 |
| --- | --- | --- | --- |
| **帧驱动（一镜一帧 / 短稿）** | 已有干净起始帧；对白、反应、单人/双人、固定机位、局部动作；构图和身份由图片锁定 | 只写这一镜的**变化量**：保留构图 + 动作 + 镜头 + 台词 + 声音 + 结束状态 | 1 张主帧 + 必要参考（常见 1–4 张）；常见 4–8 秒 |
| **单段完整（一段一稿）** | 一个连续场景/叙事节拍，没有干净帧，但不需要在一条里交付多个切点；多人同框、复杂走位、完整对白 | 参考职责 + 基础设定/场景锁 + 一个镜头/一段的完整动作与台词 + 声音 + 段尾 + 排除 | 2–8 张参考；常见 6–18 秒、600–2800 字 |
| **段落驱动（一段多镜）** | 多个切点/叙事节拍必须一次交付；动作段、蒙太奇、一镜到底中的多阶段 | 参考职责 + 固定块 + 段落功能 + 场景锁 + 逐镜块 + 声音 + 承接 + 排除 | 3–7 张参考，复杂镜可更多；常见 10–30 秒 |

判断顺序：

1. 有干净起始帧、这一镜只是局部变化 → **帧驱动**。
2. 一个连续场景/节拍，但画面构建、身份、走位和表演必须靠文字 → **单段完整**。
3. 一条里要出现多个切点或多个叙事节拍 → **段落驱动**。

风险都高时先拆：一张干净起始帧 + 一个更短的单段 Prompt，或拆成两个视频节点。不要把所有信息压进一个节点。Prompt 长度是结果，不是目标；短不等于省事，长也不等于专业。

- 路线不绑定模型模式：模型支持时，帧驱动也可接多参考，单段完整也可用首帧；不要用模式反推路线。
- 多机位场景参考要标清每张图的机位方向（例如「A 是窗户机位拍门，B 是门机位拍窗」），否则模型会把它们混成一个空间。

## 写前五步（Shotloom 绑定）

1. **读模型目录**：调用 `inspect_model_catalog`，记录本镜真实可用的视频模型、`inputMode`、图片/视频/音频上限、时长档位、是否支持原生声音和多镜头。不得凭模型名猜能力。
2. **读画布现有资产**：用 `canvas_list_nodes` 的 `artifactType`（`character` / `scene` / `storyboard`）找可复用的角色板、场景板、关键帧；再用 `canvas_get_node` 核验具体画面和真实 ID。能复用就不要重复生成。
3. **确定路线与素材职责**：帧驱动先确认「一张干净起始帧」真实存在；单段完整先确认是一个连续场景/节拍，并列出 2–8 张真正需要的参考；段落驱动先列出本段出镜的人物、场景、道具和音色。不要把所有资产塞进每个节点。
4. **建节点、连真边**：用 `canvas_create_node` 建视频节点，写具体标题、真实 `model`、`outputSpec`（画幅/时长/分辨率/声音）和 `inputMode`。用 `canvas_connect_nodes` 或 `inputLinks` 连真实输入：普通参考图 `role=referenceImage`、`slot=reference`；首帧/尾帧只有在模型目录公开该模式时才写 `firstFrame`/`lastFrame`；音色参考写 `referenceAudio`。
5. **最后写 Prompt，并核对编号**：先有真实连线，再写 `@图片N` / `@视频N` / `@音频N`。编号来自本次请求实际编译出的媒体顺序（图片在前，再视频、音频），不是节点 ID，也不是随手排的。系统在有多个媒体输入时会自动前置素材清单，正文只写职责，不要再抄一遍清单。外部占位符（`{{Mixed 1}}`、`@人物`、`{{Image 1}}`）不会替 Shotloom 传图。

目标模型为 H3 时，先读 `references/h3-routing.md`，按它的字段和引用标签输出；本页的 `@图片N` 只用于说明真实输入顺序，不要直接当成 H3 正文格式。

## 段落驱动的装配顺序

按以下顺序写，缺哪块要能说清为什么本镜不需要：

1. **参考职责账本**：每个真实输入一行，写「锁什么 + 不继承什么」。
   ```text
   @图片1 = 角色A：锁脸型、年龄、发型、服装结构；不继承定妆图的正面站姿。
   @图片2 = 角色B：锁身份与右手道具；不继承参考图的背景。
   @图片3 = 场景：锁建筑结构、入口位置、光源方向；不继承场景里的人物。
   @音频1 = 角色A音色：只锁音色、语速和口音；不继承参考音频的台词内容。
   ```
   一个素材只承担一类事实。没有真实输入边的素材，不得写成模型已经看见。

2. **全局风格锚**：画幅、媒介、画风体系、色彩与光影、摄影机质感；结尾加一句「人物始终保持自然呼吸、眨眼、细微视线与重心变化」。没有要求时写「无背景音乐、无字幕」。这一段在同项目每个节点里原样复用。

3. **段落功能与秒数预算**：先声明这一镜要在多少秒内交付哪几条叙事事实。
   ```text
   段落功能
   在 18 秒内完成：
   1. 女主推门进来，发现会议已经结束。
   2. 男主站在窗边，没有回头。
   3. 女主把合同放到桌面，声音第一次发抖。
   ```
   秒数由镜头块的总时长反推，并写入 `outputSpec.duration`；不要用默认 5 秒装 18 秒的事实。

4. **场景锁与零时刻**：跨镜复用的场景不靠名字，按 `位置 / 空间 / 材质 / 灯光 / 背景 / 重力与物理 / 基调与限制` 七维重述。再写零时刻：谁在画面左/右、前/后景、朝哪看、离镜头多远、手里拿什么；没出场的人明确写「画面内没有 X」。同时声明六项一致：人物相对位置、场景方向、光源方向、道具位置、服装状态、动作进度。

5. **逐镜块**：每一镜写成一个可执行的小段。
   ```text
   镜头 03｜8.0–13.0 秒｜5 秒｜女主把合同放到桌面
   摄影/机位：中近景，35mm，平视，机位固定，保留极轻的呼吸抖动。
   构图：女主在画面左三分之一，长桌沿纵深占右侧留白，男主在右后方窗边虚焦。
   画面/动作/表演：女主从门口走到桌边，右手把合同放下；指尖在纸角停半拍；
     视线先落在合同上，再抬向男主的背影；喉结吞咽一次，呼吸变浅。
   台词：女主：“……已经结束了？”（气口在省略号处，尾音发虚，语速偏慢）
   声音：环境声=空调底噪与远处城市低频；动作声=高跟鞋、纸张；人物声=呼吸；无 BGM。
   光影：保持起始帧的冷灰侧光，不改变主光方向。
   切点/段尾：硬切；最后一帧停在女主手指压住合同、男主仍未回头的状态。
   ```
   镜头块数量由叙事节拍决定，不要为了「看起来完整」硬凑。

6. **收束与统一风格**：对白场景可以在末尾再放一块统一风格/一致性控制（影调、色彩、镜头语言、人物造型、空间连续、无字幕/BGM）。动作段则把收束写进每个镜头块的最后一行：站位、朝向、道具持有人、焦点、屏幕方向、光线。

7. **针对性排除项**：只列本镜最可能出错的事项。例如「不要让血迹提前出现在脸上」「不要让第三个人入画」「不要让参考图的格线/箭头进入成片」「不要改变道具持有人」。不要复制一串与本镜无关的负面词。

## 帧驱动（短稿）的装配顺序

帧驱动不是「只写一句话」，而是把构图、身份、光线交给图片，文字只负责运动和表演的增量：

1. **主帧职责**：
   ```text
   @图片1 = 本镜起始帧：锁构图、人物站位、光向、色调和服装状态；
   不继承画面上的任何标注、格线或文字。
   ```
2. **变化量**：用时间顺序写这一镜允许发生的变化，开头明确「保留 @图片1 的构图和光线，只发生以下变化」。不要重新描述整套场景。
3. **镜头**：固定机位、极轻呼吸抖动、推、拉、横移或跟拍；写方向、幅度和速度。没有位移时写「固定镜头，保持呼吸感，不卡死」。
4. **台词与声音**：逐字台词、说话者、停顿和尾音；没有对白就写「无对白，只保留环境声/动作声」。没有原生声音能力时写清「只生成口型与表演，声音后期处理」。
5. **结束状态与排除项**：最后一帧停在哪里、道具在谁手里、下一镜能接什么；只列本镜风险。

```text
@图片1 = 本镜起始帧：锁构图、人物站位、光向和服装；不继承任何标注。
保留 @图片1 的构图和光线，只发生以下变化：
- 0–2 秒：她保持坐姿，视线从桌面抬起，看向画面右侧的门口。
- 2–4 秒：右手把杯子推离桌沿，停半拍，呼吸变浅。
镜头：机位固定，保留极轻的呼吸抖动，35mm，浅景深，不切换景别。
声音：无对白；环境声=空调底噪；动作声=杯底摩擦桌面；无 BGM。
段尾：杯子停在桌沿内侧，她的视线仍朝向门口；画面内没有其他人。
禁止：换脸、换装、改变座位方向、增加第三个人、出现字幕或水印。
```

## 单段完整的装配顺序

一条节点只交付一个连续场景/叙事节拍。它比帧驱动多写空间和表演，比段落驱动少写切点。

1. **参考职责账本**：同段落驱动，每个真实输入写「锁什么 + 不继承什么」；多机位场景图标明视角方向。
2. **基础设定/场景锁**：人物、场景、道具、初始位置、光向；多人同框写每个人在画面左右/前后、朝向、持物和不可交换的标识（号码、服装颜色、发型）；画面内没有的人明确写出来。
3. **一个镜头/一段**：
   ```text
   镜头 01｜0–12 秒｜12 秒｜一句话事件
   摄影/机位：……
   构图：……
   画面/动作/表演：……
   台词：……
   声音：……
   光影：……
   段尾：……
   ```
   如果这一段内部有正反打或多机位，写清「在什么时刻切到谁」，但不要把它拆成多个叙事节拍；没有切点就写「一镜到底/连续镜头」。
4. **总时长**：开头写「所有镜头/阶段时长相加不超过 N 秒」，并让 `outputSpec.duration = N`；不要让模型自行增加人物、台词、动作、剧情或道具。
5. **针对性排除项**：只列本镜风险；多人同框加「不要多人或少人、不要人物分身、不要左右错位」。

模板见 `references/prompt-recipes.md` 的「单段完整」。

## 镜头块写什么

- **动作链**：零时刻站位 → 起势/重心 → 经过地标（门、桌角、台阶、屏幕、道路边线）→ 接触/交接 → 结果 → 反应延迟。写清从哪里到哪里、经过什么、在哪里停。
- **表演到生理层**：眼神、瞳孔、眉头、嘴唇、喉结吞咽、呼吸起伏、冷汗、尾音。不要用「复杂地」「有电影感地」「情绪到位」代替可拍事实。
- **台词**：逐字保留原词，标说话者和发生时间；写停顿、气口、语速和尾音。`OS`/`VO` 不自动产生画内口型；不要给画外音写「对口型」。非母语台词保留原文，必要时附发音；方言/口音写清楚（河南话、陕北方言、天津话、关西腔等）。台词与后期字幕分开：如果字幕后期加，明确写「不生成字幕」，不要把台词当成画面字幕要求。
- **主观视角/过肩镜**：写清是谁的视角、机位高度、画面内可见的身体局部，以及不出现视角主人的脸；不要两个视角来回跳。
- **多人同框**：先写每个人的左右/前后、朝向、持物和不可交换标识（号码、服装颜色、发型），再写动作；结尾写谁转身、遮挡、离场。排除人物分身、相同面容和左右错位；需要时写不要公众人物或明星脸。
- **唱段/音乐**：把歌曲切片作为 `@音频N`，写清口型逐字同步、不改歌词、不重复、不跳拍；镜头运动按阶段时间轴写。
- **声音分四类**：环境声、动作音效、人物声音、特殊声音。原生声音开启时也要在 Prompt 里规定内容，不要交给模型即兴。无 BGM 时明确写「不要音乐」。
- **画内文字**：屏幕、招牌、终端、手机要写字面内容，并声明不该出现的文字/字幕。没有要求时写「无字幕、无水印、无画面文字」。
- **物理与材质**：重量、惯性、碰撞、摩擦、碎片轨迹、布料湿度、皮肤纹理。写清材质和物理不是装饰，是验收条件。
- **不在画面里的人**：明确写「画面内没有 X」，否则模型会自行补人。

## 固定块复用：最稳的一致性手段

不要把每个节点都重新发明风格，维护一套**逐字复用的固定块**：

- 摄影影调固定块、美术色调固定块、角色形象固定块、皮肤/材质固定块、声音策略固定块、负面控制固定块；连载项目还可以有世界观/人物关系/基础设定固定块。
- 同一项目内原样复用，不意译、不缩写、不换同义词。每个视频节点都自带一次，不假设模型记得上一节点或别的节点写过什么。连载项目的基础设定只保留本镜需要的事实，不要把整集剧本复述进每个节点。
- 变量部分只有：参考职责账本、本段叙事事实、逐镜动作/台词。固定块负责「世界不变」，镜头块负责「这一镜变了什么」。
- 固定块越稳定，跨镜漂移越小。

改动固定块时，同步改同一项目的相关节点；不要只改一条，让相邻镜头漂移。

## 对白场景的写法

对白密集的短剧建议用「角色绑定 → 场景描述 → 逐镜对白 → 统一风格」四段式，一条 Prompt 覆盖一整场对话（常见 10–30 秒）。如果一场对话只有一个连续节拍、不需要多个切点，用「单段完整」更稳，不要为了套模板硬拆镜头。

1. **角色与音色绑定**：每个角色一行，列视觉参考和音色参考。
   ```text
   角色A参考：@图片1、@图片2；角色A音色参考：@音频1。
   角色B参考：@图片3；角色B音色参考：@音频2。
   ```
2. **场景描述**：地点、时间、天气、环境声、人物初始状态、气氛；顺手写清「不要未来城市感」「不要赛博朋克」这类场景级排除项。
3. **逐镜对白**：每一镜写「谁在画面什么位置 + 做什么 + 说什么」。对白场景不必每镜都堆焦段和构图术语；镜头稳定、人物关系清楚、台词能落到动作上更重要。
4. **统一风格控制**：影调、色彩、光线方向、摄影机稳定性、人物造型/服装/发型一致、空间位置一致、无字幕/BGM。

如果目标模型只支持较短时长，就在自然停顿处拆节点，不要为了塞下整场对白把语速和动作压到不可执行。

## 资产前移：身份与空间交给图片

角色一旦反复出镜，靠形容词保不住脸。把一致性前移到上游图片节点：

- **角色板**：正面/侧面/背面全身 + 头部正面/侧面特写；严格保留脸型、年龄感、发型、发色、服装结构、配饰；浅灰底、干净、无多余文字。四格/多格板的格线和标注不能接 `firstFrame`/`lastFrame`。
- **场景空镜**：完全无人，锁定建筑结构、入口、地标、纵深和光源方向；后续视频 Prompt 才有稳定的空间可继承。
- **道具**：提取主体，纯白背景，锁形状、材质、尺寸、磨损和持有人；不要让手或场景一起进入。
- **反打/换机位**：以既有场景图为基础，推理同一空间的另一侧；保持人物站位、队列、光向和空间关系，只换机位方向。
- **局部修改**：只改一项，其余保持原图不变。例如「让 @图片1 更暗一些，其余保持 @图片1 不发生变化」。
- **起始帧**：优先用上一镜成片里选定的一帧，或重建成一张干净关键帧；去掉标注、格线、箭头和无关人物。没有干净帧时，不要假称首帧模式。
- **板的选择**：单张干净关键帧足够时不做板；人物进出、长距离移动、转身、交接、追逐、多人错峰反应才做时间板；构图/视线/前后景/主观视角有独立风险才做镜头板；两板都有独立风险才同时做。板图只做 `reference`，不能接首尾帧。

写这些图片 Prompt 时，人物板细节交给 `character-board`，其余图片细节交给 `visual-prompt-craft`；本 Skill 只决定「哪些事实必须由图片承担，视频要保留什么」。

## 跨镜连续性

- **三层承接**：起始帧素材 + 空间/光向的显式声明 + 上一镜的段尾状态。缺一层，人物和构图就会被重置。
- 上一镜的最后一帧要写清：站位、朝向、道具持有人、焦点、屏幕方向、光线、动作进度；下一镜从这些事实继续，而不是只写「延续上一场」。
- 每个节点重复固定块、场景锁和身份参考；模型不会自动记住上一个节点。
- 只做局部变化时明确写「以当前起始帧为基础，只改变景别/焦点，不重新构图」「镜头直接切到脸部近景特写」。
- 续写或视频延长只有在模型目录确实支持 `inputVideo`/视频续写时才做；否则从上一镜抽一帧重建起始帧，再生成下一段。不要把「继续上一段」当成真实输入。
- 越轴、反打、人物换位要显式声明屏幕方向；不要让模型自行决定左右。

## 时长、画幅、参考数量与声音

- **时长**：由段落功能反推，不取默认值。帧驱动常见 4–8 秒，单段完整常见 6–18 秒，段落驱动常见 10–30 秒。模型只提供离散档位时，选最接近的档位并调整镜头数量或动作密度。
- **画幅**：16:9 是默认；史诗/大场面可用 21:9；年代戏、漫剧、复古题材可用 4:3。写进 `outputSpec.aspectRatio`，不要只写在 Prompt 里。
- **分辨率**：工作分辨率常用 720p/1080p，正片再走补帧/超分；不要把「4K」当成 Prompt 里的风格词代替真实参数。
- **声音**：有对白或关键音效时优先开启原生声音，并在 Prompt 里规定声音内容；模型不支持时明确写「只生成口型与表演，声音后期」。
- **参考数量**：帧驱动 1 张主帧 + 必要参考（常见 1–4 张）；单段完整常见 2–8 张；段落驱动常见 3–7 张，复杂镜更多。不要把整集所有人物和场景塞进每个节点；被模型上限截断时，优先保留最容易漂移的身份、场景和关键道具，并把被省略的事实写回 Prompt。
- **多镜头**：段落驱动且模型支持时开启 `multiShot`；帧驱动保持单镜；单段完整不默认开启，只有这一段内部确实有切点且模型把多机位作为同一次生成处理时再开。

## 质量门槛

**P0 不可生成**：Prompt 声称模型看到了某张图但没有真实输入边；残留外部平台占位符；没有主体或可执行动作；使用了模型目录不存在的模式/槽位；时长塞不下叙事事实。

**P1 必须重写**：`@图片N` 与真实编译顺序不一致；正向要求和禁止项互相冲突；时间轴没有覆盖到目标时长；把多个独立切点压成一个镜头；有对白但没有说话人/发生时间；给 `OS`/`VO` 写对口型；没有段尾状态和下一镜可承接信息；多人同框没有排除人物分身、相同面容或左右错位。

**P2 需要补齐**：缺少景别/机位/主体位置；用情绪形容词代替生理层表演；没有声音分类；没有排除无关人物；固定块与其他节点不一致。

写完后读回节点的 Prompt、模型、模式、时长和真实输入边；生成后用 `inspect_tasks` 等真实回执核验，不用「已提交」冒充「已生成」。镜头身份、台词、空间、道具或文字漂移时，先改 Prompt 或换参考，不要用复制节点掩盖问题。

## 交付检查清单

- [ ] 已读模型目录，模型/模式/槽位/时长/声音能力都是真实可用的。
- [ ] 已选路线：帧驱动（短稿）、单段完整还是段落驱动，理由是本镜的一致性风险。
- [ ] 视频节点的真实输入边与 Prompt 中的 `@图片N` 数量、顺序、职责一致。
- [ ] 段落驱动包含：参考账本、固定块、段落功能、场景锁、逐镜块、声音、段尾承接、针对性排除。
- [ ] 单段完整包含：参考账本、基础设定/场景锁、一个镜头/一段的完整动作与台词、总时长、段尾、针对性排除。
- [ ] 帧驱动（短稿）包含：主帧职责、变化量、镜头、台词/声音、段尾状态、针对性排除。
- [ ] 时长 = 镜头/阶段/一段的秒数之和；画幅/分辨率/声音写入 `outputSpec`，不是只写在文字里。
- [ ] 没有外部占位符、没有伪造输入、没有把未生成的媒体说成已完成。
- [ ] 高风险镜头先做代表镜核验，再批量；失败时修原节点，不复制掩盖。
