# 视频提示词装配规则

按镜头风险选择帧驱动（短稿）、单段完整或段落驱动，不以字数、镜头数或风格词决定复杂度。提示词必须把可见事实、拍摄方法和输入职责写在同一份可执行文本中。

## 可迁移写法

### 帧驱动（短稿）：单动作或起始帧

```text
@图片1 = 本镜起始帧：锁构图、人物站位、光向和服装；不继承标注和文字。
保留起始帧，只发生以下变化：0–2 秒……；2–4 秒……。
镜头：机位/景别/运动/速度；表演：眼神、呼吸、手部或重心变化。
声音：环境声……；动作声……；人物声……；无 BGM/仅同期声。
段尾：站位、朝向、道具持有人和焦点；下一镜从此状态开始。
禁止：本镜最可能发生的 1–3 个漂移。
```

### 单段完整：一个连续场景/节拍

```text
【素材职责】每个真实输入只锁一类事实，并写明不继承什么。
【基础设定/场景锁】人物、场景、道具、初始位置、光向；多人同框写不可交换标识。
【镜头 01｜0–N 秒｜N 秒｜一句话事件】
机位/构图；起始状态→动作路径→接触/受力→结果→反应；台词；声音；段尾。
【总时长】所有镜头/阶段时长相加不超过 N 秒；不自行添加人物、台词、动作、剧情或道具。
【针对性排除】只写本段最可能的身份、空间、媒介或物理漂移。
```

### 段落驱动：多镜段落

```text
【素材职责】每个真实输入只锁一类事实，并写明不继承什么。
【场景锁】位置、空间、材质、灯光、背景、物理、基调与限制。
【固定块】角色外观/服装/道具、摄影影调、声音策略；同项目逐字复用。
【段落功能】在 N 秒内必须完成的 1–3 个叙事事实。
【镜头 S01｜0–a 秒】机位/构图；起始状态→动作路径→接触/受力→结果→反应；台词；声音；切点。
【镜头 S02｜a–b 秒】承接上一镜的状态，只写发生的变化。
【段尾】站位、屏幕方向、道具、焦点、光线和动作进度。
【针对性排除】只写本段最可能的身份、空间、媒介或物理漂移。
```

## 在 Shotloom 中的边界

- 先用 `inspect_model_catalog` 决定输入模式、参考数量、时长、画幅和原生声音；再决定帧驱动（短稿）、单段完整或段落驱动。不要把外部平台占位符或外部节点 ID 写入 Prompt。
- 真实边建立后，按系统注入的 `@图片N` / `@视频N` / `@音频N` 编写素材职责；没有真实边就删掉该引用。
- Prompt 中写的总时长必须与 `outputSpec.duration` 和镜头时间码一致。模型档位不够时拆节点或减少事件，不压缩到不可执行的语速。
- 角色板、场景板、时间板和镜头板只做 `reference`；干净单帧才可做 `firstFrame`/`lastFrame`。外部项目中的“延续上一段”必须改成真实帧、视频边或显式状态。
- 生成前后都核对身份、站位/轴线、道具持有人、台词口型、字幕/文字、声音和段尾；失败时修改原节点，不复制节点掩盖问题。
