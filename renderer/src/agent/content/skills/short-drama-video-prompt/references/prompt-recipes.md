# 视频提示词可复制模板

模板里的方括号是待填内容；`@图片N` / `@视频N` / `@音频N` 必须来自 Shotloom 本次请求真实编译出的媒体顺序。先用 `inspect_model_catalog` 确认模型支持的模式、时长和声音能力，再用对应模板。不要把模板当填空游戏：每一项都要能对应到本镜真实需要的事实。

## 1. 帧驱动（短稿）：单镜变化

**适用**：已有干净起始帧；单人/双人、对白、反应、局部动作、固定或轻微移动机位。

```text
@图片1 = 本镜起始帧：锁构图、人物站位、光向、色调和服装状态；不继承画面上的标注、格线或文字。
[可选：@图片2 = 角色A身份，锁脸型/发型/服装，不继承定妆站姿。]

保留 @图片1 的构图和光线，只发生以下变化：
0–[a] 秒：[主体从什么状态开始，触发什么，动作路径经过什么地标，停在哪里]。
[a]–[结束] 秒：[接续动作、反应、道具或视线变化]。

镜头：[固定/手持/推/拉/横移/跟拍]，[方向、幅度、速度]；[景别或焦段，仅在必要时写]；不切换景别。
表演：[眼神、眉头、嘴唇、吞咽、呼吸、手指/重心等可见细节]。
台词：[角色A：“原词”]（[停顿、气口、语速、尾音]）；[没有对白就写“无对白”]。
声音：环境声=[…]；动作声=[…]；人物声=[…]；[无 BGM]。
段尾：[人物站位/朝向/道具持有人/焦点/屏幕方向]，下一镜可承接[动作或道具状态]。
禁止：[本镜最可能出现的 1–3 个漂移，例如换脸、换装、增加第三人、改变座位方向、出现字幕]。
```

**示例（4 秒反应镜）**：

```text
@图片1 = 本镜起始帧：锁构图、人物站位、光向和服装；不继承任何标注。
保留 @图片1 的构图和光线，只发生以下变化：
0–2 秒：她保持坐姿，视线从桌面抬起，看向画面右侧的门口；呼吸变浅。
2–4 秒：右手把杯子推离桌沿，指尖在杯沿停半拍；嘴唇轻抿后松开。
镜头：机位固定，保留极轻的呼吸抖动，35mm，浅景深，不切换景别。
表演：瞳孔先向右移，随后头才转；眉头轻收，喉结吞咽一次。
台词：无对白。
声音：环境声=空调底噪；动作声=杯底摩擦桌面；人物声=一次吸气；无 BGM。
段尾：杯子停在桌沿内侧，她仍看向门口；画面内没有其他人。
禁止：换脸、换装、改变座位方向、增加第三个人、出现字幕或水印。
```

**常见失败**：重新描述整套场景，和起始帧打架；写「自然移动」却没有起点/路径/终点；没有段尾状态；把多镜切点塞进单镜。

**固定机位多人分时入画**：按时间顺序写谁在何时进入、停留、离开，不要写切镜；如果天气/光线随时间变化，也写清变化方向（例如「天空从黑夜过渡到白天」）。

## 2. 帧驱动（短稿）：对白/反应镜

**适用**：双人对白、一人说话一人听、主观视角或过肩镜。构图和身份由帧/角色板锁定，视频只演这一句。

```text
@图片1 = 本镜起始帧：锁两人站位、景别、光向；不继承标注。
@图片2 = 角色A身份；@图片3 = 角色B身份；@音频1 = 角色A音色；@音频2 = 角色B音色。
保留构图和光线，只发生以下变化：
[角色A]在[位置]开口说话，[头/肩/手的小动作]；[角色B]保持[姿态]，在台词[某处]才出现[眼神/眉头/呼吸]反应。
台词：[角色A：“原词”]（[停顿/尾音/语速]）。[角色B 无台词，不安排口型。]
镜头：[固定/极轻推]，[轴线不越]；焦点从[角色A]保持或轻微转到[角色B]。
声音：环境声=[…]；动作声=[…]；人物声=[角色A 的声音质感]；无 BGM。
段尾：两人仍保持[站位/朝向]；[角色B]的[视线/手部]停在[状态]，可接下一句。
禁止：两人同时说话、听者抢口型、换脸、换装、改变站位、出现画外第三人。
```

**规则**：
- 一句台词一个说话人；听者写可见反应，不写台词。
- 口型只给真正说话的人；`OS`/`VO` 不写口型。
- 台词过长、动作塞不下时拆镜，不要加速到口型不可读。

## 3. 单段完整：一段一稿

**适用**：一个连续场景/叙事节拍；没有干净起始帧，但不需要在一条里交付多个切点。多人同框、复杂走位、完整对白、单镜动作都常用。常见 2–8 张参考、600–2800 字、6–18 秒。

### A. 单镜/连续段

```text
【基础设定】
[只写本镜需要的故事/场景上下文，不复述整集]
人物：[角色A] @图片1：外观、服装、身份；[角色B] @图片2：外观、服装、身份。
场景：@图片3，锁建筑结构、入口、地标、光向；多机位场景图标清每张的视角方向。
道具：@图片4，锁形状、材质、尺寸、当前持有人。

【强制声明】
总时长不超过 [N] 秒；所有镜头/阶段时长相加不超过 [N] 秒。
严格按本段执行，不自行添加人物、台词、动作、剧情或道具。
[声音策略：仅同期声 / 无 BGM / 无字幕 / 方言或口音]

【氛围与画质】
[画幅、媒介、影调、色彩、光线、摄影机质感、材质与物理]

【镜头 01｜0–[N] 秒｜[N] 秒｜一句话事件】
机位/景别：[景别、机位、焦段、运镜、速度]。
构图：[主体位置、留白、前后景、焦点]。
画面/动作/表演：[起始状态 → 动作路径经过的地标 → 接触/受力 → 结果 → 反应延迟；生理层细节]。
台词：[角色：“原词”]（停顿、气口、语速、尾音、口音）。
同期声：[环境声/动作声/人物声/特殊声音]。
光影：[主光方向、色温、保持或变化]。
连续性提醒：[进入顺序、站位、道具持有人、不可交换标识]。
段尾：[站位、朝向、焦点、屏幕方向、下一镜可承接状态]。

负面提示词：[本镜最可能出现的 1–5 个漂移，例如多人/少人、人物分身、左右错位、换脸、换装、字幕]。
```

### B. 紧凑对白段

```text
【相机与色彩】
[摄影机、镜头、光圈、光源方向、色彩与胶片质感]。
不得出现字幕/文字叠加；[不要 BGM/仅保留同期声]；[全片台词使用 XX 方言]。

镜头1：[0–N 秒]，[手持/固定 + 景别组合]，[角色A] 说：“[原词]”[同时的动作/表情]；
[角色B] [动作/反应] 说：“[原词]”；
[角色A] [接续动作]；
……
段尾：[人物关系最终状态、谁停在哪里、什么动作结束]。
负面：[换脸、换装、多人、少人、加戏、字幕]。
```

**注意**：这种写法可以在一段里用正反打和多机位，但仍是一个叙事节拍；不要把它扩成多个场景。

### C. 唱段/音乐驱动

```text
【素材职责】
@音频1 = 本段歌曲切片：口型逐字同步，不自行配音、不改歌词、不重复、不跳拍。
@图片1 = 人物：只采用外貌、发型、服装和年龄感，不采用背景。
@图片2 = 场景：采用空间、舞台、灯光和观众席布局。
@图片3 = 道具：只采用外形与材质，不采用背景。
@图片4、@图片5 = 观众群像：只采用穿着和人群构成。

【主体设定】
[人物在舞台/场景中的位置、动作、与观众的关系]。
【镜头总则】
[一镜到底/不切镜/不转场/不换机位]；[摇臂/轨道/手持]运动方式与速度。
【阶段一 0–[a] 秒】[镜头起点、运动、人物动作与歌词段落]。
【阶段二 [a]–[b] 秒】[接续运动、人物动作与歌词段落]。
【阶段三 [b]–[N] 秒】[收束运动、结束姿态]。
【声音】全程只用 @音频1；[观众不出声/环境声策略]。
【保持一致】[脸、发型、服装、道具位置、舞台方向、观众构成]。
【负面】[第二个人上台、观众张嘴、换装、字幕、额外音乐]。
```

## 4. 段落驱动：对白场景（多镜）

**适用**：一条视频节点覆盖一整场对话（常见 10–30 秒，5–15 镜）；场景简单、人物关系和对白是核心。

```text
角色设定：
角色A参考：@图片1、@图片2；角色A音色参考：@音频1。
角色B参考：@图片3；角色B音色参考：@音频2。

# 场景描述
[地点、时间、天气、环境声、人物初始状态、气氛]。
[人物A 在什么位置、正在做什么；人物B 在什么位置、正在做什么]。
[本场需要避免的类型偏差，例如“不要未来城市感”“不要赛博朋克”“不要过度繁华”]。

---

## 镜头1｜[景别/视角/关系]
[谁在画面什么位置，镜头怎么拍，人物做什么，说什么。]
对白情境：
[角色A]：“[原词]”

---

## 镜头2｜[景别/视角/关系]
[接上一镜的空间关系；动作变化；听者反应。]
对白情境：
[角色B]：“[原词]”

---

## 镜头[N]｜[收束镜]
[人物关系最终状态；谁停在哪里；什么动作结束。]
对白情境：
[角色A]：“[原词]”

---

# 统一风格控制
[影调、色彩、光线方向、摄影机稳定性、人物造型/服装/发型一致、空间位置/太阳方向/时间连续]。
无字幕，无水印，无画面文字，无背景音乐。
```

**写作要点**：
- 角色绑定放在最前，视觉参考和音色参考分开；一个角色一行。
- 场景描述一次写清，后面镜头不再重复大段环境；只写这一镜的变化。
- 每镜的「谁 + 在哪 + 做什么 + 说什么」必须完整；对白场景不需要每镜都堆焦段术语。
- 结尾统一风格块负责「世界不变」；镜头块负责「这一镜变了什么」。
- 镜头数由对话节拍决定；目标模型时长不够时，在自然停顿处拆节点。
- 开头写「总时长不超过 N 秒；所有镜头时长相加不超过 N 秒」，并写「严格按分镜执行，不自行添加人物、台词、动作、剧情或道具」。

## 5. 段落驱动：动作/灾难段（时间码）

**适用**：多人走位、追逐、打斗、灾难、一镜到底；需要精确的时间和空间关系。

```text
[固定风格块：画幅/媒介/胶片质感/色彩光影/摄影机体系]。
[固定角色块：每个角色的外观、服装、状态]。
无背景音乐，无字幕。

场景美术锁定
位置：[场景在空间中的位置、地标、入口/出口]。
空间：[主体之间的相对位置、纵深、前景/中景/远景]。
材质：[服装、道具、建筑、植被、特效材质]。
灯光：[主光方向、色温、空气介质、阴影]。
背景：[远景、天气、环境细节]。
重力/物理：[重量、惯性、碰撞、碎片、液体、烟雾的运动逻辑]。
基调/限制：[写实质感、避免廉价 CG、血腥尺度、无 BGM/字幕]。

段落功能
在 [N] 秒内完成：
1. [叙事事实1]
2. [叙事事实2]
3. [叙事事实3]

镜头 S01｜0–[a] 秒｜[a] 秒｜[一句话事件]
摄影/机位：[景别、机位、焦段、运镜、速度]。
构图：[主体位置、留白方向、前后景、焦点]。
画面/动作/表演：[起始状态 → 动作路径经过的地标 → 接触/受力 → 结果 → 反应延迟]。
台词：[角色：“原词”]（[停顿/尾音]）；[无对白]。
声音：[环境声/动作音效/人物声音/特殊声音]。
切点：[切到哪里；下一镜从什么状态开始]。

镜头 S02｜[a]–[b] 秒｜[b-a] 秒｜[一句话事件]
[同上]

……

镜头 S0N｜[x]–[N] 秒｜[N-x] 秒｜[收束事件]
[同上]
段尾：[站位、朝向、道具持有人、焦点、屏幕方向、光线、动作进度]。
```

**规则**：
- 时间码必须连续覆盖 0 到目标时长；最后一镜的结束时间 = `outputSpec.duration`。
- 每个镜头只承担一个主要事件；切镜必须带来新的主体、空间、状态、视点或时间信息。
- 动作链写「起点 → 经过 → 接触/受力 → 结果」；不要用「激烈打斗」「混乱」代替。
- 多人同框先写每个人的左右/前后、朝向、持物和不可交换标识（号码、服装颜色、发型）；结尾写谁转身、遮挡、离场。
- 镜头运动必须能拍到动作；如果角色从画面左侧跑出，下一镜的屏幕方向要接得上。
- 物理写清来源和结果：碎片从哪来、烟尘怎么扩散、水花落在哪、人物受击后重心怎么变。

## 6. 固定块 + CUT 增量

**适用**：同一场景、同一画风连续生成很多镜头；需要把「世界设定」和「这一镜」彻底分开。

**固定块（每个节点原样复用）**：

```text
参考图统一绑定与空间位置锁定
@图片1｜场景：锁定建筑结构、入口、地标、纵深、光源方向。
@图片2｜角色A：严格锁定面部、发型、服装、年龄、体型；只锁身份，不继承定妆姿势。
@图片3｜角色B：严格锁定面部、发型、服装、年龄、体型。
@音频1｜角色A音色：只锁音色、语速、口音。

摄影影调固定提示词
[画幅、媒介、镜头体系、胶片/数码质感、色彩、曝光、对比、黑位、噪点、镜头语言]。

美术色调固定提示词
[场景类型、时代、材质、主色/辅色、饱和度、环境元素、禁止的现代元素]。

皮肤/材质固定提示词
[真实皮肤细节、毛孔、纹理、湿润/灰尘状态，禁止磨皮、塑料感、蜡像感]。

声音固定要求
[只保留对白与音效；不生成旁白；不生成 BGM；不生成歌词；不生成字幕]。

负面控制
[本项目的固定禁止项：现代元素、仙侠滤镜、游戏 CG 感、表情过火等]。
```

**变量块（每个节点只写这一镜）**：

```text
CUT [编号]｜[一句话事件]
时长：[N]s
景别：[…]
角度：[…]
运动：[…]
焦段：[…]

位置锁定：
- [镜头在哪里，朝什么方向]。
- [前景/中景/背景各是什么]。
- [人物站在画面的什么位置]。

画面：
[动作、表演、对白、视线、道具、接触关系]。

表演/台词：
[角色：“原词”]（[停顿/尾音/语速]）。

声音：
[环境声/动作声/人物声/特殊声音]。

切点：
[这一镜怎么结束，下一镜接什么]。
```

**规则**：
- 固定块逐字复用，不意译、不缩写；变量块只写这一镜的差异。
- 固定块改动时批量更新同项目相关节点，避免相邻镜头漂移。
- 固定块不是越长越好；只保留真正跨镜不变的影调、角色、材质、声音和禁止项。

## 7. 续写与衔接

**模型支持视频续写/输入视频时**：

```text
@视频1 = 上一段成片，继承最后一帧的人物站位、朝向、道具、焦点、光线和声音状态。
从[接续动作]开始，经过[动作路径]，停在[新的结束状态]。
镜头继续以[方向/速度/焦点]运动，不重新生成人物，不改变屏幕方向。
环境声/对白从上一段自然延续；结尾保留[下一段需要的动作或声音]。
禁止：重新构图、换脸、换装、重置机位、突然改变光线。
```

**模型不支持视频续写时**：

```text
@图片1 = 从上一镜成片选定的最后一帧，已清理标注；锁人物站位、构图、光向和服装。
保留 @图片1 的构图和光线，只发生以下变化：
[从上一镜最后一刻继续的动作]。
镜头：[继续原来的运动方向/速度]；不重新建立场景。
段尾：[新的站位/道具/视线状态]。
```

不要把「继续上一段」「沿用上一场」当成真实输入；没有起始帧或视频边，模型会重新生成。

## 8. 资产图：视频需要图片承担什么

写资产 Prompt 时，先问「这张图要在后续视频里承担哪一类事实」。人物板、场景、道具、反打、关键帧的完整写法分别由 `character-board` 和 `visual-prompt-craft` 负责，这里只列视频侧的最低要求。

### 角色板

```text
以 @图片1 为角色参考，生成[角色]的角色设定板：
左侧全身三视图（正面/侧面/背面），右侧头部三视图（正面/3/4 侧面/侧面）。
严格保留脸型、年龄感、发型、发色、服装结构、腰带、鞋子、配饰和体型。
浅灰底，干净、克制，不出现表情演绎、场景、武器或多余文字。
```

视频用法：作为 `reference` 提供身份；**不能**把多格板直接接 `firstFrame`/`lastFrame`。

### 场景空镜

```text
[地点]完全无人空间，没有人物也没有工作人员。[纵深构图]；
[建筑结构、入口、地标、光源方向和色温]；[时间/天气/空气介质]。
不要[与本项目冲突的风格词]。
```

视频用法：作为 `reference` 锁空间结构与光向；不继承场景里可能出现的人物。

### 道具

```text
提取[主体物]，纯白色背景；锁形状、材质、尺寸、磨损和使用痕迹；
影棚柔光，无人物，无手，无场景，无 CG 塑料感。
```

视频用法：作为 `reference` 锁道具形状与材质；在视频 Prompt 里写清当前持有人。

### 反打/换机位

```text
以 @图片1 为基础，推理同一空间的另一侧机位：
保持人物站位、队列、光向、建筑结构和空间关系不变，只改变机位方向；
[新机位的位置、景别、朝向]；不增加原图没有的人物或家具。
```

视频用法：作为 `reference` 提供新构图；视频 Prompt 继续沿用原场景的光向和地标。

### 局部修改

```text
以 @图片1 为基础，只修改[一项]：[目标变化]；
其余保持 @图片1 不发生变化，包括构图、人物、光线、材质和空间关系。
```

视频用法：修改后的图作为 `reference` 或干净起始帧；视频 Prompt 写「保留构图，只发生以下变化」。

### 起始帧/关键帧清理

```text
以 @视频1 第 [t] 秒的画面为基础，清理[无关元素/标注/字幕]，只修正[目标]；
不重新构图、不改变人物身份、服装和光向；输出干净的单帧画面。
```

视频用法：作为 `firstFrame`（模型支持时）或 `reference`；必须是干净单帧，不能带格线、箭头、编号或文字。

## 9. 参考视频/动作/节奏复刻

**适用**：舞蹈、打斗、运动、运镜、剪辑节奏复刻；模型目录支持 `inputVideo` 时使用。

```text
@视频1 = 动作/节奏参考：只继承动作顺序、节拍、身体重心、镜头运动和剪辑点；
不继承原视频的人物身份、服装、场景、光线和台词。
@图片1 = 替换人物：锁脸型、发型、服装、体型；@图片2 = 替换场景：锁空间、地标、光向。

按 @视频1 的节拍复刻：
0–[a] 秒：[动作段1，身体部位、重心、方向、结果]；
[a]–[b] 秒：[动作段2]；
[b]–[结束] 秒：[收束动作与结束姿态]。
镜头：[跟随/固定/环绕]，[方向、幅度、速度]与 @视频1 一致；不越轴。
剪辑：只复刻[剪辑点/最后一镜不断镜推进+拉焦/卡点]，不复制原视频的身份和场景。
声音：[只保留动作音效/环境声；不要复制原视频音乐/台词]。
禁止：把原视频人物/服装/场景带入、改变节拍、增加原视频没有的动作、出现字幕。
```

没有视频输入能力时，不要声称「复刻参考视频」；把参考视频拆成关键帧和动作描述，按帧驱动、单段完整或段落驱动重写。

## 10. 最简检查

1. 这句 Prompt 是在描述「这一镜变了什么」，还是在重复图片已经给出的信息？
2. 每个 `@图片N` 都有真实输入边、单一职责和明确的「不继承」吗？多机位场景图标清视角方向了吗？
3. 时间段覆盖到目标时长了吗？最后一镜的结束时间等于 `outputSpec.duration` 吗？有没有写「所有镜头时长相加不超过 N 秒」？
4. 每个动作都有起点、路径、结果和反应延迟吗？多人同框的站位、持物和不可交换标识写清了吗？
5. 台词有说话人、原词、停顿和尾音吗？画外音被误写口型了吗？方言/口音和字幕策略写清了吗？
6. 段尾状态能让下一镜直接接上吗？
7. 单段完整是否只交付一个叙事节拍，而不是把多个切点塞进一段？段落驱动是否每个镜头只承担一个主要事件？
8. 排除项只针对本镜风险，还是复制了一串无关负面词？是否写了「不自行添加人物、台词、动作、剧情或道具」？
