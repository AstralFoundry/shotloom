# 场景参考

为实际拍摄方向建立空间参考，当某个位置将在多个镜头中重复出现或用户请求设置表时。重复使用足够的现有参考；当不需要单独的设置表时，直接在其拍摄提示中描述一次性过渡。

- 默认为 16:9 风景参考图像，除非用户另有说明。参考宽高比与最终输出无关；保持提示和生成参数对齐。
- 建立空间结构、入口、地标、固定家具和关键道具及其关系，以及尺寸、材料、时间和光照位置。将方向锚定在特定固定物体上。将可见事实与仍需设计的区域区分开来；一个看不见的后部区域不是已建立的布局。
- 覆盖拍摄所需的视角。当只有镜头尺寸在同一方向变化时，一个宽视角通常就足够了。对于反向角度、侧视角或揭示其他方向的运动，只需添加所需的未覆盖视角。一张 2×2 的纸可以代表同一空间的多个可重复使用的方向。
- 在四视图表中，将主视图放在左上方，反向视图放在右上方，两个侧视图放在下方。说明每个摄像头相对于固定物体的位置和方向，而不是简单地说前、后、左或右。面板描绘一个空间，而不是四个装饰选项。默认情况下，显示一个干净的空场景，配备固定的家具和道具，不添加人物、标题或方向标签。
- 移动摄像机可以改变屏幕的左右、遮挡和透视，同时保留物体的物理位置、数量、比例和材质。光源会随着屏幕投影的变化保持其空间位置。
- 将每个视图锚定在门、窗户、地标和家具之间的相同关系上；仅使用网格并不能确保空间一致性。当影响下游框架或与故事相关的空间关系时，请纠正报告的不匹配。仅使用未使用视图的缺陷不需要更多图像。对于损坏或重新排列的家具，请保留基础布局并说明当前状况。
- 下游参考素材指定了位置、状态和拍摄方向。使用空间结构、家具和材料，而不是将网格导入单个镜头。分别描述当前镜头中人物的位置和动作；保留现有场景记录中可重复使用的空间事实。

例如，当从入口处拍摄到舞台时，屏幕左侧的一扇窗户可能会在反向拍摄时出现在屏幕右侧，同时保持在同一面墙上。

在规划过程中，根据本轮所需的方向评估覆盖范围。一旦覆盖范围确定，并明确了固定对象之间的关系，就不需要额外的参考。
