# 视觉风格与排版知识库

当需要为 MG 口播动画选择整体视觉系统时，使用这份知识库。它总结了可复用的配色体系、画面风格、排版结构、层级规则、背景处理、图标/角色风格、行业映射和一致性规则。

## 核心原则

MG 口播动画必须先建立统一视觉系统，而不是把每个镜头做成独立画面。每个项目都需要稳定的配色、排版网格、背景处理、字体层级、图标风格、容器风格和动效语言。

最稳定的画面结构是三层：

- 背景氛围层：低对比渐变、纹理、网格、粒子、图案或抽象环境。
- 中景概念层：角色、产品、图表、图标、UI、流程或视觉隐喻。
- 前景信息层：关键词、数字、标签、指引线、按钮、箭头和高亮效果。

## 全局配色规则

### 主色克制 + 强调色点睛

强 MG 参考通常使用有限色彩：

- 60% 主背景色。
- 30% 信息承载色。
- 10% 强调色。

强调色只用于观众必须注意的位置：关键词、数据值、激活节点、进度、按钮、路径、警告或最终结论。

### 科技 / AI / SaaS / 云服务

典型配色：深蓝、藏蓝、暗灰、黑、蓝灰背景；电光蓝、青色、绿色、紫色、橙色或黄色点缀；低透明网格、光晕、粒子、HUD 线条、玻璃卡片。

适合 AI 工具、云服务、SaaS、网络安全、数据平台、区块链、数字化转型和企业科技。

### 医疗 / 健康 / 生物科技

两种方向：

- 友好医学科普：浅蓝白背景、柔和蓝紫点缀、干净扁平图标。
- 高端生物科技：深蓝紫背景、光晕、粒子、半透明器官、DNA、细胞、光轨。

避免血腥写实，使用几何化、半透明、简化和清洁的医学表达。

### 教育 / 大学 / 培训

浅色背景、低饱和蓝/绿/黄/紫，搭配清晰卡片、地图、证书、时间线、清单和流程图。

视觉感觉：友好、有秩序、可信、容易跟随。

### 食品 / 生活方式 / 环保

暖白、燕麦、奶油、米色、柔和绿、棕色、果红、自然黄；搭配纸张颗粒、圆角食物几何、植物、有机图标和柔和阴影。

视觉感觉：温暖、手作、亲和、生态、柔软。

### 新中式 / 茶 / 文化

宣纸色、墨绿、茶绿、低饱和红、朱砂、暖米色、炭黑；搭配印章、竖排标题、茶叶、水波、山水、祥云、纸纹。

视觉感觉：克制、优雅、有文化感、呼吸感。

### 文字海报 / 年轻潮流

强黑白对比、高对比色块、大胆强调色、霓虹或高饱和点缀；搭配巨型字体、重复文字纹理、贴纸、几何图形和动态海报构图。

## 排版系统

- 左文右图：默认推荐。左/右一侧放标题、关键词、数字或短主张，另一侧放图表、UI、图标、流程、角色或概念图。
- 右文左图：当视觉主体需要从左侧进入，或平台 UI 需要右侧文字时使用。
- 中心主体：中心放大符号、产品、数据、角色或标题，四周放小标签、指引线和环绕图标。
- 卡片看板：多张圆角卡片组成网格或层叠，每张卡片承载一个数字、图标、关键词或步骤。
- 流程时间线：横向或纵向路径节点，每个节点对应一个口播步骤。
- 分屏对比：双色或双面板表现问题/方案、前后、旧新、但是/然而。
- 消息流布局：竖向气泡、通知、红点、头像标签，适合社交与 App 场景。
- 新中式留白：大留白、竖排标题、小横排说明、文化物件或山水剪影。
- 动态海报：文字为主视觉，配合巨型字、贴纸、几何形、弧线和强节奏。

## 层级与信息密度

三层层级：

1. 前景：关键词、大数字、标签、箭头、按钮、激活图标。
2. 中景：角色、产品、图表、UI、流程、概念物。
3. 背景：渐变、网格、纸纹、粒子、柔和几何、远景剪影。

规则：当前口播焦点必须最大、最亮或动效最明显；辅助信息更小、更弱、更晚出现；背景轻微运动但不抢文字和数据。

信息密度：

- 低密度：茶文化、生活方式、食品、情绪品牌片。
- 中密度：教育、医疗科普、课程、App 功能解释。
- 中高密度：SaaS、AI、云服务、数据报告、金融科技、区块链。

单屏建议：一个核心视觉主体 + 一个关键词或短主张 + 2-3 个辅助图标/标签/数据点。

## 背景处理

- 浅色干净渐变：教育、医疗、生活、App、商务。
- 深色径向渐变：AI、数据、安全、高端医疗、云服务。
- 点阵/HUD/粒子场：科技、数据、网络、区块链。
- 纸张颗粒/轻噪点：食品、文化、生活、手作、新中式。
- 抽象色块：动态海报、年轻品牌、高能解释。
- 山水/水波/祥云剪影：茶文化、康养、东方主题。

背景动效：粒子慢漂、低透明网格移动、光晕呼吸、纸纹轻噪、小图标循环、镜头移动时视差。

## 图标、形状与角色

- 图标和形状优先几何、圆角、简化、符号化。
- 全片保持统一描边粗细。
- 科技/HUD 用线性图标；教育/生活用填充圆角图标。
- 医疗/生物科技可用半透明或发光轮廓。
- 新中式使用茶叶、祥云、水波、印章、山、竹、纸纹等文化符号。
- 角色优先简化：无五官或极简五官、长肢体、干净轮廓。
- 角色用于引导、指向、反应或演示，不要每帧都压过主体。

## 口播到视觉系统的判断规则

- 解释型脚本：左文右图或卡片看板，信息装进容器，按步骤释放。
- 情绪/品牌型脚本：使用主视觉、大留白、少标签，让文字和动效承载情绪。
- 数据型脚本：使用大数字、图表、终点标签、克制强调色。
- 文化/生活型脚本：纸纹、暖色、慢呼吸动效、物件中心构图。
- 科技型脚本：深色或干净蓝色背景、HUD 标签、节点、卡片、光效。

## 质量检查

- 所选风格是否匹配行业和语气。
- 配色是否克制，强调色是否没有滥用。
- 排版是否能承载口播信息量。
- 卡片风格、图标描边、字体层级、圆角和背景处理是否统一。
- 前景、中景、背景是否清楚分层。
- 背景动效是否不影响阅读。
- 每屏是否只有一个主要焦点。
