# 数据可视化动效知识库

当口播包含数字、百分比、增长、对比、排名、分布、流程、交易、用户数据、金融指标或商业报告时，使用这份知识库。它负责把口播中的数据关系转成 MG 图表、数据动效和可读排版。

## 总体原则

- 一个画面只解释一个数据观点，除非口播明确要求对比多个图表。
- 核心数字或趋势必须成为视觉锚点，图表服务结论，不做复杂表格堆砌。
- 优先使用简化图表、隐形网格、发光节点、大数字和短标签。
- 用动效解释数据关系：点拖出线、线形成趋势、节点形成网络、条形增长成对比、圆环填充成占比。
- 转场时尽量保留一个视觉锚点，例如圆点、圆环、条形末端、激活节点或数字徽章。

## 排版系统

### 一侧结论 + 一侧可视化

适合科技、企业、分析报告和抽象数据场景。

- 左侧或右侧三分之一放大数字、百分比或短结论。
- 另一侧放数据场、节点网络、波动线、雷达环、流向图。
- 标签保持短：大数字 + 单位 + 一句短说明。
- 使用点阵或弱引导线替代厚重坐标轴。

### 全屏单图表聚焦

适合需要观众直接读懂关系的图表。

- 一个图表占据画面中心。
- 标题或解释放顶部/底部。
- 核心数值贴近相关点、条形末端、圆环中心或气泡。
- 图表动画完成后停留，给观众阅读时间。

### 大数字海报式布局

适合里程碑或关键成果。

- 大数字成为主构图。
- 图表元素围绕数字、指向数字或从数字延伸出来。
- 粒子、短刻度、光晕爆点可用于庆祝突破。
- 避免段落文字，只保留单位、时间、类别和短标签。

## 图表类型与动效规则

| 图表形式 | 动效方式 | 适合口播语义 | 设计要点 |
|---|---|---|---|
| 增长折线图 | 亮点沿时间移动并拖出线条，历史节点依次出现，终点数值弹出 | 增长、趋势、上升、时间变化 | 主线更亮更粗，辅助线更弱 |
| 多线对比图 | 主线突出，副线减弱，用终点标签或放大镜强调差距 | 对比、领先、差距、排名 | 线条数量控制在 2-4 条 |
| 横向条形图 | 条形从分类名向数值方向增长，末端数字同步计数 | 分布、类别、年龄、排名 | 左侧类别，条尾数值，行距均匀 |
| 圆环进度图 | 圆弧顺时针绘制，中心数字计数，到点时轻微弹性停止 | 完成率、满意度、推荐度、占比 | 适合少量百分比，不适合复杂明细 |
| 同心圆层级图 | 多层圆轨道依次出现，圆点沿轨道运动 | 频次、层级、用户分层 | 用圆层代替复杂表格 |
| 气泡/双圆对比 | 两个圆按数值比例缩放，数字在圆内或旁边出现 | 金额、规模、体量差异 | 标签必须清楚，不要只靠面积判断 |
| 节点网络图 | 节点弹出，连线绘制，关键节点发光或波纹扩散 | 关系、连接、系统、网络 | 避免线太多形成乱网 |
| 数据流向图 | 路径先出现，小光点沿路径运动，可汇聚或分散 | 交易、流量、传播、路径 | 运动点比静态箭头更能表现流动 |
| 波动线 | 曲线波动穿过数据场，在峰值/谷值处脉冲或贴标签 | 波动、风险、监测、趋势变化 | 适合科技背景和弱网格 |
| 雷达/涟漪环 | 从节点向外扩散同心圆并淡出 | 检测、扫描、激活、影响 | 用于关键节点激活 |

## 数据入场与出场

- 文字和标签：从图表生长方向轻微滑入并淡入。
- 数字：在口播读到数字前略微开始计数，到重音点锁定。
- 节点：缩放弹出并发光，再稳定。
- 线条：从起点到终点绘制。
- 条形：横向增长，末端轻微过冲回弹。
- 圆环：顺时针绘制或从中心扩散。
- 气泡：弹性缩放，并停留给观众比较。
- 背景点阵：轻微呼吸，只有激活节点强发光。
- 出场：缩成点、顺镜头方向滑出，或放大成遮罩进入下一场。

## 数据强调方法

- 大数字：用超大字号呈现核心结果。
- 色彩聚焦：强调色只给主数字、主线、终点、条形或节点。
- 光晕/涟漪：激活数据点时使用柔光或同心圆。
- 放大镜：局部放大终点、差距或关键区域。
- 粒子爆发：仅用于里程碑、破纪录等强强调。
- 终点标签：数值标签直接贴近点、条、圆环，不要远离。
- 层级对比：主数据亮、粗、大；背景数据弱、细、小。

## 数据动画转场

- 跟随镜头：跟随移动圆点、条形末端或折线终点进入下一图表。
- 缩放遮罩：点、环、气泡或卡片放大覆盖画面后打开下一场。
- 分屏擦除：用于对比、反转、但是、然而。
- 图表形变：线终点变圆点，圆点变圆环中心，圆环变气泡，气泡变节点。
- 网格平移：保持同一数据空间，镜头移动到下一组数据。

## 口播语义映射

- 增长 / 上升 / 趋势 / 时间变化 -> 增长折线图。
- 对比 / 超过 / 领先 / 差距 -> 多线对比、双圆对比或并列条形。
- 占比 / 完成率 / 满意度 / 推荐度 -> 圆环进度图或 Donut 图。
- 年龄 / 类别 / 分布 / 排名 -> 横向条形图。
- 关系 / 连接 / 系统 / 节点 -> 网络节点图。
- 交易 / 流量 / 传播 / 路径 -> 数据流向图。
- 波动 / 监测 / 风险变化 -> 波动线和峰值高亮。
- 关键数据 / 里程碑 / 突破 -> 大数字海报式画面。

## 分镜字段建议

```json
{
  "data_visual_type": "增长折线 / 条形图 / 圆环进度 / 网络节点 / 流向图 / 气泡对比 / 大数字",
  "core_data": "需要展示的准确数字或对比关系",
  "chart_motion": "数据如何入场并到达最终值",
  "data_emphasis": "大数字 / 终点发光 / 放大镜 / 粒子爆发 / 涟漪",
  "label_policy": "大数字加短标签，避免长段落"
}
```

## 质量检查

- 图表类型是否匹配口播中的数据关系。
- 核心数值是否不用小标签也能看清。
- 标签是否贴近相关条形、点、圆环或气泡。
- 坐标轴、图例、网格是否已简化。
- 动画稳定后，观众能否在 2 秒内理解数据结论。
- 图表之间转场是否保留视觉锚点。
