# 元素动效与转场知识库

当口播动画依赖图形、图标、卡片、线条、圆点、背景层、物理反馈和顺滑转场时，使用这份知识库。它总结了 MG 动画中元素如何入场、停留、强调、转场和出场。

## 核心原则

MG 动画不应该把元素静态摆放在画面里。形状、图标、卡片、圆点、线条和背景都应该有清楚的物理逻辑：进入、变形、反应、跟随、呼吸、转场。每个动作都要服务注意力引导、概念解释、段落连接或口播节拍。

## 元素生命周期

| 阶段 | 动效规则 | 适合用途 |
|---|---|---|
| 入场 | 快速进入、慢速停稳、轻微过冲、阻尼回弹 | 关键卡片、图标、数据徽章、概念图形 |
| 停留 | 轻微悬浮、呼吸缩放、小角度旋转、背景漂移 | 长口播段落中的保活 |
| 强调 | 弹出、发光、粒子爆发、挤压拉伸、短促推镜 | 关键词、关键数字、警告、揭示 |
| 转场 | 复用当前元素作为遮罩、路径、圆点、圆环、卡片或形变种子 | 段落切换、主题跳转 |
| 出场 | 缩成点、旋转缩小、滑出、粒子消散、形变成下一元素 | 避免普通淡出 |

## 入场规则

- 关键元素使用快入慢停，入场后有小回弹。
- 卡片和面板分层入场：背景卡片先出现，文字延迟，图标/粒子再延迟。
- 线条先绘制，再生成卡片、节点或连接图形。
- 圆点可先弹出发光，再成为线条、圆环或数据路径的锚点。
- 避免所有元素同时出现，使用 2-4 帧延迟制造层次感。

## 出场规则

- 缩点：元素缩成一个圆点，作为下一场种子。
- 旋转缩小：元素先略微放大并旋转，再缩到消失。
- 顺向滑出：元素沿下一场入场方向离开。
- 线条回收：路径从尾部回缩或返回起始节点。
- 粒子爆散：元素分解成 5-8 个小点或碎片，快速淡出。
- 遮罩吞没：大形状扫过并带走旧场景。

## 弹性与物理反馈

- 过冲：元素超过目标 5%-15%，再回到目标。
- 挤压拉伸：快速移动时沿运动方向拉伸，撞击时压缩。
- 阻尼摇晃：落位后进行 2-3 次逐渐减弱的小幅晃动。
- 碰撞粒子：卡片落地或关键词出现时，从接触点发出小圆点/短线。
- 跟随惯性：附属图标、标签、小点比主元素晚几帧到位。

注意：物理反馈要让元素有生命力，但不能影响文字和数据可读性。

## 形变规则

当口播从一个概念移动到另一个概念时，优先考虑形变转场。

常用形变：

- 圆形 -> 圆环 -> 全屏遮罩。
- 圆点 -> 线条端点 -> 网络节点。
- 线条 -> 卡片边框 -> 容器。
- 卡片 -> 背景面板 -> 下一场舞台。
- 图标 -> 简化几何形 -> 新图标。
- 多个小形状 -> 组装成 logo、卡片或系统图。
- 一个大形状 -> 拆成多个子卡片或功能标签。

规则：形变过程中保留一个视觉锚点，让观众知道它从哪里来、变成了什么。

## 线条、圆点与路径

- 线条不只是装饰，它应该引导视线和揭示结构。
- 大转场前可用一条快速引导线把观众拉到下一场。
- 圆点可以表达激活、传输、选择、冲击或焦点。
- 圆点沿路径移动比静态箭头更能表现流动。
- 背景中的小点、小十字可做轻微循环，形成节奏粒子。
- 线条高速运动时可以加轻微拉伸或运动模糊。

## 卡片、图标与 UI 元素

- 卡片不要直接出现，使用滑入弹出、缩放回弹或线条绘制容器。
- 图标可由基础几何体组装，再落位成最终符号。
- UI 面板可从按钮、圆点或卡片种子翻折、滑出、缩放生成。
- 产品/功能模块可径向展开、扇形展开或层叠展开。
- SaaS/App 场景可加入光标、输入框、弹窗、进度条和轻微 hover 循环。

## 背景层动效

- 背景支持氛围，不抢主体。
- 可使用点阵漂移、小十字旋转、低透明引导线、慢速渐变。
- 背景可通过前景动作改变：圆形扩散、颜色涟漪、卡片擦除、粒子爆发。
- 快速转场时，背景可沿运动方向拉伸或模糊。
- 使用视差：前景强运动，背景慢速或反向轻动。

## 转场类型

| 转场 | 行为 | 适合语义 | 备注 |
|---|---|---|---|
| 图形遮罩放大 | 圆形、卡片、圆环或矩形放大覆盖画面并打开下一场 | 接下来、现在、下一章、看这里 | 最通用的 MG 转场 |
| 形变转场 | 当前核心图形变成下一场核心图形 | 从 A 到 B、升级、演化 | 保持连续性 |
| 甩动/速度线 | 快速横向或斜向运动，带模糊和色带 | 快速变化、话题跳转 | 出场方向与入场方向一致 |
| 色块滑入 | 2-3 个色块错时扫过画面 | 章节切换、对比、段落断点 | 干净高效，隐藏断层 |
| 引导线牵引 | 线或圆点飞过画面，镜头跟随进入下一布局 | 流程继续、下一步 | 适合流程解释 |
| 穿透视口 | 镜头冲进屏幕、孔洞、圆环、按钮或图标入口 | 深入、内部、幕后 | 形成一镜到底感 |
| 分屏擦除 | 对向面板推入或分割画面 | 但是、对立、问题/方案 | 逻辑转折时使用 |
| 组装/拆解 | 图形拆成碎片，再重新组装为下一图形 | 系统拆解、重组 | 适合复杂概念 |

## 镜头联动

- 镜头应跟随最强运动元素，不要随机移动。
- 推近表示深入、细节、聚焦。
- 拉远表示总结、全局、系统视角。
- 横向甩动表示快速进入下一点。
- 快速镜头配运动模糊或速度线。
- 镜头落位时加轻微回弹，让场景更有物理连接感。

## 口播语义映射

| 口播语义 | 推荐元素动效 |
|---|---|
| 重点 / 关键 / 注意 | 卡片弹出、粒子强调、短促推镜、光环扩散 |
| 从 A 到 B / 变化 / 升级 | 图标形变、卡片变背景、元素作为下一场种子 |
| 流程 / 步骤 / 路径 | 引导线先绘制，圆点沿路径运动，节点卡片出现 |
| 连接 / 网络 / 系统 | 节点弹出、连线绘制、镜头拉远展示网络 |
| 拆解 / 组成 / 多个部分 | 主形状拆成子卡片，或碎片组装成整体 |
| 冲击 / 痛点 / 警告 | 碰撞、挤压拉伸、震动、粒子爆发、色块急擦 |
| 进入 / 深入 / 看内部 | 穿透视口或图形遮罩进入设备/卡片/圆环 |
| 总结 / 汇总 / 回到整体 | 镜头拉远，元素聚合为中心系统或主卡片 |
| 但是 / 转折 / 对比 | 分屏擦除、色块滑入、对向面板运动 |

## 质量检查

- 每个主要场景是否有视觉锚点。
- 是否规划了入场、停留、强调、转场、出场，而不是只规划静态布局。
- 转场方向是否符合观众视线预期。
- 弹性动作是否没有影响文字或数据阅读。
- 背景动效是否保持辅助地位。
- 需要连续性时，下一场是否继承了点、线、卡片、圆环、色块或形状。
