# MG 基础动效模式库

当需要把口播脚本转成 MG 动画动效方案时，使用这份知识库。它记录了可复用的抽象概念动效：对比、分流、重复聚焦、聚合、平衡、波形等。

## 核心原则

MG 动效不是装饰，而是把口播里的抽象概念转成可理解的视觉运动。每个动效都应该服务一个语义目的：解释关系、强调重点、表达变化、连接段落或制造节奏。

## 核心动效模式

| 动效模式 | 运动方式 | 适合的口播语义 | 视觉用途 |
|---|---|---|---|
| 对比碰撞 | 两个相反圆形或图形相向运动、环绕、碰撞、融合、分裂或擦除画面 | 但是、相反、对比、冲突、两面性、A vs B | 表达对立、冲突、取舍、前后对比 |
| 分流路径 | 多条贝塞尔曲线从一侧生长到另一侧，线头可发光或脉冲 | 渠道、路径、分支、步骤、流向、传播 | 表达流程分叉、信息传递、路径选择 |
| 重复聚焦 | 大量重复点阵或图形铺满画面，其中一个或几个元素被放大、变亮、推近 | 重点、其中、最、核心、筛选、脱颖而出 | 表达从大量对象中聚焦关键点 |
| 聚合协同 | 多个小元素围绕中心运动，最后聚合成一个中心图形 | 整合、协作、系统、团队、统一、完整 | 表达系统整合、多因素协同、整体方案 |
| 平衡反馈 | 几何块堆叠、倾斜、摇晃并最终稳定 | 稳定、安全、成本、收益、风险、权衡 | 表达风险控制、预算平衡、理性决策 |
| 波形反馈 | 对称波形向内或向外推动，中心元素缩放、压缩或脉冲 | 波动、影响、压力、趋势、共振、传播 | 表达趋势变化、外部影响、压力传导 |

## 转场模式

- 文字变图形：先出现关键词，再让文字缩小、折叠、遮罩或形变成第一个图形元素。
- 图形放大遮罩：圆形、卡片或大色块快速放大覆盖全屏，再在同一颜色或图形里打开下一场。
- Z 轴缩放：对重复元素快速推近或拉远，制造空间深度并完成切场。
- 形状延续：上一场的某个圆、线、卡片继续成为下一场的起始元素。

## 节奏与缓动规则

- 口播是时间主轴，碰撞、融合、弹出、擦除、推近要卡在重音、转折词或节拍上。
- 避免匀速直线运动，优先使用快入慢停、弹性过冲、挤压拉伸、阻尼回弹。
- 音效轻量即可：快速移动用 whoosh，弹出用 pop，UI/图表节点用 click，融合/液态用软挤压声。
- 单个画面只承载一个清晰动效概念；如果一句话有两个想法，拆成两个视觉节拍。

## 简约图形规则

- 控制配色，常用灰阶 + 一个强调色，或两色对比体系。
- 优先使用圆、线、卡片、箭头、网格、进度条、节点、简单几何块。
- 屏幕文字保持短：一个关键词、一个标题加 2-4 个标签，或一句短句。
- 尽量让文字和图形互相转化，不要让文字只是孤立标签。

## 口播语义映射

- 对比语义 -> 对比碰撞、分屏、黑白或双色图形互动。
- 流程/路径语义 -> 分流路径、线条生长、圆点沿路径移动。
- 重点/数据语义 -> 重复聚焦、阵列高亮、推近、聚光。
- 整合/团队/系统语义 -> 多元素环绕并聚合到中心。
- 稳定/风险/价值语义 -> 堆叠、跷跷板、权衡、阻尼摇晃。
- 趋势/压力/影响语义 -> 波形、脉冲、涟漪遮罩、压缩反馈。


## 质量检查

- 每个段落是否有合适的动效模式，或明确说明为什么保持静态。
- 动效是否匹配口播语义，而不是只匹配表面名词。
- 转场是否复用了形状、方向或视觉锚点。
- 强调色是否只出现在真正需要注意的位置。
- 动效是否帮助理解，而不是抢走信息。
