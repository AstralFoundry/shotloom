# 文字动效知识库

当口播脚本需要强文字表现、标题片头、动态歌词、品牌主张、SaaS 产品卖点、搜索/输入/代码/AI 提示词或高节奏短句时，使用这份知识库。

## 核心原则

MG 动画里的文字不是字幕层，而是运动图形。文字可以入场、碰撞、拉伸、切割、组装、成为遮罩、成为转场，甚至引导镜头。

## 文字出现方式

| 方式 | 动效行为 | 适合语义 | 使用建议 |
|---|---|---|---|
| 淡入滑入 | 文字带轻微位移淡入 | 平静说明、辅助文字 | 用于次级信息，不要给主关键词只用这种方式 |
| 弹性缩放 | 词或短句从小到大，过冲后回弹 | 重点、爆点、好处、数字、揭示 | 可配合轻 pop/click 声 |
| 遮罩显现 | 文字从矩形、线条、卡片、胶囊或窗口后滑出 | 品牌标题、章节标题、UI 文案 | 干净稳定，适合商业片 |
| 打字机 | 字符逐个出现，伴随光标 | 搜索、输入、AI 提示词、代码、提问 | 加键盘声与光标闪烁 |
| 碎片聚合 | 字母或几何块从多方向飞入并组成文字 | 片头、发布、爆点、大标题 | 时间控制在 1-1.5 秒 |
| 路径文字 | 文字沿弧线、圆环、丝带、透视路径运动 | 流程、环绕、周期、方向、关系 | 让文字成为空间元素 |
| 3D 飞入 | 文字沿 Z 轴飞入、旋转或穿过镜头 | 高级片头、里程碑、强转场 | 少用，必须保持可读 |
| 插槽替换 | 固定句式中某个关键词滚动或翻转替换 | 多卖点、多状态、身份切换 | 降低快速阅读负担 |
| 线稿绘制 | 笔画、辅助线、锚点先构造文字，再填充 | 设计过程、品牌识别、创作感 | 适合工作室、VI、品牌片 |

## 文字消失方式

- 反向遮罩：色块、卡片、线条盖住文字并带走。
- 缩成锚点：文字缩小成点、logo 或下一场的转场对象。
- 快速滑出：带运动模糊，方向与下一场一致。
- 卡点硬切：适合歌词、广告和短爆点词。
- 切片消失：文字水平或垂直切层错位后消失，适合科技、冲突、揭秘。
- 撕裂剥离：文字像纸张被撕开，适合真相、态度、反转。
- 液态融化：字母滴落、粘连、流动，适合能量、灵感、转化。
- 粒子消散：文字分解为粒子或沙尘，适合记忆、消失、情绪淡出。
- Z 轴离场：文字飞向或远离镜头，作为下一场转场。

## 文字层级动画

### 单字/字母级

用于高节奏和细节感：单字弹跳、字符旋转归位、笔画拆分、字符重力掉落、字母沿路径组词。

### 词级

用于语义强调：关键词放大、变色、描边转实心、故障、液态、撕裂、粒子化、固定句中替换关键词。

### 行级

用于短句和歌词：多行级联、行间滚动、一行裂开插入图形、行沿弧线运动。

### 段落/卡片级

用于解释型内容：卡片先出现，标题、数值、小字分层进入。信息多时用卡片级动画，不要让每个字乱动。

## 效果类型

- 遮罩容器：矩形、圆形、胶囊、卡片、窗口、网格、门缝、裁切框显隐文字。
- 切割错位：斜切、横切、竖切、分屏、故障切片，适合对比和反转。
- 弹性文字：过冲、Q 弹、果冻回弹、挤压拉伸，适合轻松产品和年轻品牌。
- 故障文字：错位、扫描线、抖动、噪点、横向撕裂，适合 AI、科技、安全、警告。
- 液态文字：滴落、填充、波纹遮罩、粘连融合，适合流动、能量、情绪。
- 路径文字：文字绑定弧线、圆环、丝带、透视网格或 3D 空间。
- 镜头联动文字：文字跟随镜头推拉、平移、震动、穿梭，成为环境的一部分。

## 排版系统

- 中心大词：一个巨型词或短句居中，次级文字延迟出现。
- 主副延迟：主词先出现，副标题、说明、标签延迟 0.3-0.5 秒。
- 分屏对比：两侧承载对立词或观点，适合前后、问题/方案、但是。
- UI + 主张：一侧 UI/产品，一侧大字卖点，适合 SaaS、App、AI 助手。
- 重复文字纹理：低对比重复文字做背景，前景放大关键词。
- 动态海报：文字是主构图，配合巨型字体、弧线、贴纸、几何块。

## 节奏与声音同步

- 文字弹出、替换、切割、故障、回弹、组装、推镜要卡口播重音或节拍。
- 强拍用于主要变化，弱拍用于回弹、停稳、次级文字。
- 打字机配键盘声；滑动/遮罩配 whoosh；弹跳配轻击；故障配电流噪点；撕裂配纸张声。

## 口播语义映射

| 口播语义 | 推荐文字动效 |
|---|---|
| 重点 / 关键 / 核心 / 注意 | 弹性放大、变色、描边转实心、中心大词 |
| 但是 / 相反 / 问题是 / 另一方面 | 分屏对比、切片、对向面板、故障错位 |
| 搜索 / 输入 / 提问 / AI生成 / 代码 | 打字机、光标、输入框、UI 卡片 |
| 流程 / 路径 / 步骤 / 方向 | 路径文字、线条显现、沿箭头/丝带运动 |
| 改变 / 迭代 / 升级 / 更新 | 插槽替换、形变、关键词替换、故障转清晰 |
| 崩塌 / 失败 / 下坠 / 压力 | 字符掉落、重力散架、垂直坍塌 |
| 揭秘 / 打破 / 撕开 / 真相 | 撕裂、剥离、切割显现 |
| 增长 / 数字 / 里程碑 | 大数字、计数、镜头推近、粒子爆发 |
| 流动 / 灵感 / 能量 / 消融 | 液态填充、波纹遮罩、粘连融合 |
| 品牌 / 官网 / 产品主张 | 遮罩显现、主副延迟、UI + 大字 |
| 歌词 / 节奏 / 短句卡点 | 单词闪现、硬切、快速行替换 |

## 质量检查

- 关键字或短句是否拥有最强视觉处理。
- 文字动效是否匹配句子语义。
- 动画停稳后文字是否可读。
- 主文字和辅助文字是否没有同时抢焦点。
- 转场方向是否清楚，不随机。
- 主要文字动作是否规划了口播重音或声音卡点。
