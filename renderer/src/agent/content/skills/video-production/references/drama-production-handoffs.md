# 短剧导演意图、版本交接与恢复

短剧从剧本进入镜头制作、已有结果发生改版或生成中断时读取。把信息写进现有 Production Plan 的阶段描述、镜头工作项及真实引用，不另建流程状态或固定阶段门禁；只处理本轮授权范围。

## 让导演意图落到镜头验收

先读场尾的信息、关系或权力变化，再解释本场共同事件和人物各自的目标、阻力、策略、倾听对象。沉默人物也有可观察的参与方式；沿用剧本已有生活动作表达策略，不为填字段补造情节。分镜说明观众先知道什么、何时发现变化，机位、景别、调度、光影与声音如何服务这个变化。普通对话或简单拿放无需额外动作预演。

把每镜最可能失败的点改成可观察的验收项：例如“甲右手把杯子交给乙左手，结束时杯子只在乙手中”，而不是“动作自然”；镜面核对映像与真人，群像核对具名人物和人数，前景遮挡核对关键接触点可见，竖屏核对脸、道具和字幕安全区。按实际风险取舍，不复制整张检查表，也不以多生成参考板代替证据。空间或复杂接触确实需要预演时，使用 `director-desk-staging` 的真实场景与预览，再把结果作为有来源的参考。

## 改版只追踪受影响的依赖

记录当前采用的剧本、镜头、图像、视频和声音对应的真实节点、任务及可获得的结果标识；工具没有版本字段时记录实际输出引用，不编造版本号。候选结果与当前采用结果分别说明。

上游改动后沿真实依赖核对下游：造型变化影响引用该造型的参考和镜头；道具或走位变化影响相邻接点；视频换版影响从它取得的尾帧、声音样本和剪辑源；配音换版影响口型、字幕与剪点。把尚未复核的结果标为待复核，不把文件仍存在当成仍适用。保留旧结果和未受影响的工作，只有确需重新生成且授权覆盖时才运行付费任务。

## 中断恢复先查原任务

网络报错后先读原节点与 `inspect_tasks` 回执。在途继续查询；已成功则核对已有输出；本地缺媒体时先使用当前工具支持的取回方式。只读查询的瞬时失败可以有限退避重试，401/403、余额、参数和能力错误应修正具体原因。

提交超时、响应丢失或没有拿到任务 ID 时，结果属于未知，不能直接重发生成。先查节点任务历史与可用回执；只有确认未受理或明确失败，且已有授权覆盖，才修复并重提。无法确定时说明阻碍与重复计费风险，继续其他独立工作。revision 或会话冲突时重新读取当前事实，只提交尚未成功且仍适用的修改，不重放已经成功的批次。

## 交给剪辑的真实信息

交接当前采用的视频与音频来源、镜头顺序、可用源区间、对白归属、入出点和声音桥意图。原生音频先实际试听，合格部分保留；后配只替换问题区间或满足用户明确要求，并说明需要保留的现场声。缺少听音能力时记录待试听，不能假定原声不合格而重复生成。

字幕依据最终采用声轨的实际转写或人工听写校对，剧本用于核对漏词和错词，不能代替实际发声与时间证据。换声、裁切、变速或换版后重新核对字幕和口型。剪辑能力以当前工作区工具为准，完成声明分别对应已配置、已生成、已审片与已导出；没有真实成品或导出回执时交付执行单并明确剩余事项。
