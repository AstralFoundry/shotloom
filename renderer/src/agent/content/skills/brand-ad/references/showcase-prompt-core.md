# 广告创意和视听提示

使用这种方法来解决当前的创意差距。提供的脚本、板块和已接受的处理仍然是基础；不要在想法已经确立后开始第二次构思练习。图像准备仅使用[tvc-moodboard-creative-guide.md](tvc-moodboard-creative-guide.md)来覆盖缺失的部分；执行使用[production-and-delivery.md](production-and-delivery.md)。

## 将想法转化为可见的体验

将观众应该记住的内容与感官联想联系起来，使用结果、意外关系、转化、表演或图像事件。产品观点需要一种有意义的关系，而不仅仅是一系列必要的角度。直接演示可以像延迟揭示一样刻意，但两者都不是强制性的。

当创造一个新想法时，要在内心考虑不同的表达方式，并选择一个具有特定回报的表达方式。简短的概述可以让你发展摄影、舞台设计、效果、节奏和声音，而不是创造产品事实或标志。保留提供的措辞。保持创意卡片的紧凑性：包含内容、想法/世界、关键事件/节奏、强制性要求和剩余的准备工作。现有的作品已经可以包含所有这些内容。

用户要求和经过验证的身份保持不变。建议的摄像机角度、拍摄速度、色彩分布和声音仍然是创造性的选择，可以在接受的方向上进行改进。不要将每个偶然的选择都转化为新的禁止或审查形式。

## 节奏跟随注意力

一个视觉事件、镜头、生成单元和分镜面板是不同的东西。塑造吸引注意力的内容，发展、改变意义并留下痕迹，然后为实际持续时间分配时间，完成动作、言语和阅读。

- 联想蒙太奇：触觉细节、手势、反应或环境碎片积累情感，并回到一个可识别的主题或结果。情感积累可能使用更密集的剪辑。
- 持续发现：沿着世界旅行或穿越世界，同时通过规模、焦点、访问或速度揭示新的信息。这需要长时间的内部发展。
- 跨视角行动：在可理解的行动范围内切换，保持方向和动力，同时省略常规间隔。
- 带着改变的意义回归：在事件改变其意义后，重新审视一个手势、形状或地点。

如果有用，可以选择或组合这些元素。剪辑密度、运动速度和信息密度是独立的控制。一个密集的通道可能会开启一个广阔的曝光；一个安静的时刻可能会通过小的发现而变得更加强烈。没有固定的镜头数量、每个镜头的秒数规则、转场配额或结束百分比。一块提供的底片并不意味着相同的底片时间。较长的影片会产生影响，而不是重复微型广告的开场和结尾。

## 具体地书写摄影和转换

给每个重要图像一个焦点层级、视角、比例以及前景/主体/背景关系。出于某种原因，选择负空间、遮挡、深度走廊或比例对比。光线应该揭示实际的玻璃厚度、金属纹理、液体张力、布料或纸张响应。悬浮空间不需要地面平面；阴影和反射随选择的世界而动。

将摄像机、主体和环境运动分开。一个缓慢旋转的产品可以支持快速平稳的镜头运动。一个固定的摄像机可以见证一个含能材料事件。高级并不意味着缓慢、安静、低饱和度或空白。将所选动作描述为**起始视图→路径和速度展开→显示→着陆**。一个近地表滑翔机可以加速然后进入远处的英雄；命名变化的视图而不是任意的坐标。

给予效果一个来源、行为和分辨率：流体伸展和断裂，颗粒沿曲线运动然后散开，几何形状展开暴露内部。效果不需要单独的触发器。当它们符合概念并保留所需的产品结构时，身份一致性并不禁止摄影机卷轴、光桥、变换或速度对比。

在有意义的切换中，指定出口提示和入口焦点着陆。选择影片所需的元素：

| 机制 | 提示词所明确表达的内容 |
| --- | --- |
| 形状/构图匹配 | 下一个主体继承的轮廓、位置或负空间 |
| 动作匹配 | 运动阶段、方向和动量在视角间传递 |
| 前景遮挡 | 覆盖图像的现有材料及其清晰化成的新场景 |
| 光学/材料桥 | 动机性反射、折射、光或液体充满视野及其分辨率 |
| 对比度/硬切 | 尺度、能量、空间或意义的决定性变化，具有明确的新焦点 |
| 声桥 | 连接或预示下一个图像的声音、动作或氛围 |

这些都是选项，而不是强制性的过渡。直接切换或不间断的动作可能是最有效的。避免使用通用禁止列表来取消所选择的处理方式。

## 声音和副本随图像发展

为这个概念选择原生音乐、声音、氛围、幻灯片或刻意的沉默。没有单独的音乐文件并不意味着没有音乐。描述音乐的特征、入口、构建、重音、结尾以及音乐在哪里让位于一行或一个动作。并非每个剪辑都需要 “嗖” 的一声。

叙事使用准确的建议词语、支持的主张、语言、声音特征、表达和图像关系。情感线不需要创造表演规范。关键字体设计突出意义，而不是抄写每一句话；使用[voice-keyword-typography.md](voice-keyword-typography.md)表示字母形式、空间关系和可读的输入/输出。保留用户的无文本/无声选择。在独立生成的单元中，遵循实际的连续性计划，而不是承诺从散文中创作相同的音乐。

## 编译完整的局部进度

一旦必要的真实输入可用，就要针对它们制定镜头处理方案。简报或卡片不是细节的上限。写得足够多，让读者能够想象变化、拍摄方式和声音;“高级宏观”→“揭示”→“主角” 是不够的。扩展事件，而不是重复约束。

使用以下框架，省略不相关的字段，而不是提交空白标签：

```text
Create {duration and format} ad for {subject}, expressing {specific idea}.
Visual world: {space, light/color relationships, art direction, material behavior}.
References: {actual input order, identity/look/state contributions and transfer limits}.
Preserve {verified identity, supplied text and mandatory requirements}.
Editorial intent: {how attention, motion and sound develop}.

{Time window / passage}:
The viewer first sees {scene, subject state, viewpoint, scale, depth and focal read}.
{Action} causes {visible material, light, environmental or emotional response}.
The camera starts {view}, moves {path/direction/speed and optical development},
reveals {new image or relationship}, and lands {view/state}.
{Internal discoveries or cuts; outgoing cue → bridge → incoming focal subject}.
{Music, ambience, Foley or exact voice line} enters, changes or yields with {event}.
{Exact text if needed}: {letterform, hierarchy, position/depth, entrance, reading, exit}.
Leave {continuing action/visual state/sound} for the next passage.

Ending: {recognizable resolution, required identity/copy, background motion, audio tail}.
Relevant constraints: {concrete identity facts, user exclusions or specific failure risks}.
```

一个段落可能包含多个剪辑或一个不断变化的长篇段落。选择一种实际的处理方式，而不是未解决的 “推或绕” 替代方案。保持必要的动作、顺序、措辞和身份的准确性；为自然运动和微时间留出空间。不要冻结每个小剪辑或动画化分镜网格边界。每个生成单元都重复必要的上下文及其完整的局部进展，而不要 “与上述相同”。通过提交保留这个详细的提示；能力适应不要默默地总结它。

在生成之前，阅读实际提示，寻找可见的想法/效果、有意义的相邻变化、有形的构成/材料、有目的的动作和节奏、完整的语音/朗读、真实的参考角色和连贯的结尾。解决诸如禁止所选效果或无缘无故移除有用声音等矛盾。这是一种写作检查，而非额外媒体生成的授权；实际的质量声明需要实际的观察。
