# 产品视觉技法库

仅在当前产品创意需要时选用，适用于图片设计与视频动作。每种手法都落实为具体空间、材质、运动和视觉结果，不整库复制，不设效果触发门槛。场景锚点图与故事板按 [tvc-moodboard-creative-guide.md](tvc-moodboard-creative-guide.md) 编写；场景图承接环境和美术设计，产品身份由独立的一致性锚定图提供，技法中的产品准确性要求在主体锚定与成片中落实。

| 创意需要 | 可发展为画面事件的手法 |
| --- | --- |
| 透明、纯净、轻盈 | 玻璃厚度、水膜、棱镜、焦散与内部微泡；让折射掠过、包裹或揭示主体，前景介质可以承接转场 |
| 精密结构与功能 | 轴向爆炸展开、局部剖切、气流/声波/信号路径；按已知结构展开并回收，微距穿行揭示层次，不虚构部件或性能 |
| 口味、清爽与触感 | 液体拉伸与破裂、冰块碰撞、气泡释放、碎屑飞散、配料轨道、微距截面；为运动写明轨迹、速度变化与收束 |
| 工艺和价值证据 | 镜片镀膜、金属滚花、皮革缝线、织物张力、纸纤维、冷凝水珠与包装肌理；改变角度/焦点/光线使材质可感知 |
| 产品权威与空间尺度 | 低机位纪念碑、对角悬浮、极近到极远、产品结构作为空间入口；通过尺度和纵深揭示形态，不只孤立慢转 |
| 系列与多 SKU | 扇形、矩阵、运动接力、色面折叠、阵列重组；让口味/色号的差异产生节奏，保留各包装真实身份 |
| 生活与创作 | 真实使用动作、阳光/窗影、桌面触感、图形从笔触或物理操作中发展；允许人物与产品关系承担广告内容 |
| 品牌文字与图形 | 空间字、版面接管、弹性字块、透视面、图形匹配；用 [voice-keyword-typography.md](voice-keyword-typography.md) 保证信息层级和阅读 |

摄影可以贴近材质快速掠过，再打开空间形成识别；主体缓慢自转时相机也可以高速丝滑穿行。颗粒、流体、结构和光学效果必须有具体来源、发展与落点，不以“无特效”代替设计。真实产品不能因视觉夸张改变型号、组件数量或包装身份。

构图可选中心、平衡的不对称、负空间牵引、前景遮挡、深度走廊或镜面空间；切换由新的信息或情绪支持。完整产品、极近细节、人物/环境关系可以形成反差。用于识别的镜头保护轮廓，用于感官的镜头可以局部化；不要求全片都用相同识别机位。

色彩按产品、品牌和创意选择，低饱和与高饱和都可以精致；不强制单一强调色，也不让风格色覆盖真实包装色。光线可以通过显现、折射、遮挡和投影参与叙事，保留其来源及材质响应。

晶体仿生奢华适合相关护肤、香氛、珠宝或柔性科技概念：透明晶体、液态金属、微泡、焦散与羽毛/水母般结构可围绕产品发展，进入前景形成遮挡，再回收到主体。它是可选创意语言，不是全品类默认，也不是新功能主张。
