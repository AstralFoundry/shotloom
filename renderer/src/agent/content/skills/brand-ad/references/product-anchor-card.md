# 产品识别参考

使用这种方法可以减少对真实产品的模糊性，而不是默认生成综合卡片。使用实际来源保护相关轮廓、比例、组件、材料、标记和确认状态。这张图像作为产品的一致性锚定。[Scene anchors](tvc-moodboard-creative-guide.md)分别开发环境和艺术方向，无需产品或字母一致性要求。

## 选择最小的有用准备

| 可用证据 | 行动 |
| --- | --- |
| 清晰的原始资料已经涵盖了所需的身份和视角 | 直接使用它们；不要创建新卡 |
| 产品来源过于模糊，无法可靠地识别所需身份 | 在创意生成之前，从受支持的来源视图中生成产品身份参考卡；保持不受支持的细节未知 |
| 有用的证据分散且难以整合使用 | 将选定的现有视图整理成一张清晰的标识卡，保留原始视图 |
| 缺少一个必要的角度或状态 | 获取或澄清缺失的证据，然后仅填补那个空白；如果可以避免未知的细节，则使用其他组合 |
| 标记、控制或纹理需要精确识别 | 保持清晰的原始或本地作品在可读的尺寸上；不要将其缩小成密集的网格 |

身份卡可以是现有来源的排列，也可以是当可用产品材料过于不清晰而无法可靠识别时生成的参考图像。在后一种情况下，在创作图像生成之前，只需生成一张基于来源的卡片；它不会验证一个未得到支持的事实。只选择计划工作所需的视图和细节，并留有足够的识别空间。没有必要的区域、视图计数或材料样品。如果所需的事实仍然未得到支持，就让它保持未解决状态，并说明局限性，而不是编造它。

未知的规格、反面标记和组件仍然未知。一个合理的生成视图并不能为它们提供证据。源代码支持的视图变更仍需要验证其预期用途。一个明确的原创概念可能会建立一个连贯的设计，与实际产品的特性有明显区别。

## 当需要图像提示时

描述实际来源、受保护的细节、准确的缺失视图或状态，以及后续拍摄所需的可读结果。仅使用这个可选框架的相关部分：

```text
Prepare {one needed view / detail / compact identity card} for {subject and intended use}.
Use {actual source} to preserve {verified shape, proportions, components, marks and state}.
Show {specific evidence-backed coverage}; leave {unsupported details} unresolved.
Keep {recognition features or exact detail} large and unobscured enough to read.
Use lighting that reveals {relevant geometry or material} faithfully.
If arranging several sources, keep only complementary views and essential accurate labels.
```

在依赖准备好的参考资料之前，使用授权审查范围内的可用观察结果来检查身份和可读性。保留原始的高分辨率品牌和包装来源；生成的卡片不会验证新的事实。如果一个视图是错误的，请保留有效来源并报告差距，而不是自动再生它。

交出可用的原作、作品或准备好的图像及其身份角色。它们偶然出现的背景、标签、布局和普通灯光并不会限制广告世界。一个清晰的原作仍然是最有用的最终参考。
