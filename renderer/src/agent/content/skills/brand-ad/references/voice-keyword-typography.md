# 广告文案、空间字体与原生旁白

需要创意文案、旁白或动态字体时读取。本卡负责把信息写成具体字形、空间关系和音画行为；不另建文案问卷或逐字审批表。声音整体发展见 [showcase-prompt-core.md](showcase-prompt-core.md)。

## 信息与文案

保留用户原文、语言、大小写和标点。新增文案围绕品牌态度、产品证据或故事关系提出，标记为创意提案并纳入既有方案。缺少技术规格不等于不能写情绪或品牌表达，但不能编造数字、性能或认证。遵守明确无字、无旁白、静音要求。

旁白负责完整表达，花字突出值得记住的关键词，不把每句旁白变成字幕。按需要区分主标题、卖点说明和行动信息，不为凑层级追加无用文字。真实 Logo、标准字、包装和法律文字沿用核验来源；新创意字体可以设计，但不能改变受保护标识。

## 字形、构图与空间

先用品牌已有字体规则；没有时描述模型能呈现的字形特征，不假设能调用本机字体文件。根据表达选择：

| 表达 | 字形与层级选择 |
| --- | --- |
| 精密与现代 | 开放字腔、明确几何骨架的主句，较轻紧凑的辅助层；沿产品边线或透视轴组织 |
| 轻奢与编辑感 | 高对比粗细笔画、清楚衬线、疏朗字距；副层用稳定无衬线，与主句共享阅读轴 |
| 力量与速度 | 窄而厚实、端点明确的主字，大尺度重音之后让位给动作；辅助信息更轻、更开阔 |
| 工艺与温度 | 印刷触感的衬线或粗衬线、自然纸面肌理；字与压痕、套印或载体翻动发生关系 |
| 社媒与愉悦 | 圆厚字块、弹性尺度与鲜明色彩；整组语义可读后再发展形变或重排 |

这些是选项，不是品类限制。中文描述重心、偏旁比例和收笔；拉丁字描述字腔、宽度、端点和字距。双语只有需求存在时才加入。用字重、宽窄、尺度、间距和对齐区别主副信息，不只是等比缩小。

选择文字的实际载体：画面留白、产品前后独立深度层、纸张/玻璃/面板的透视面、可信投影或反射。写清位置、尺度、对齐、深度、遮挡和焦点。空间字随镜头产生视差，平面字不强制做3D；悬浮字不添加无来源接触影。读字时保持字形和对比，保护产品识别面。

## 从片头字体系统迁移到品牌广告

空间文字、Logo 包装和产品展示动效沿用三层字体角色，但按广告信息重新分工。这些是成片文字设计要求，不要求场景锚点图提前生成准确文字：

- **Display A / Hero**：品牌名、产品名或本段唯一的主信息；写清骨架、字宽、字重、字距、字腔、材质、颜色、尺度、空间位置和主运动。
- **Display B / Benefit**：卖点、情绪短句或第二视觉主张；与 Display A 至少在字形类别、宽窄、粗细、实心/线框或静态/构建中的两项形成对比。
- **Utility / Identity**：已确认的规格、型号、功能标签、英文对应层或行动信息；稳定、清楚、固定对齐，不把 Display A 等比缩小充当辅助层。
- **Marks**：来自真实 Logo 字形、笔画、字腔、边框、线、点或低对比重复的无新增语义图形；不凭空生成伪文字。

准确的品牌名、Logo、包装字、法律文字和用户指定文案先锁定，再决定排版和动效。Logo 的字形、字距、比例和拼写不可变形；可以放大真实字腔或轮廓做遮罩、框线、切割边和转场入口，但下一状态要恢复完整标识。只有 Logo 时，Logo 是画面的文字主角；有产品或人物锚点时，保护锚点的识别面，不能让持续大字覆盖它。

按一组广告的实际阅读层级设置尺度阶梯：Hero 约占画面宽度 50%–95%，中尺度信息约 18%–55%，小尺度 Utility 约 5%–16%；同一画面只保留一个最大文字焦点。每组文字选择可解释的空间关系：负空间、透视锁定、前景遮挡、反射显影、纸片/卡片/面板承载或独立深度层。成片中的产品展示至少让文字与产品边线、材质、光线或镜头路径发生一种真实关系，不能退化成贴在画面旁边的静态标签。

所有动态文字遵循：**触发 → 揭示/构建 → 完整词组 → 可读停留 → 一次响应 → 稳定/退出或继承**。先让准确词组完整出现，再做一次字距舒展、焦点交换、材质经过、字块重排或字形变图形；禁止随机散字、逐字弹跳、持续漂浮和为装饰重复新词。转场应继承已出现的基线、轮廓、材质、光路、纸边或产品运动，落到下一段的新主体或新状态。

## 将动态写入对应视频段落

以具体画面行为组织：**触发 → 揭示/构建 → 完整词组 → 阅读 → 响应或退出**。静态文字可直接完整存在，不必强加动画。

- 前景/产品离开，露出后方完整文字；清空遮挡后留出阅读。
- 光、墨、玻璃或纸张沿明确路径显现字形；完整显现后保留字腔和对比。
- 产品证据将焦点交给另一深度的文字，读完再交还主体。
- 已读完整的词组作为语义块弹性落位或重排，保持字序而非随机散字。
- 读完后，笔画、字腔或承载面成为转场入口；下一镜继承几何或动势并落到具体主体。

将选定机制展开为可执行描述，不只写“高级花字”。例如：厚实圆角主标题作为完整字块从包装后方弹出，压缩后回弹并停稳；相机此时放缓，完整阅读后包装边缘携带字块退出并切入下一口味。具体文字、材料、方向和阅读时间必须来自当前广告，不照搬例子。

在最终提示词相应段落写入：准确文本、字形/层级、颜色/材质、位置/深度、出现触发、完整阅读与退出。时间根据字数、观看距离、运动和对比决定，无固定帧数或占屏比例。文字构建、产品证据和快速运镜应有主次，不能同时争抢注意力。

## 原生声音与品牌落点

需要旁白时，在视频提示词中写明逐字稿、语言、声线、情绪、语速/停顿、对应画面和完整句子边界。让音乐与动作声在关键语义处让位，花字跟随语义或动作重音；不重复叠加同内容配音。多段连续性按 [production-and-delivery.md](production-and-delivery.md) 处理。

有品牌落点时，使用图片阶段已准备的 ending card，标识位于上方安全区，背景保留合适运动或光线变化。创意文字随视频生成，禁止事后叠字、换字或用 Logo 遮盖生成问题。按可用观察说明逐字准确、可读停留、跨帧稳定和音画同步的实际情况；不把未观察的内容判为通过。
