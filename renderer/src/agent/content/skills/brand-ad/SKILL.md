# 品牌广告

使一个官方品牌或产品展示具有清晰的视觉理念和丰富的视听执行。保留视觉路线参考中的展示处理方式，以及用户要求的等效风格。叙事 TVC、活动策略和多电影制作超出了这项技能的范围：解释这个边界，然后停止这项技能，而不要指定其他技能或工作流程。

## 内容所有权边界

品牌主导的展示内容由品牌对信息的控制来定义，而产品或品牌仍然是视觉主体。人员、手、脚本演示和产品使用可以作为官方方向、规模或证据出现；它们本身不会成为创作者的内容。定义目标是品牌认可、产品记忆或官方视觉主张，而不涉及创作者的个人评论或受众行动目标。

原创内容通常包括评论、推荐、比较、开箱、个人体验叙述、第一人称视角、教程以及旨在参与、关注、询问或转化的平台钩子。即使产品仍然是视觉主题，主讲销售和基于体验的演示仍然是原创内容的案例。

官方产品演示属于品牌主导的展示类别，前提是该演示由品牌创作，使用经批准的事实和复制品，并呈现产品行为或视觉识别，且没有创作者角色、个人判断或社会商业行动号召。

当核心可交付内容是创作者原生内容时，解释它超出了本技能的范围，然后在不指定其他技能或工作流程的情况下终止该技能。

## 1.继续提供的工作

在规划新作品之前，请阅读简要和实际可用的资料。保留经过验证的身份、提供的脚本/分镜、准确的副本、持续时间意图、格式和公认的艺术方向。区分用户需求和可以开发的创意选择。只询问那些会显著改变身份、声明或交付的差距；重用现有决定和授权。

如果想法缺失，建立一种可见的关系或事件，使产品/品牌令人难忘。使用一张紧凑的创意卡片来记录外卖、视觉想法、重要事件和节奏、结束和剩余的准备工作。如果提供的脚本或分镜已经传达了这些决定，请继续下去，并仅列出缺失的选项。不要重新构建卡片或故事来满足工作流程模板。

选择[homepage-visual-routes.md](references/homepage-visual-routes.md)中的相关处理。使用[showcase-prompt-core.md](references/showcase-prompt-core.md)进行详细的视听写作；一个紧凑的计划不是一个简短的生成提示。

## 2.根据需要准备一致性锚和场景锚

### 将准确性与创作自由分离

在图像生成之前，在现有方案中只总结两个类别：

- **必须准确:**真实主体的表格、个人身份、品牌标志、指定文本、确认状态和其他批准要求。确定每个相关事实的来源；不支持的细节保持未知。
- **对创作持开放态度:**环境、灯光、构图、调色板、视觉隐喻、空间比例和情感，在可接受的方向上。源照片中的普通背景和灯光不会成为创作的限制，除非概要要求它们。

不要用看似合理的发明来填补真实身份的空白。寻找缺失的信息来源或澄清，或者围绕未知的细节进行构思，同时继续独立的创作工作。表现性的空间尺度变化并不能建立真实的维度或产品主张。

### 为创作空白准备两个锚定角色

使用已接受的想法和即将拍摄的镜头来区分两种形象角色:**一致性锚** 保留反复出现的人物、产品和其他主体的身份和外观;**场景锚** 建立场景设计、空间关系、灯光、构图和创意状态。场景锚不承载产品外观、标志或文本一致性的要求。没有单独的 KV 准备阶段。

根据实际视图、状态和所需的可读细节来判断现有材料。首先检查所提供的产品来源是否使轮廓、比例、组件、标记和所需状态可靠可读。如果它们太不清晰以至于无法可靠识别，请在创作图像生成或视频制作之前生成产品识别参考卡，只使用支持的来源视图，并保持未分辨的细节未知。不要让场景主播代替进行识别检查。直接重复使用足够的原始材料。只有在分散但可读的来源更容易使用时，才将它们组织成清晰的识别卡；只用支持的证据补充必要的缺失视图或状态。为了准确识别，要保留清晰的原始或本地作物，而不是将细节缩减为密集的网格。目标是减少模糊性，而不是全面的卡片。当产品锚需要准备时，请参见[product-anchor-card.md](references/product-anchor-card.md)。

当一个人必须在不同的照片中保持一致时，检查面部识别、头身比例、头发、衣服和携带物品是否被包含在计划的视角中。重复使用足够的人物参考。仅补充必要的、缺失的侧面、背面、面部特写或特定状态，保留同一个人和公认的风格；不要假设一张全身照片覆盖所有视角。从公认的设计中建立原创人物；使用可靠的来源描绘真实的人物，而不要虚构身份。选择视角数量、布局和格式进行识别，而不是固定的网格。

一个现有的图像可能包含多个角色。一个被称为 “锚” 的缺失文件本身并不构成差距。当现有作品清楚地涵盖了身份认同和已接受的场景设计时，继续**不要生成新的图像**。如果身份认同仍然不明确，即使创作方向已经得到批准，产品卡也是必要的准备工作。保留提供的脚本、面板和已批准的图像；无论是新的布局还是通用的审美升级，都不应该重复它们。尊重对纯文本作品或减少准备的明确要求，除非是在不明确的真实产品可能被发明或误导的情况下。

### 使用场景锚定开发完整的场景设计

当创意所需的环境、重要变化状态或艺术方向关系缺乏可用覆盖范围时，请准备一个场景锚。具有相当大的创作自由或需要重新设计，可以用它来探索完整的场景提案。展示环境、空间比例、材料、照明、构图、情感和潜在变化；不需要出现人物或产品。仅在对比例或行动关系有用时才包含临时主题，不需要建立人物/产品身份或要求准确的品牌标识。单独的一致性锚将主题身份带入视频制作。最终影片中的产品、标志或中文副本不会对场景图像施加这些准确性要求。

根据图像角色选择模型。对于一致性锚定，优先考虑忠实的人物/产品外观、来源细节和所需视角。对于场景锚定，首先评估当前可用的图像模型，其优势包括装饰或编辑美学、艺术印刷或绘画方向、抽象实验和情绪探索。这是一个软偏好：用户选择的模型获胜；如果特征匹配的路径无法承载场景自身所需的参考或输出约束，则使用一个有能力的替代方案并解释具体原因。同一项目或参考集中的不同角色可能使用不同的模型；主题锚定和场景设计不需要共享同一个模型。

不要仅仅将这些场景设计优势列为可选的替代方案，在默认使用一般标识或逼真模型后。当需要一个新的场景锚定且没有场景特定的硬性需求规则时，将其记录为推荐的首选候选，先评估它，当它满足简要要求时再使用。优先选择纯文本场景设计，并在需要时仅添加必要的参考；不要自动调整产品卡片或角色参考中的每个场景图像。保留准确的产品、人物、品牌标志和指定文本，使其保持各自的一致性来源和最终影片要求。

每张图像在选择镜头或照明之前都需要一个特定的视觉主题：在广阔空间中的小物体可以表达孤立或力量；近距离接触可以传达触感；前景遮挡和远处的明亮区域可以创造发现；相关的形状可以连接两个想法。确定为什么要这样拍摄图像，然后选择其手段。“高级”、“电影效果” 和 “高压” 不能替代这种设计。将[tvc-moodboard-creative-guide.md](references/tvc-moodboard-creative-guide.md)应用于当前的视觉差距。

### Shotloom视觉节奏的设置

对于第一个场景探索，通常从**3-4 个互补视觉状态**开始，根据简短、现有的覆盖范围和商定的范围进行调整；这既不是生成配额，也不是所需的一致性锚定数量。每个添加的图像都应该提供新的发现或有用的对比度。

| 变奏 | Shotloom问题 |
| --- | --- |
| 拍摄比例和主体比例 | 我们是否总是从相同的距离或大小看待主体？ |
| 信息和行动状态 | 每个图像是否都揭示了新的内容，而不是重复同样的展示？ |
| 能量与情感 | 这个场景是否会产生紧张感和放松感，而不是保持一致的紧张或安静？ |

宽视角、中视角和近视角不是轮换时间表；当它带来新信息时，就改变距离。重复的视角对于深思熟虑的状态比较是有用的，但连续性并不需要每张图像都共享它。独立的方案不需要变成网格、固定的镜头列表或等长的视频片段。直接使用提供的分镜；一个可行的书面镜头计划可能就足够了。

为当前模型容量范围内的每个视频选择相关的、互补的输入：一致性锚定提供准确的人物/产品识别，场景锚定提供空间、艺术方向和状态，提示词则解释它们的组合。场景图像中的临时主体不能覆盖经过验证的识别。网格、标签、偶然的背景和不相关的识别不会转移到影片中；普通的引用不会隐含地绑定第一帧/最后一帧。不要仅仅为了将两个角色结合起来而产生额外的完整广告。重复使用合适的结尾图像。仅凭标志就能提供识别，而不是结尾构图：只需准备一个缺失的结尾，将标记放在上部安全区域，置于能够移动的品牌相关背景之上。一个标志性的闭幕图像可以满足所需的品牌曝光要求，但并非对每个场景锚都有要求。除非要求，否则不会有纯白色的静态标志屏，也不会有后续的品牌名称/标志叠加。

## 3. 导演和制作电影

一旦所需的输入可用，就为完整的局部进展写一个独立的提示：构图和深度；特定材料的光线；主题动作和结果；摄像机起拍、路径、速度变化、曝光和着陆；切换和出入提示；精确的拷贝和阅读时间；原创音乐、叙事、福莱和氛围；品牌分辨率。提交时保留最终细节。

对于每个生成单元，在生成之前记录一个独立的最终提示词。实际发送的提示词串必须与记录的最终版本逐字逐句完全相同，这样确认的创意细节才能在提交后保存下来。后续步骤不得缩短、总结、重写、翻译、重新排序或默默润色。如果需要修订，请先在现有决定和授权范围内更新并记录最终版本，然后提交相同的提示词串。如果提示词串不同，请停止提交并解决不匹配问题；永远不要改为发送总结。

从注意力、行动、情感、言语和阅读中选择节奏。密集的插入可以展现广阔的内容；长篇段落可以通过内部发现赢得时间。没有固定的镜头数量、相同的持续时间段或过渡配额。对于选定的效果，使用[product-visual-techniques.md](references/product-visual-techniques.md);对于副本、空间类型、标志包装、产品展示动作或叙述，使用[voice-keyword-typography.md](references/voice-keyword-typography.md)。它包含类型角色、空间绑定、精确文本、标志保护、可读性保持和遗传过渡的标题 - 序列规则。不要预加载不相关的方法。

请阅读[production-and-delivery.md](references/production-and-delivery.md)以了解其性能、范围和连续性。当能够承载影片时，保持一个整合的版本；只有在需要时才在有用的动作边界处分离；每个片段都保留自己的相关参考、声音连续性和完整详细的广告提示。在这里，创意副本与图像一起生成，品牌曝光使用其准备好的图像；通用的后期制作文本默认设置不得悄悄改变约定的处理方式。只有在计划中才使用共享音乐床，不得重复音乐或旁白。

交付实际胶片、完成提示和相关现有/新素材，并保留实际持续时间、尺寸和已知限制。重复使用的素材视为准备；不要为交付产生副本。保留已完成的工作，报告持续时间差异，不要自动再生、修剪、垫片、循环或重新定时以强制实施名义持续时间。
