# 单镜镜头分镜板

本板与 `motion-board.md` 的时间故事版分别建立真实图片节点。两者描述同一镜头，但任务不同：时间板固定身体、道具和机位随时间的连续状态；镜头板让导演读懂观众先看到什么、视线如何转移、谁触发谁的反应，以及景别和构图为何成立。镜头板不是整场跨镜总览；后者只在用户明确要求时走 `sequence-storyboard.md`。

## 先确定本镜节拍

依据镜头卡、原文和角色/场景参考，列出建立、触发、看见、反应、关系改变、收束中**实际存在**的节拍。每格给一个可辨认的新信息或关键姿态，写明主体、位置、朝向、景别、摄影机相对地标的位置、前后景、视线目标、遮挡和光源。第一格对齐本镜入点，最后一格对齐镜尾状态。若节拍少于格数，拆有意义的起势、转折和结果；不能复制站姿凑格。用户指定九宫格时一张图严格为 3×3、从左到右再向下阅读。

本镜没有明示切机位时，所有格子保持同一连续镜头的轴线和空间关系；格间可因本镜已规划的运镜连续改变构图，不擅自切成反打、插入镜头或另一场景。镜头卡或已有机位元数据明确规定的机位、人物站位和朝向优先。相邻镜头只供连续性核对，不画进本板。保持人数、左右顺序、已占座位、关键道具所有者、入口和光向不漂移；心理变化用可见的视线、姿态和反应，不写抽象情绪词代替画面。

## 给图片模型的成品提示词

明确要求“一张完整的多格单镜镜头分镜板”，给格数、布局、画幅和阅读顺序。逐张说明**实际连接**的人物图锁哪些身份和服装、场景图锁哪些建筑与光向、道具图锁什么外形；再给全板一致的成片媒介和每格独有的构图与叙事信息。画面保持项目美术风格；信息条或简短导演标注仅在用户要求且图片模型可可靠书写时出现。用于视频参考的版本不画箭头、路径线、彩色标注或纸张纹理；需要现场批注时另做审阅版本，不覆盖视频参考板。

以真实 `referenceImage` 边连接身份、场景和必要道具，`artifactType` 设为 `storyboard`，标题标明镜号与“镜头板”。读回提示词和 `inputLinkResults`；实际出图后核验格数、格序、角色身份、空间、关键叙事信息与本镜时间板一致。不能用时间板的同一图片或同一节点 ID 冒充镜头板。
