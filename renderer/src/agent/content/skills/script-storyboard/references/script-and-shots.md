# 剧本拆解与镜头卡

先读完用户指定范围。保留原文事实和台词；把自行决定的视觉细节标为“设计”，与“剧本已写明”和“画布资产已证实”分开。已有完整分镜时先核对并补缺，不重复编造一版。

## 拆解顺序

1. **场景**：地点、时间、进出人物、场景开始和结束的状态、复用的物理空间。
2. **节拍**：某个人采取行动、得到信息、改变策略或付出代价；动作和反应之间的因果要可见。
3. **镜头**：按观众需要看到的信息选择景别和切点。建立空间后，追踪视线、动作、表情或证物。一次模型生成只承载能连续拍成的一段；需要切机位、换场或跳时间时分镜处理。
4. **镜头接力**：前镜结束时的动作、视线、物件或声音如何进入下一镜。特别检查入出画方向、手持物与人物站位。

## 每镜工作卡

| 字段 | 应写的内容 |
|---|---|
| 编号与来源 | 场景 ID、镜头 ID、剧本段落或台词范围 |
| 目的 | 这一镜让观众看见的新事实、关系或情绪转折 |
| 人物/资产 | 角色名与稳定资产节点 ID；服装或状态变化版本 |
| 场景/道具 | 场景资产 ID、关键道具资产 ID、空间地标 |
| 站位 | 人物相对门窗家具的位置、朝向、摄影机侧、屏幕左/右 |
| 走位 | 开始位置 → 动作路径 → 结束位置；何时接触或交接道具 |
| 镜头 | 景别、机位高度和角度、取景边界、焦点、主运镜及目的 |
| 光和画面 | 实际光源与方向、时间天气、材质、前中后景、画面重心 |
| 声音 | 原文台词、环境声、动作声；无原文台词时不擅自补成既有事实 |
| 时长与模型模式 | 按台词、停顿和动作估计需要的时长；核对候选模型支持的档位、声音能力和多图参考容量，记录最终选择及退到首帧模式的原因 |
| 接点 | 与上一镜的进入状态、给下一镜的出画/视线/动作/声音线索 |
| 输入与结果 | 计划使用的真实上游节点、图片节点、视频节点与任务状态 |

镜头数量由剧情和模型可执行性决定；不要为了填表强制一个场景拆固定数量。若一场戏只需要两个清晰镜头，就写两个。镜头卡可以存进 Production Plan 的对应工作项，并通过真实节点的标题与计划引用关联；不要创建只供展示的虚假连线。
