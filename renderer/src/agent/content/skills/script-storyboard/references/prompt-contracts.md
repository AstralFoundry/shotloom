# 图片与视频提示词的成品标准

场景、分镜静帧、时间板、镜头板和视频镜头的完整写法以 `visual-prompt-craft` 为准；时间板的格序与动作连续性另读 `motion-board.md`，镜头板的叙事构图另读 `shot-board.md`。本文件保留剧本分镜流程的素材引用与镜头衔接检查。用户、剧本、参考图片和模型目录决定实际内容。不要把字段名或空模板直接塞进生成节点。

## 人物参考图

新建人物身份参考图时，先加载 `character-board`，按其规范写造型与角色板提示词。已有图片时说明“保留参考图中的脸部身份、头发轮廓与固定服饰”，只改变剧情需要的状态。避免用姓名或历史人物标签代替可见外观；模型并不能从“李白”三个字稳定复现此前节点的脸。

## 场景参考图

写清：空间类型和时代、门窗与家具的固定相对位置、入口出口、主要道具所在点、材料与磨损、光源的物理位置和方向、天气/时间、主视角和要留给演员的通道。反向视角若需要另生一张，应说明摄影机换位后哪些物体仍在同一墙面或同一侧。

## 分镜静帧提示词

每镜必须有**具体可见瞬间**：

1. 参考输入职责：人物图锁身份/服装，场景图锁空间/陈设，关键道具图锁形状；哪个参考只作风格，哪个不得改变身份。
2. 景别、摄影机相对空间地标的位置与朝向、机位高低、主体在画面中的位置、前景/中景/背景、视线与留白方向。
3. 人物的实际站姿、手部与道具关系、动作已到达的确定时刻、另一人的反应；写“谁的哪只手做什么”，不写无法静态呈现的连续运镜或长串动作。
4. 光源、阴影方向、时段、环境材质、颜色依据、风格和画幅。必要时写局部不得改变项，例如脸、服装、门窗位置、道具持有人。

## 两张板到视频镜头提示词

进入视频制作的每个 `shot_id` 先建立两个独立的图片节点：一张时间板和一张镜头板。时间板把“起始站位 → 起势 → 路径 → 接触/交接 → 反应 → 收束”变成连续格序；镜头板把观众先看到的信息、主体关系、景别、视线、前后景和空间锚点变成可见构图。两张板必须使用独立提示词、独立真实输入边和独立节点 ID，不能复制同一张图或以一张大宫格图同时承担两种职责。

写视频 Prompt 前记录真实输入的 `{nodeId, type, purpose, order}`。只有实际连接的图片才能写成“参考图”；没有连接的板只能把已核对的事实转译进文字并标记降级。两张板只能作为普通参考，不能冒充 `firstFrame`/`lastFrame`。每条视频 Prompt 只覆盖一个连续镜头；真实切机位、换场或时间跳跃拆成新的 `shot_id`。

视频提示词必须把两张板编译成一条可执行动作链：镜头零时刻的站位和朝向、谁沿哪个地标向谁移动、经过何处、何时说哪句原词、听者何时如何反应、摄影机如何连续运动、镜头末态和下一镜接点。不能只写“参考分镜完成动作”，也不能把多镜剧情堆进一条总提示词。

## 视频镜头提示词

在静帧基础上明确：实际输入图与用途、镜头开始状态、单条主要动作链、人物沿地标的移动路径与结束站位、表情/情绪可见变化、摄影机的一个主要运动及其服务的叙事目的、原文台词/环境音/拟音、镜头结束状态和给下一镜的接点。已有时间板时，按其格序逐段转写关键姿态和动线；已有镜头板时，按其构图重点补足观众信息、视线和主体关系。说明格线、箭头和标注只作导演参考、不得进入成片；两板只有在目录支持额外参考图时才称为视频输入。模型支持时才填写音频、参考视频或首尾帧；对照原文台词与动作所需时间，从目录的真实可选时长中选档，不把 `defaultDuration` 当作每镜目标时长。放不下的剧情需重新划分镜头或安排后续配音，不能删去原词。画幅和分辨率也按目录真实参数配置。一次生成若需要切机位、复杂多人打斗或多次场景变化，就拆镜或降低动作复杂度。

提示词可以细，但不要把整份人物档案、全剧设定或所有镜头复制到每个节点。每镜只携带当前生成必须稳定的具体事实，并让真正的参考图通过输入边进入模型。
