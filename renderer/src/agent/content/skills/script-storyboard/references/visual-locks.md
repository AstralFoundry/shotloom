# 人物、场景与道具的视觉定锚

定锚的目的不是多写形容词，而是让不同节点生成的是同一人物、同一空间。只锁会影响识别或叙事的事实；剧情变化必须记录发生在第几场、第几镜。

## 人物档案与资产提示词

为每位反复出现的人物记录：剧本姓名/别名、现有真实图片节点、年龄阶段与体态、脸型五官、肤色、发型发色、服装层次与材质、鞋靴、固定饰物和标志性姿态。区分**永久身份锚**与**镜头状态**：汗湿、受伤、换衣、手持物、表情会变，但不能因此换脸。未给出的长相是设计选择；若用户提供照片或已生成图，以真实参考为身份依据。

人物参考图应让人物可识别、可在后续镜头引用。为反复出镜的具名角色新建身份资产时，先按主 Skill 的路由加载 `character-board`，由它确定四区域版式和具体造型提示词；这里仅维护人物身份锚与镜头状态的区分。已有可用人物资产时复用，不重复生成相似但身份不一致的新人物；用户提供的参考图或明确版式优先。

## 场景档案与固定关系

记录门、窗、主要家具、走廊或街道方向、关键道具位置、可拍摄区域、固定光源及时间天气。描述**物体之间**的关系，而非只写“古风书房”：例如“门在书案左后方，窗在书案右侧墙，灯位于桌面靠窗端”。逆向机位可能改变画面左右，但不能改变门窗实际所在墙面。

重复场景可先建立空场参考图，再按镜头需要补反向视角；一次性过渡场景若文字描述足以保持一致，不必额外生图。分镜节点引用场景图时，明确它约束的是空间、陈设、材质与光线，不覆盖人物身份或当下动作。

## 道具状态

只有推动剧情、影响动作交接或必须跨镜一致的道具才建立独立资产。记录外形、尺寸、材质、所在位置和当前持有人；交接后更新状态。普通背景摆件可留在场景档案，不为流程完整而增加节点。
