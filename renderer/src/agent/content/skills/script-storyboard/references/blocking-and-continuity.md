# 人物站位、走位与跨镜连续性

站位先用场景的固定物体描述，再翻译成画面左右。不要只写“李白在左、杜甫在右”，因为反打后屏幕左右可能改变。

## 站位草图的文字格式

```text
场景 S1：门在北墙西端，窗在东墙，书案居中；案后有一把椅子。
动作轴线：书案南北向；李白在案南侧，面向北；杜甫在案北侧，面向南。
镜头 A：摄影机在轴线东侧朝西北拍；李白画面左前景，杜甫画面右中景。
走位：李白从案南侧向东绕半步，把诗稿放到案东端；杜甫停在案北侧，右手拿起诗稿。
镜头 B：仍在轴线东侧反打；沿用诗稿在案东端、杜甫右手持稿的事实。
```

以上只是字段示例，不是必须采用的剧情或场景。真实镜头应根据剧本和生成模型的动作能力简化路径。

## 检查关系

- **人物**：谁与谁相对、距离如何变、手势从哪只手开始、谁看向画外的哪个方向；情绪变化需要可见动作承载。
- **镜头**：相邻镜头的镜头轴线、视线方向、入出画方向和构图重心是否能接上。需要跨轴时设计一个空间建立镜头、人物换位或清晰的轴线重置，不让观众误以为换了位置。
- **场景**：门窗家具与固定光源保持真实位置；摄影机反向只改变屏幕投影。不同时间段的天气和光线变化有剧情或时间依据。
- **道具**：谁拿着、放在哪里、何时被拿起或交给谁。动作特写、反应镜头和下一镜不得让物件瞬移。
- **任务结果**：视觉参考图本身可能画错上述关系。检视真实图片后，若关键位置或身份漂移，先修正这张图或改提示词，不把坏参考继续传给下游。

为每个镜头保留“进入状态”和“离开状态”；下一个镜头若承接同一动作，必须继承上一个镜头的离开状态。跨场切换则写明新场景、新时间或叙事线索，避免把连续性要求错用在非连续镜头上。
