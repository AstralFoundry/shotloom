# 跨镜头分镜页（九宫格）

这是**一张图片里的多个不同镜头**，用于阅读一场戏的镜头顺序、景别变化和人物关系。它与 `motion-board.md` 的**一镜之内多个时间姿态**是两种产物。只有用户明确要求整场或整集的跨镜总览页时才用本文件；通常的“逐镜九宫格”“多宫格分镜”走单镜时间板与镜头板，不要把已有的逐镜单图节点数量当作宫格，也不要把一张单镜动作图当作整场戏的分镜页。

## 排格前

从剧本与现有镜头工作项提取连续的叙事节拍。先决定每格对应哪个镜头或哪段相邻镜头的代表性画面，再写清该格的镜号、原文动作、出镜人物、景别、机位、画面左右/前后、视线、道具状态、与上一格的可见变化。一个格子只能呈现一个可见时刻；跨格允许真实切镜、反打和景别变化，但角色身份、服装、场景布局、轴线和剧情顺序仍须连续。对白、`os`、`vo` 保留在镜头工作项与视频提示词里，格内仅画对应表演或听者反应。

用户指定九宫格时写成**单个 3×3 图片节点**，明确从左到右、从上到下的 1–9 格；每格都有不同的具体画面和叙事作用。用户给的剧本超过九个镜头时，按连续戏剧段落分成多张分镜页，或让一个格子承载一组镜头的代表性关键画面并在工作项保留映射。选择取决于能否让观众读懂整段事件，不能机械地为凑九格重复相同姿态、挤进太多人或遗漏后半段。若一页无法覆盖全剧本，继续做下一页，不因页数未指定而停下追问。用户只给一个镜头且明确要该镜动作九宫格时，则走 `motion-board.md`。

## 图片节点的成品提示词

开头写明“生成**一张完整的 3×3 跨镜头分镜九宫格**，九个有清晰边界的画格，不是九张散图，也不是一个主画面加装饰小图”；给整图画幅和阅读顺序。接着写共享的画风、角色参考图的身份/妆发/服装、场景参考图的建筑与空间、固定的出入口和光向。按格序逐格写能直接绘制的事实，例如机位位于哪个地标一侧、景别、谁在画面何处、身体朝向和目光、动作的当前姿态、谁或什么成为视觉焦点、与上格发生了何种信息变化。逐格内容必须来自本剧本，不把“建立—冲突—高潮”这类抽象标签当作画面。

分框大小一致、每格画面可读；不要让一格铺满整张图。图片模型若难以稳定写对镜号、对白或导演术语，优先画清画面，把精确镜号与格序映射放在 Production Plan 的工作项或相邻文本说明，不用乱码文字冒充交付。导演动线只在确实有走位或运镜需要表达时用细箭头，箭头贴合该格人物的起止位置，不遮脸；跨格切镜不画成同一机位的连续运动。不能把九格分别写成九次 `canvas_create_node` 调用来替代单个多格节点。

## 画布与视频关系

用 `inspect_model_catalog` 核实图片模型的参考输入容量；一页连接实际出场且可辨认的人物身份板、场景图和必要道具图。参考数量超出容量时，按镜头段落拆页或用由真实资产派生的复合参考，不能悄悄删掉关键身份。创建 `imageGeneration` 节点、设置 `artifactType: storyboard`，标题标明场次与覆盖镜号，例如“紫霄宫大殿｜分镜九宫格 01｜镜01–09”。把上述完整成品提示词写入节点并连接真实 `referenceImage` 边；读回节点与 `inputLinkResults` 核验，不只在聊天里描述分镜页。执行权限关闭时节点保持 `idle`，只能报告“九宫格已配置、图片尚未生成”。

跨镜头分镜页服务导演审阅和连续性，不是视频的干净首帧。后续每个视频节点仍须按本镜选用正确的单镜参考、人物板和场景图；若模型可安全接收分镜页作普通 `reference`，在视频提示词明确指定使用哪一格的构图，并要求成片不出现分框、箭头和纸张。模型不能可靠从整页取单格、参考容量不足或只支持首帧时，另用相同资产建立本镜干净关键帧，不把九宫格直接接入 `firstFrame` 或 `lastFrame`。

已实际出图后查看真实图片：必须有正确数量的画格、明确边界、顺序正确且每格有不同镜头信息；检查人物外貌与衣着、场景结构、座次、道具和屏幕方向。若模型画成一张单画面、格数错误或重复同一姿态，修订原节点提示词/参考后重试，不能以成功任务回执宣布九宫格完成。
