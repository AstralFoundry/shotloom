# 单镜动作宫格

从剧本制作视频时，每镜建立一张多格时间故事版，并另建一张 `shot-board.md` 的镜头分镜板；只分析或只写文字时按用户要求停止在相应阶段。九宫格为一个节点生成的一张 3×3 图，不是九个节点。格子是同一连续镜头的时间关键姿态，不把相邻镜头或场景拼进来。

时间板固定同镜头的动作顺序，镜头板服务构图与叙事阅读。两板分别建节点，不用一张图冒充两种；这里使用 Shotloom 的真实画布节点与 Production Plan，不引入外部项目的策略字段或脚本。

## 先定逐格事实

从本镜原文提取起始、触发、动作、发现、反应与收束。每格写具体可见增量：具名人物在画面左/中/右、前/中/后的位置，身体和脸朝向、视线目标、支撑脚、手与道具、摄影机状态。移动者写起点、经过地标、入出画边和终点；未移动者保持原位和独立注意。第一格对齐本镜零时刻，末格对齐镜尾接点。自然节拍不足时拆有意义的起势、转折与结果，不复制站姿或改动剧情凑格。对白按起声、说话中、说完安排口型和听者反应；OS 不开口，画外 VO 不凭空入画。

固定同一人物身份、服装、场景结构、座次、人数、道具数量和光向。座具已被占用时不能再画空置副本；特效要固定发出者、轨迹和目标。默认同一机位、轴线、景别和背景关系；只有本镜明确运镜或已有机位元数据时，才沿一条连续轨迹改变构图。director_shot.active_camera 或 composition_reference.primary_camera 若存在，优先决定机位和站位；其他绑定机位只供连续性核对。没有这些字段时依据剧本和参考图设计，不因此停工。neighbor_panel_continuity 只用于衔接，不带入邻镜事件。

## 写入图片节点

成品 prompt 依次写：一张图的格数、布局、画幅和阅读方向；实际连接的每张人物、场景和道具参考分别锁定什么；共享画风、服装、空间与机位；按 cellIndex 或自己从原文拟出的格序逐格描述画面；本镜的关键排除项。禁止把占位符或原始 JSON 直接留给图片模型。参考图上的身份标签只供识别，不画进格内；群众、道具和背景与主角使用同一媒介、描边、材质和光影。

给视频模型作参考的时间板保持成片画风，格内不画箭头或导演批注；动线路径在格序和视频 prompt 中写清。用户要现场审片标注时，另建审阅版本：红色细箭头表示人物/道具，绿色表示视线，蓝色表示有证据的摄影机运动；箭头贴合起止位置，不遮挡主体。用户要求黑白线稿工作纸时仅用于审阅版本，不覆盖视频参考板。需要信息条时仅写可靠的镜号、景别、机位、运镜；文字生成不稳则把准确术语留在工作项，禁止乱码。画面不加对白气泡、水印或无关 UI。

用图片模型支持的 referenceImage 输入边连接真实角色、场景、道具节点，artifactType 设 storyboard。读回 prompt、格数和 inputLinkResults，修复失败边。节点运行关闭时状态如实为 idle；实际出图后看格数、格序、身份、座次、道具、轴线和每格增量，错误在原节点修正。

## 给视频使用

带格线、箭头或信息条的宫格不是 firstFrame/lastFrame。模型可安全接收时，作为普通 reference，并在视频提示词指明格序只表示时间姿态，成片是一幅连续画面，不出现宫格、纸张或标注。若标注易烧录，可沿同一格序与参考资产另做无箭头、无批注的成片画风版本；容量不足或模型不能可靠解读时，改把动作顺序写进视频 prompt，不能声称宫格已传入。首尾帧模式另用无标注的干净起止帧。视频提示词继续写具名人物路径、台词与听者反应、机位及镜尾状态，不能把宫格本身当作全部运动说明。
