# 剧本分镜导演

`/script-storyboard` 的交付是画布上的真实节点、输入边和逐镜提示词。计划用于续行，不代替产物。先查已有节点与工作项，修缺项和失败边，不重建整套资产。用户明确要求制作时连续推进；生成执行仍遵守用户设置和模型能力。

## 按阶段读取

| 阶段 | 读取 | 本阶段产物 |
|---|---|---|
| 资产 | `character-board`；需要空间/造型细节时读 `references/visual-locks.md` 和 `visual-prompt-craft/references/image-direction.md` | 可复用的人物、场景和必要道具节点 |
| 拆镜 | `references/script-and-shots.md`、`references/blocking-and-continuity.md` | 每镜镜头卡：原文范围、人物站位、动作、机位、时长意图和前后接点 |
| 分镜图片 | 每镜读 `references/motion-board.md` 与 `references/shot-board.md`；落地时读 `references/canvas-delivery.md` | 每镜两张用途不同的多格图：时间板固定同镜动作顺序；镜头板固定叙事重点与机位构图 |
| 视频 | **必须加载** `short-drama-video-prompt`、`references/canvas-delivery.md` | 依据实际参考和模型能力配置的视频节点、提示词、时长及输入边 |

不要一开始读取所有 references。只有用户明确要求一场戏的跨镜总览页，才读 `references/sequence-storyboard.md`；它不能替代任何一镜的时间板或镜头板。若用户只要求分析或文字分镜，做到请求的阶段；若要求从剧本制作视频，则每镜继续完成上述产物。

## 逐镜控制循环

1. 通读剧本并核对已有真实角色、场景、道具。原文事实、已存在资产和自行设计的视觉细节要区分；角色与空间锚点在下游复用。
2. 把剧情拆为可连续生成的单镜，记录本镜入点、主要因果动作、出点、原词、OS/VO、站位与画面方向。相邻镜头的镜尾和镜首要能接上。先按对白、动作、停顿估时，再从模型目录选真实时长档位。
3. 默认先用角色图、场景图和单镜关键画面完成视频 Prompt。只有用户明确要求多格故事版，或本镜确实存在人物进出、长距离走位、转身、施法、交接、追逐、多人错峰反应或复杂连续运镜等动作风险时，才创建时间板；只有构图、视线、前后景或主观视角存在独立风险时，才创建镜头板。两板都需要时才分别创建，不能为了流程完整强造 3×3。指定九宫格时才使用单个 3×3 图片节点；未指定格数时由镜头节拍决定，不自动默认为 3×3。
4. **写入视频节点前先调用 `skill(name="short-drama-video-prompt")`。** 视频提示词根据实际存在的角色图、场景图、关键画面、时间板或镜头板编译：写清谁从哪里走到哪里、何时说哪句、谁如何反应、摄影机如何运动以及镜尾状态。检查多图参考模式；格线和标注不接 `firstFrame`/`lastFrame`。逐镜估时，不能整批沿用默认 5 秒。没有先加载该 Skill，就不要直接用通用模板创建视频节点。
5. 读回节点、提示词、时长、`inputLinkResults` 与实际媒体。记录每镜真实节点 ID 和任务状态；缺图、缺边或质量失败只修对应镜头。仅按成功回执报告“已配置”“已生成”“已核验”的真实范围。
