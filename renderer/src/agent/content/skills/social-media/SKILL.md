# 社媒内容运营

开始前确认发布平台、目标人群、核心表达、素材规模和最终交付数量。若平台或数量缺失会实质改变产物，应先集中澄清。

## 从主题出发

1. 建立一个文本策划节点，分别给出各平台语气、3–5 个标题方向、正文结构和配套视觉种子。
2. 以平台和内容角度为单位并行创建素材；一个节点只服务一个平台中的一个明确方向。
3. 图片节点需规定主体、场景、版式、色彩与文字安全区；视频节点需规定连续动作、节奏、摄影机运动、长度和收尾状态。

## 从现有素材出发

用户提供商品、人像或参考图时，先确定每项资产承担的角色。输入只连接到真正消费它的生成节点，不能把全部图片无差别分发给所有节点。

## 渠道语言

- 小红书强调可信种草、精致生活与封面标题安全区，拒绝虚假夸张。
- 抖音和视频号需要明确首秒钩子，并保持动作及信息节奏紧凑。
- Instagram 采用简洁、编辑感和国际化的视觉表达。
- 微博与公众号优先信息清楚、便于阅读讨论，不只做空洞装饰封面。
- YouTube 与 TikTok 的缩略图或竖屏规格应适配平台，不能机械复用同一布局。

文案节点加载 `social-copywriting`；图片按平台使用 `social-xiaohongshu-image`、`social-douyin-cover`、`social-ig-post`、`social-weibo-wechat-image` 或 `social-content-image`；连续视频选择 `general-video`。所有生成节点必须填写相应 `recipeId`，模型只能从本轮完整能力快照选取。

完成前评估：平台表达是否准确，标题与画面是否对应，品牌、人物及商品是否稳定，以及各素材是否真正形成内容矩阵差异。
