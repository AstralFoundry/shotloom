# 未来科幻电影生成器

使用这项技能制作一部超真实的未来科幻短片。这项技能中的每一个视觉输出——包括角色素材、物种素材、道具素材、场景锚、四视图表、分镜网格、镜头参考和最终视频——都必须使用逼真的好莱坞科幻大片视觉语言，除非用户明确要求进行其他处理。它协调创意开发、可重复使用的角色/场景/道具素材、素材绑定的分镜、分段视频生成和有序组装。将每个用户确认的故事、角色、场景和参考视为权威；保留任何用户未要求更改的内容。

## 第 1 步：锁定创意简报

1. 捕捉故事前提、主人公、核心事件、世界逻辑、语气、结局、语言、持续时间、段落计数、宽高比和物理媒介。
2. 如果用户给出了视觉方向，可以将其转化为灯光、颜色、空间、材料、氛围和比例的可执行规则。否则，可以提供四张卡片：硬科学深空探索、史诗太空歌剧、荒原遗迹科幻和外星有机生态。
3. 如果用户没有选择方向，请使用克制的超现实主义科幻电影，而不是默默地从四个主题中选择一个。
4. 锁定已确认的方向、非赛博朋克基线、16:9 景观格式、持续时间、段落计数、叙事语言和物理媒介。默认缺失持续时间为 60-90 秒和 4-6 个段落，每个段落 10-15 秒。
5. 确认故事梗概，以及结局是否需要转折。开场三秒必须通过冲突、异常或悬念来呈现；梗概必须确立主角、事件、世界逻辑、基调和段落数。

## 第二步：识别参考素材和角色

1. 将提供的媒体分类为人物、场景、道具、分镜、参考视频或参考音频。只提取可观察的事实：面部特征、头发、衣着、比例；空间结构、材料、家具、光源、天气；或运动、摄像机、节奏和声音。
2. 根据已确认的剧本，在素材生成之前制作一份详尽的演员阵容清单。包括银幕上出现的每一个人类、机器人、机器人、外星人、生物、智能物种、类似动物的生物以及其他物种，这些物种可以在参考素材中看到，也可以通过幕外关系或事件驱动故事发展。任何出现的角色或物种都不得遗漏。
3. 对于每个清单条目，记录名称/代码、物种或身体类型、叙事角色、关系、权力/情感状态、冲突/共同目标、场景/段落和跨段落外观要求。在创建角色素材之前，请获得用户对这份完整清单的确认。
4. 将用户提供的角色或物种直接引用到匹配元素，并保留核心身份和设计。除非明确要求，否则不要重新设计它们。
5. 为每个确认的库存条目生成一个单独的独立角色素材，包括非人类物种和外星生命形式。不要仅仅为了方便而将不同的角色或物种合并到一张纸上。每个新角色都是一个独立的白色背景素材。基础肖像是一个正面朝上的 9:16 上身图像，外观描述简明扼要；不要添加场景、额外的人物、故事情节或装饰环境。用户提供的参考资料可能会保留其原始背景，除非明确要求提供干净的白色背景版本。
6. 确认所有角色和物种基本特征后，按照固定的从左到右的顺序生成一个 16:9 的四视角角色表：胸部特写、全身正面、全身侧面、全身背面。保持身份、服装、面部特征和比例完全相同。
7. 为道具和其他单一主题元素创建单独的白色背景素材，具有完整的轮廓、可信的材质和稳定的比例。

## 第 3 步：构建场景锚

1. 只有在接受角色/四视角资源后，才能确认场景设置。
2. 对于每个场景元素，首先制作一个空白的 16:9 场景概念图像。如果没有场景参考，则使用文本到图像；如果有场景参考，则使用图像到图像。这张图像是空间结构、材料、天气/生态、颜色、光线方向和风格的评审锚。
3. 仅对这个场景概念图使用Midjourney V7。其提示主体必须是一个连续的正面英语描述，仅包含中文字段标题，且不能有负面提示或单独的禁止块。
4. 用户批准场景概念后，根据批准的图像生成一张 16:9 4K 2x2 场景四视图表。四个视图分别是：中心前轴、左前方 45 度、右前方 45 度，以及向外看的最深/后视图；对于仅包含外部景观的场景，将第四个视图替换为远至前景的中心视图。
5. 所有四种视角都必须描绘相同的空白位置、时间、天气/生态、光线方向、比例、材料、颜色和风格。场景单上不得出现人物、轮廓、反射、阴影、带有人物、事件或活动的屏幕。
6. 将批准的四视图表作为最终场景素材进行绑定。在确认之前，不要继续使用素材绑定的分镜脚本。

## 第 4 步：写分镜脚本和可选草稿

1. 写一个 100-200 字的核心概要，然后制定一个严格的时间线。对于长达 60 秒的项目，使用 4-5 个段落；对于 90 秒的项目，使用 6-10 个段落。每个段落包含一个镜头和一个视频片段，最长 10-15 秒。总持续时间、段落计数、镜头计数和视频片段计数必须匹配。
2. 将每个段落保持为一代任务。内部 3-4 秒的节奏可以组织行动和情感，但不能成为额外的镜头。
3. 喜欢中景、近景和特写。只有在叙事上需要深空尺度、纪念碑式建筑、荒地隔离或外星生态的情况下，才使用广角或极广角视角。
4. 在每个段落中明确引用绑定元素。描述环境、光源、物理介质、可见动作、情感、情节事件、效果以及进入下一段的过渡。精确保留批准的事件顺序。
5. 对于六个段落的短片，为每个段落创建一个推荐的分镜图像，使用 12 面板网格，最好是 3×4 或 4×3 布局，带有明确编号的面板。这 12 个面板应该展示段落的内部视觉节奏、连续性线索、人物动作、摄像机进度以及进入下一个段落的过渡。使用与短片相同的超逼真好莱坞科幻大片视觉语言渲染所有分镜面板：现场动作摄影的真实感、电影制作设计、物理上可信的材料、光源照明、受控色彩和特写电影级别的构图。不要默认使用黑白铅笔、粗略草图、卡通、动画、游戏 CG 或未完成的概念艺术处理。不要添加对白字幕。十二面板显示改善了连续性评论，但不会改变单段/单镜头/单视频片段的关系。对于段落数不同的项目，请使用当前简报或工作流程明确要求的分镜网格大小。
6. 在制作昂贵的视频之前提交分镜进行确认。如果用户请求发生变化，只需修改受影响的资源或段落，并保持所有其他已确认的模块保持不变。

## 第 5 步：编译提示词并生成视频

1. 在最终视频生成之前，请用户选择预览第一个镜头或生成所有视频片段。如果选择预览，请仅生成第一个镜头并等待批准。
2. 默认情况下，通过标准视频生成路径使用MiniMax-H3，每个片段保持其分镜持续时间 16:9，并使用工作流程的锁定分辨率。如果用户明确选择了其他模型，请先检查其功能，并在兼容时遵循该选择。将角色、批准的场景四视图和必要的道具资源以其绑定角色传递；每个镜头使用的参考图像不超过 9 个。
3. 仅当连续性真正依赖于先前的动作、取景或摄像机运动时，才使用前一个最终镜头作为视频参考。它绝不会取代角色或场景参考。
4. 按以下顺序编写提示：主题/素材、场景/空间、可见动作和情感、摄像机/构图、光源和物理媒介、锁定风格、约束条件。使用`<<<image_N>>>`占位符作为图像参考。
5. 所有非场景概念提示包括：无字幕、无水印、无文本、无卡通、无动画、无游戏 CG，以及无塑料 3D 渲染外观。每个视频提示都不包含背景音乐和字幕，但默认情况下不得禁止对话。如果存在对话，请输入说话人物和准确的台词，同时为表演、口型同步和环境音效留有空间。
6. 保持所选风格的连贯性。不要使用霓虹灯、高饱和紫/粉/洋红/蓝光污染、全息界面、控制论体或被雨水浸透的网络朋克街道作为默认快捷方式。外星生物发光必须是局部的、柔和的、生物来源的，并且仅限于其可见生物体。
7. 如果生成失败，仅重试失败的片段，并对诊断原因进行实质性修正，同时保留已确认的身份、场景、持续时间、纵横比和事件顺序。然后，如有必要，切换到另一个兼容的可用模型；不要反复强制使用同一模型或重新生成成功的片段。

## 第 6 步：组装和呈现

1. 按照批准的时间线顺序组装最终镜头。通过动作、凝视、光线方向、颜色或环境媒介保持段落结束和下一段落开始的连续性。
2. 使用直接切换、动作匹配、光线连续性或简短的环境声桥；避免无动机的效果转换。
3. 等级和声音根据锁定风格设计最终作品：机械和受控的适合深空，庄严的适合太空歌剧，灰尘和风雕刻的适合荒野，或潮湿和有机的适合外星生态。独立的音频可以支持节奏和情感，但不能与对话或环境声音相冲突。
4. 除非有明确要求，否则不要添加后期制作中的霓虹灯污染、全息 UI 效果、控制论身体图像或雨夜街道氛围。
5. 提交最终组装的胶片和任何明确要求的中间资料。在项目画布上的每一个所需输出都可用且可用之前，绝不要声称已完成。

## 风格规则

- 硬科学深空探索：可维护的航空航天结构，实用的舱室点灯，磨损的钛，反光太空服，仪器显示，冷对比度控制，以及物理上合理的浮尘。
- 史诗般的太空歌剧：宏伟的极简主义/粗野主义建筑，巨大的负空间，庄严的自然光，风化的石头，沉重的哑光金属，保护性织物和干燥的飘浮尘埃。
- 荒原遗迹科幻：侵蚀的技术废墟，刺眼的阳光，散落的沙粒，生锈的钢铁，风化的装甲，磨损的皮革，龟裂的表面，以及克制的尘土色调。
- 外星有机生态：内部一致的有机结构、植物/真菌、湿润表面、半透明的静脉、水滴、角蛋白鳞片、折射和局部生物光。
- 默认或自定义方向：使用用户确认的可见规则，包括逼真的材质、源光照明、深黑色、受控饱和度和清晰的叙事空间。避免将赛博朋克信号视为未来科幻小说的默认定义。

## 输出契约

使用 Markdown 标题和固定模块顺序；不要使用表格。面向用户的描述和所有生成提示词主体为中文，但Midjourney V7 场景 - 概念提示词主体为英文。保留模型名称、工具名称、素材标识符和`<<<image_N>>>`字面意思。不要将创作者或现有影片名称添加为执行说明。所有决定都是逐步确认的；不要在中间检查点后自动运行整个流水线。
