# 邮戳照片动态

这项技能将用户提供的照片转化为三步视觉工作流程：朴素的平面插图风格、混合风格的邮戳复合，以及固定镜头运动版，其中场景动画化，但邮戳框架和风格分割保持稳定。它专为需要强烈空间对齐的混合媒体拼贴场景设计，特别是当相同的建筑、地平线或路线线必须跨越邮戳边界时。

## 步骤 1:重新风格化源照片

使用用户上传的照片作为源图像，并将其转换为韩国朴素平面插图。

### 目标
- 保留场景内容和粗略的空间布局。
- 保持相同的物体、主要结构和整体构图。
- 将照片转换为孩子气、有趣的平面插图风格。

### 视觉规则
- 使用粗糙、摇晃、破损的手绘黑色轮廓。
- 去除摄影光照、阴影、透视深度和表面纹理。
- 将所有阴影区域替换为实心平面色彩填充。
- 将物体简化为圆润的几何形状列表。
- 保持构图清晰可读且可爱，带有一种天真和俏皮的感觉。
- 结果应该看起来像原始场景的平面插图版本，而不是一张追踪照片。

### 输出
生成重新设计的图像作为下一阶段的视觉参考。

## 第 2 步：构建邮戳复合材料

使用原始用户照片作为基础图像，并在中间插入邮戳相框。

### 目标
- 将基础图像保持在邮票框之外，保持其原始的摄影风格。
- 将步骤 1 的插图样式放入邮票框内。
- 对齐内外场景，使共享的建筑物、地平线、道路、铁轨或其他主要结构水平匹配。

### 视觉规则
- 邮票框架必须居中且清晰可见。
- 邮票边缘应感觉像一个真实的穿孔邮票边缘。
- 出现在邮票内外的相同场景元素应保持水平对齐。
- 不要让两种风格相互混淆；保持一种可见的风格分离。
- 保持外部区域忠实于原始照片，内部区域忠实于插图风格。

### 输出
生成一个具有稳定印章叠加的合成静止图像，并明确区分内外部视觉风格。

## 第 3 步：为合成图像添加动画效果

使用步骤 2 图像作为动作生成的源。

### 目标
- 使用固定摄像机。
- 自然地激活场景内容。
- 保持邮戳帧静止。
- 保持内部风格不变。
- 保持外部风格不变。
- 让场景根据图像内容移动：火车可能移动，小动物可能移动，树叶可能飘动，水可能泛起涟漪，行人或车辆可能轻微移动。

### 运动规则
- 运动必须来自图像内容本身，而不是来自任意的运动效果。
- 如果一个物体越过印章边界，两种样式必须同时保持可见。
- 不要变形、漂移或溶解图章框架。
- 不要将内部风格和外部风格融合在一个视觉效果中。
- 保持固定的空间分割，同时允许自然的场景移动。

### 输出
制作一个简短的动画视频，其中场景在移动，但邮票构图保持锁定且视觉上清晰可辨。
