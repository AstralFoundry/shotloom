# 商业广告影片

先确认商品图片、品牌资料、目标受众、投放渠道、视频长度和转化目标。商品身份或渠道画幅缺失且会改变结果时，需要先澄清。

## 制作流程

1. 商品证据：整理可验证卖点、外观识别点、典型使用情境、受众痛点和不可改变的品牌元素。
2. 创意命题：确定核心承诺、叙事钩子、情绪曲线、视觉母题与行动号召。
3. 广告脚本：依总时长拆镜，逐镜标明传播任务、台词或字幕、商品动作、景别、运镜及转场。
4. 视觉规则：在广告脚本和后续分镜 prompt 中统一配色、材质、照明、文字层级与节奏。当前 Skill 没有独立风格图 Recipe，因此不建立此类节点。
5. 分镜与定帧：一个镜头对应一张独立画面，商品外观必须忠实于参考。
6. 连续镜头：等待分镜或关键帧完成后建立视频节点并连接主关键帧；若商品包装、标识、外观或关键场景没有被该帧充分呈现，应在模型能力范围内补充商品图或场景依据。每个节点只生成一个连续镜头，提示词逐项写清参考职责、商品动作、环境反馈和收尾状态；内部输入适配由运行时自动完成。
7. 声音内容：按需要创建配音、音乐和拟音，使节奏与镜头时长匹配。
8. 画布整理：由本 Skill 先确定脚本次序，再把明确的镜头和声音节点交给 `canvas_layout_nodes` 整理；布局工具不从标题猜广告结构。代码没有剪辑时间线或最终汇总节点，不能虚构入口，也不能用无意义连线表达顺序。

## Recipe 对应关系

- 创意命题：`video-ad-creative-outline`
- 全案脚本：`video-ad-brief`
- 分镜总览与高清帧：`video-storyboard-grid`、`video-frame-extraction`
- 连续广告镜头：`video-clip-generation`
- 配音、音乐与拟音：`video-audio-design`

## 商业约束

- 卖点只能来自用户资料或可见商品证据，不得杜撰参数、认证和功效。
- 视觉冲击应服务商品与品牌，拒绝无关赛博特效、廉价贴纸和大字压屏。
- 每个镜头承担一个主要传播任务，不让所有镜头重复全部卖点。
- 按投放渠道确定画幅与节奏，模型和参数从本轮能力快照选择。
- 主关键帧不能普遍替代商品身份。商品特写、包装旋转、多人使用和严格品牌镜头应保留必要直接参考；只有低风险且已核验融合完整时才单独使用主关键帧。输入数量由镜头风险决定，不能设置固定下限或无差别堆图。
- 每个生成节点按上表加载唯一 Recipe 并写入 `recipeId`。

完成前评估：商品一致、卖点真实、首秒钩子有效、信息逐步推进、品牌语言统一、镜头和声音节奏匹配、行动号召清楚。
