# 模仿对象视频

当用户提供一个人在没有物理道具的情况下表演的视频，外加 1-3 个参考对象图像，并且想要一个增强视频，其中参考对象出现在指定的身体部位时，请使用这个技能。核心承诺是：自然地添加对象，但保持原始视频中的人物、场景、摄像机、时机、动作和整体连续性不变。默认使用MiniMax H3。如果用户明确选择了另一个模型，请检查其功能并遵循该选择；如果失败，请重试一次以确定诊断原因，然后切换到另一个可用的模型。

不要将这项技能用于一般对象替换、完整场景重新设计、产品广告、对白字体包装、仅字幕编辑或从文本生成通用视频。如果用户想要一个新的脚本化广告，请转向更广泛的视频或广告工作流程。

## 第 0 步：收集所需输入

所需输入：

1. 来源视频：一个上传的或画布视频，展示原始非道具性能。
2. **物体参考**:1-3 张要插入的物体、产品、配件、服装或道具的图像。
3. 目标附着区域：物体应该出现的身体部位或区域，例如手、手腕、头部、脸部、肩膀、躯干、腰部、脚、背部或 “两手之间”。
4. 预期互动：如果不明显，请询问是否应该持有、穿戴、附着、漂浮在身体附近、携带或跟随某个手势。

如果缺少任何必要的输入，请仅询问缺失的项目。除非用户明确要求提供字幕，否则不要询问字幕。

可选输入：

- 所需的输出宽高比或平台。如果省略，请保留源视频的宽高比。
- 参考对象是必须完全复制还是仅在视觉上匹配。默认值：自然忠实匹配。
- 是否应该保留原始音频。默认值：当源视频有有用的音频时，保留原始音频。

## 步骤 1:分析源视频和引用

分析源视频的目的：

- 可见人数和主要演员。
- 身体部位的可见度、运动范围、遮挡和接触机会。
- 摄像机运动、取景、时机以及任何运动模糊。
- 场景照明、透视、阴影和背景连续性。
- 目标身体部位是否足够可见，以便进行所需的插入。

分析物体参考信息，用于：

- 物体类别和预期用途：手持道具、可穿戴物品、安装在身体上的物品、携带物品或附近物体。
- 必须保持可识别的主要可见结构和轮廓。
- 附着逻辑：它在哪里接触身体，如何被握住/穿戴，以及哪个部分应该面对摄影机。
- 如果多个参考图像显示相同的对象，请将它们视为具有多个视图的单一对象标识。如果它们显示不同的对象，请询问用户是想要一个选定的对象还是多个插入的对象。

除非用户用文字说明颜色，否则不要将颜色转换为提示文本。让参考图像以视觉形式呈现颜色和纹理。

## 第 2 步：生成前验证可行性

在进行任何昂贵的视频生成之前，请检查：

- 目标身体部分在剪辑中出现的时间足以支持效果。
- 请求的物体可以在物理上适合目标区域。
- 这种互动不会与原始动作相矛盾。例如，一个大型双手物体需要两只可见的手或一个清晰的搬运姿势。
- 源视频的原始身份、场景、摄像机和动作应保持基础；编辑不得重新设计人物、服装、背景或镜头。

如果请求模棱两可，请提出最短的阻塞问题。例如：

- “物体应该握在手中还是绑在手腕上？”
- 这三幅图似乎显示了不同的物品。应该插入哪一个？
- “请求的身体部位大部分都被遮住了。我是否应该将物体放在附近可见的区域？”

## 第 3 步：创建编辑简报

创建一个紧凑的编辑摘要，优先考虑保存：

1. **来源不变量**:保留原始演员身份、面部表情、服装、头身比例、场景、灯光、摄像机、时机、动作和拍摄节奏。
2. 物体插入：将参考物体以正确的尺寸、透视、握持/穿戴/接触、阴影、遮挡和运动跟踪插入到指定的身体部位。
3. **参考保真度**:保持物体的可识别轮廓、部件、材料线索和功能细节不被引用。
4. **不得进行不必要的变更**:不得添加新人、更改背景、更换服装、改变姿势、改变摄像机运动或引入不相关的道具。

对于简短的请求，保持最终编辑提示简短且接近用户的措辞，只添加必要的保存和联系限制。

## 步骤 4:选择制作路径

使用能够保存源视频的最短可用路径。首选MiniMax H3 作为此技能的默认制作模型：

- 如果任务可以一次性解决，并提供源视频和图像参考，请选择基于**MiniMax H3**的编辑路径。
- 如果 H3 或所选路径需要视觉锚点，首先从代表性的源帧和对象引用中创建一个静止的对象放置参考帧，然后将其用作视频编辑的指导。
- 如果编辑必须保留原始音频，请先生成视觉编辑，然后在需要时将原始音频调回。
- 除非用户明确要求使用其他平台格式，否则请保留源宽高比。

不要将其变成一个完整的多阶段工作流程，除非用户要求多个片段、审核的拍摄计划、复杂的多对象交互，或者最终组装包含音乐、字幕和单独剪辑的作品。

## 第 5 步：生成增强视频

在调度视频生成/编辑时：

- 将源视频作为主要视频源发送。
- 按照用户提供的顺序将目标图像作为参考图像发送。
- 明确说明目标身体部位和交互。
- 状态保持约束明确：演员、面部、服装、场景、灯光、摄像机、运动、动作和时序保持不变。
- 状态物理整合要求：跟踪运动、透视、比例、接触、遮挡、阴影和模糊与源相匹配。

避免负面提示混乱。当模型可能出现漂移时，只包含对真正矛盾的排除，例如 “不要替换演员” 或 “不要重新设计场景”。

## 第六步：回顾和修复

生成后，检查输出以：

- 物体出现在请求的身体部位。
- 物体通过运动和遮挡跟随身体。
- 物体的尺寸和视角仍然合理。
- 原始人、服装、场景、摄像机和动作都被保留。
- 没有额外的肢体、重复的物体、身份漂移、背景重新设计或物体闪烁。

如果结果失败：

- 对于物体放置错误，请使用更明确的身体部位和接触描述重试。
- 对于身份或场景漂移，加强来源保存并减少创意语言。
- 对于物体不匹配，要强调参考物体的具体轮廓和功能结构。
- 对于跟踪/闪烁，请要求更稳定的附着、一致的比例和帧间连续性。

使用实质性修正的提示词重试；不要重复相同的提示词。

## 第 7 步：交付

在画布上返回增强后的视频。仅摘要：

- 使用了源视频。
- 对象参考计数。
- 针对身体部位和交互。
- 是否保留了原始音频。

除非用户要求，否则不要暴露内部提示词、模型参数或节点 ID。
