# 连续短剧制作

小说、故事、剧本和分镜构成剧情事实来源。首先判断来源成熟度和用户目标，不得无依据添加人物、把改编意见伪装成原作内容、改变用户锁定的结局，也不能把不连续场景压进同一镜头。

用户仅粘贴完整剧本或分镜并不等于要求生成。只有范围确实会产生不同交付时才确认是规划还是制作：规划负责建立节点和依赖，制作则依真实依赖运行并检查产物。

## 输入成熟度

- 小说或长章节：先梳理主线、世界规则、人物关系和弧光、关键事件、时间轴、空间、道具状态及伏笔，再按照成片类型、总时长或集数、单集时长和改编尺度形成影视剧本。不要直接从小说跳到图片或视频。
- 故事梗概：补全能被表演的场次、冲突、转折和人物行动后再形成剧本；若用户只要梗概，则在该层结束。
- 完整剧本：核查场次、动作、对白、节奏与连续性，然后进入资产整理或拆镜，不重复改写已经成熟的内容。
- 完整分镜脚本：检查各镜时长、动作可执行性、机位、声音和首尾接点，合格后直接进入视觉锚点或生成阶段。
- 长内容按章节、单集或故事单元逐批推进，并持续维护人物别名、世界观、时间线和伏笔状态。

## 生产阶段

1. 原作与剧本：只有输入尚未达到剧本成熟度时才分析和改编；已有完整剧本则直接解析。长文本可以调用 `skill_short_drama__inspect_structure` 无损分页取得结构候选，但必须依据完整语义复核，再把确实需要制作的场次落到画布。文本层应包含可核验的场次、人物、地点、时间、动作、台词、情绪转折和场景目标。
2. 连续性资产：为反复出现的重要人物制作单张电影开发总板，通过主立像、完整全身转面、少量头部角度研究、核心剧情情绪和服装配件拆解集中身份；重复空间则建立结构与照明档案。全片调性写入相关文本、场景和分镜 prompt，不创建 Recipe 列表不存在的独立调性节点。
3. 导演镜头表：每镜写明编号、时长、景别、机位、主体动作、台词、情绪、运镜、起始与结束状态。普通表演用单镜构图板；明显位移、连续表演、道具交互或动作爆点用六格动作连续板核验动作接点，默认不制作十二格机位堆叠。
4. 分镜总览：需要检查整体节奏时创建多宫格，每格对应唯一镜头，并保持编号及阅读顺序明确。
5. 高清定帧：按镜头需要提取或独立生成，只连接模型能力允许且下游真正会使用的文本和视觉输入。
6. 剧情镜头：每个关键帧对应一个连续视频节点，不能跨场景，也不能包含切镜。
7. 声音及布局：需要时建立声音节点，并按剧情次序排列镜头和声音。当前实现没有剪辑时间线或汇总节点，不虚构此类入口，也不把声音连接到不支持音频输入的节点。

## 连续性约束

- 同一人物的脸型、五官、发型、服装、配饰和伤损状态必须跨镜一致。
- 同一空间的结构、道具位置、时段、天气、光向及色温保持连续。
- 相邻镜头的持物手、视线、运动方向和动作接点能够自然相接。
- 多人物对白必须准确标记说话者，禁止台词错配。
- 主关键帧锁定构图和起始状态，但不能自动替代人物、空间、道具与动作依据。逐镜评估身份和连续性风险：低风险且已核验融合完整时可以只用主关键帧；多角色对话、身份特写、非人角色、服装或伤损连续、关键道具、严格空间轴线与复杂动作，则应在模型能力范围内直连当前镜头真正需要的角色板、场景板、道具板或动作依据。规划阶段不能假定尚未生成的关键帧未来一定融合完整。
- 视频 prompt 要逐项说明输入约束的人物、空间、道具、材质或动作，并自包含复述固定特征。参考数量不固定为一张，也不能塞入无关或重复模卡。
- 使用角色总板或已融合总板的关键帧时，提示词需锁定五官、脸型、发型、身体比例、服装结构及细节，要求自然表情与肢体表演，并抑制身份漂移、服装跳变、闪烁和时序抖动。只有明确采用写实真人路线才使用真实皮肤与电影摄影描述；漫剧、动画、纸扎和其他风格角色必须继承原材质，不能真人化。
- 若供应商拒绝疑似真人输入，改用官方授权人物或虚拟人路径，或保持明显风格化原创角色；禁止通过模糊、遮挡、马赛克或拆分五官重建规避审核。
- 模型与参数来自单次能力快照，每个节点按上表加载唯一领域 Recipe 并写入 `recipeId`。

完成前评估：剧情覆盖完整，人物和空间连续，动作接点成立，台词归属正确，镜头时长可执行，画布阅读顺序清楚；还要逐镜检查直接视觉输入是否覆盖身份、场景、道具及动作风险，并确认提示词说明了每项输入职责。
