# IP 素材生产

当用户想要将一个 IP 字符转化为可重用的资源系统时，请遵循以下工作流程。目标不仅是创建一个图像，而是首先锁定字符标识，然后将其扩展为一组可控的可交付成果:IP 3D 形象图、IP 九宫格表情包、IP 多种服装主体形象、IP 海报场景延伸、IP 文创周边等。用户可以提供草图、完成的参考资料，或者仅提供文本构思。在每个模块边界处，呈现结果并询问是否继续；用户可以在任何部分可交付成果后停止。

## STEP 0: 收集输入与范围

1. **接受草图或文本优先输入**。
   - 如果用户已经有一个草图/参考图像，可以将其用作 IP 锚。
   - If the user only has a text idea, first ask whether they want to先设计草稿图，or直接进入成品化角色图。
2. **明确目标范围**。
   - If the user provided a sketch or reference image, do not ask them to pick a module list first; use the fixed default sequence: 3D形象图 → 九宫格表情包 → 多种服装主体形象 → 海报场景延伸 → 文创周边。
   - 如果用户只有一个文本想法，请询问他们是想先看草稿图还是直接看成品化角色图，然后从选择的切入点开始。
   - 如果他们对后续模块不确定，仍然建议使用相同的默认顺序。
3. 锁定固定标识。
   - 记录角色的面部表情、头部形状、发型、轮廓、身体比例、核心标志、核心色系以及任何必须保留的配件。
   - 记录可以改变的内容：姿势、表情、服装、道具、场景和产品包装。
4. **确认制作风格**。
   - Use the user’s already confirmed phrases as anchors, such as“保持角色外观完全一致”“不改变造型/服装/颜色/发型和任何细节设定”“明亮干净的色调”“柔和光影过渡”“简洁现代的视觉氛围”“泡泡玛特风格”“3D卡通角色”。
   - 如果用户想要一个新的方向，请在生成之前更新锁。

## STEP 1: 如果没有草稿，先生成草稿方向

如果用户没有提供可用的草图或参考图像，请不要直接跳到商品或海报。

1. 为同一 IP 提出 3-4 个草图方向。
2. 生成一小组草稿选项。
3. 显示选项并询问哪个选项将成为身份锚。
4. 只有在用户做出选择后，才能继续进行下一步。

如果用户已经提供了清晰的草图或完成的 IP 参考，则此步骤是可选的。

## STEP 2: 建立IP基础形象

创建核心 IP 3D 形象图像作为后续素材的标识锚。

- 保持固定标识不变。
- 如果用户想要润色，可以将草图精炼成一个完整的 3D 卡通潮流玩具手工成品。
- 如果用户想要进行一致性测试，可以创建一小组核心视图或颜色变体，但保持相同的字符。
- 在展示结果后，询问是否继续下一个模块，以及他们是否需要更多的色域。

## 步骤 2.5:Colorway 优先级规则

当用户请求 IP 颜色或调色板选项时，首选顺序如下：

1. 从温暖、低攻击性的基色开始，如奶油色、奶茶色、桃色、燕麦色、薄荷色或雾蓝色。
2. 使用一种主要英雄色、一种辅助对比色和一种小强调色。
3. 保持整个系列在相同的亮度和饱和度范围内，使系列感觉统一。
4. 对于盲盒或可收藏系列，在保持相同柔和整体色彩语言的同时，可以在不同变体之间调整色调。
5. 对于实体商品或图案纸张，建议使用低饱和度、高亮度的颜色，并为轮廓和装饰添加明显的深色或金属色调。

## 步骤 2.6:可选动作扩展板

在核心 3D 角色完成后，工作流程可以选择性地询问用户是否想要一个动作扩展板，或者在需要时生成一个。

1. 保持角色外观完全一致，只改变运动、角度、表情和光线交互。
2. 默认为 8 种不同的动作方案，具有自然的动作、多样的视角，且无僵硬的重复。
3. 保持道具简单；如有必要，让角色直接握住或触碰道具，而不是将其放在角色旁边。
4. 最适合用作白色背景参考板、动作提案页面或动作研究页面。
5. 生成后，询问是否继续使用下一个资源模块。

### 动作扩展提示模板

根据提供的 IP 设置，保持风格统一，并在纯白背景上生成 8 个普通的动作扩展方案。结果应该感觉自然、差异化、角度丰富且互动，同时完全避免重复的僵硬姿势、重复的视角和重复的面部表情。保持角色外观完全一致，只改变动作、角度、表情和光线互动。保持道具简单，如果它们出现，让角色握住或直接触碰它们。

## 第 2.7 步：表情包模块（可选）

当用户请求 IP 九宫格表情包或表情贴纸时：

1. 保持相同的角色模型、服装、色彩系统和主要配饰。
2. 只需改变表情、小动作和姿势。
3. 默认为 3×3 的网格，包含九种不同的情绪，除非用户要求不同的计数。
4. 默认使用干净的白色无缝背景，这样每个表情包输出都易于阅读且保持一致；只有在用户要求使用不同背景时才进行更改。
5. 保持风格统一，使整个集合感觉像一个角色家族。
6. 呈现工作表，询问是继续还是修改。

## 第 4 步：服装标识模块（可选）

当用户想要同一 IP 的多个服装标识时，首先要询问他们是想要一个通用主题还是自定义主题。

### A. 共同主题

1. 生成标准的职业或主题装扮，如面包师、宇航员、赛车手、医生、厨师、警察、画家或歌手。
2. 保留角色的面容、轮廓、比例和关键标志。
3. 只改变服装逻辑、角色道具和身份线索。
4. 让每套服装清晰地呈现为不同的角色或主题，同时仍然感觉像是同一个 IP。
5. 默认为一张白色背景纸上的 8 种不同角色变体，除非用户要求不同的数量。
6. 完成后，询问是否继续下一个模块。

### B. 自定义主题

1. 分析 IP 的风格、识别点和整体氛围，以找到合适的角色设计方向。
2. 将分析转化为自定义角色设计建议，然后将其转化为图像生成准备的提示。
3. 只有在确认方向后才生成图像。
4. 保留角色的面部、轮廓、比例和关键标志。
5. 新的装扮应该仍然感觉像是同一个 IP，只是身份、服装和道具朝着自定义的方向移动。
6. 如果用户想要多个身份，可以将它们作为一个系列生成，然后暂停并询问接下来该怎么做。

## STEP 5: 海报场景延伸模块（可选）

当用户想要主题海报或场景扩展时：

任何海报标题、标签或支持文本默认为英文，除非用户明确要求使用中文。

1. 保持同一 IP 角色不变。
2. 将角色置于一个充满活力、有趣、故事丰富的场景中。
3. 让场景支持角色，而不是替代它。
4. Common directions include海上冲浪、森林探险、拳击比赛、潮玩展示、节日活动等.
5. 将结果作为海报保持可读性，并询问是否继续。

## STEP 6: 文创周边模块（可选）

当用户想要文具、学校用品、贴纸或儿童友好商品时：

1. 保持 IP 角色身份可识别。
2. Extend the character into products such as笔袋、书包、铅笔、橡皮擦、儿童水杯、午餐盒、毛绒玩具等.
3. 保持设计明亮、有趣、简单，适合儿童使用。
4. 除非用户另有要求，否则最好使用纯白或简单的背景。
5. 在一个商业板或一组产品之后，询问是继续还是分拆成单个产品。

## STEP 7: 细节修改与重做

在任何时候，如果用户认为某个素材过于简单、颜色平衡不正确、姿势不稳定或缺少某个细节，请进行以下更新：

- 仅更新受影响的模块。
- 除非用户明确更改，否则保持身份锁完整。
- 如果用户要求更改基础程序，请先修改程序，然后再次生成下游素材。
- 如果用户在部分结果完成后要求停止，请结束工作流程并总结已完成的内容。

## STEP 8: 交付与继续选择

在每个模块之后：

1. 显示生成的素材。
2. 总结保留了什么和改变了什么。
3. 问一个简短的问题：是继续到下一个模块，修改当前模块，还是停止。

用户可以选择只生成完整 IP 集的一部分。当用户从草图图像开始时，始终遵循上述固定顺序，并在每个完成的模块后询问是否继续到下一个。如果用户只想要一个草图、一个 3D 图像、一个表达式包或只想要 merch，千万不要强制执行完整的顺序。
