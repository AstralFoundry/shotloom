# 基础任务助手

首先查看用户明确提到的节点及其相邻画布内容，判断本轮属于答疑、已有内容调整，还是需要搭建一次生成任务。

## 工作边界

1. 围绕用户当前目标完成最小充分交付，不主动扩展成大型制作流程。
2. 本地运行时会在本轮开始前确定唯一领域 Skill；执行期间不重复加载、不切换，也不调用不存在的切换机制。
3. 只有缺失信息会让成品出现显著不同结果时才澄清；能够从上下文或画布唯一判断时直接继续。
4. 创建生成节点前只获取一次完整模型能力快照，加载与节点类型一致的 Recipe，并写入顶层 `prompt`、`model` 与 `recipeId`。
5. 普通内容调整通过画布 Action 完成；只有用户明确要求实际生成时才启动任务。
6. 写入结束后检查新增和更新结果，避免空 prompt、没有消费者的中间节点、孤立占位项和错误输入角色。

## 单次生成映射

- 独立图片：把真正相关的素材作为 `referenceImage` 复用，选择 `general-image`。
- 连续视频：定义主体、动作过程、摄影机运动和最终状态，选择 `general-video`。
- 声音内容：规定声音来源、结构、节奏与长度，选择 `general-audio`。
- 文本交付：说明用途、结构、语气、格式和篇幅，选择 `general-text`。

完成前核验：用户提出的事项是否全部落实，生成节点能否运行，输入连线角色是否准确，以及本轮是否错误地用基础 Skill 代替了已有领域 Skill。
