# 倒置质量关卡和恢复

检查生成的图像本身。成功意味着可控的低生产价值，
不是传统的视觉润色。

## 硬通过标准

- **硬锚保真度:**主题计数/类型、编排、语义动作、作品、
摄像机、场景类别、主要道具和主色块仍然可识别。
- **保真度上限:**精致的面孔、眼睛、头发、双手、服装和背景是
明显简化；近乎精确的抛光复制失败。
- 极其稀疏的拓扑结构：头部、躯干、四肢、动物身体、手、面部，
树叶和建筑使用少量粗糙的大块材料。密集的小面
即使它们的正常面看起来是多面的，也无法保持光滑的轮廓。
- **破碎比例:**人类或动物的头部/身体、肢体、颈部、躯干、关节，
口鼻部和爪/蹄比明显偏离源头，但不改变
主体类别或变得可怕。
- **失败的姿势和支撑:**语义动作存活，但关节流动、平衡，
重量传递、躯干补偿和接触是僵硬、简化或错误的。
- **可见的碰撞失败:**当存在合理的接触区域时，1 至 3
局部网格交叉点在袖子、肘部、肩部、衣服周围可见，
手、持有的支撑物、毛发或邻近的身体。完全清洁的碰撞失败；面部
遮挡、缺失肢体、暴露、类似损伤的变形或全面剪裁也会失败。
- **粗糙的凝视:**角色的眼睛僵硬，略微不对称或不完美对齐，
缺乏专业的动画细腻度，同时保持不恐怖。
- **纹理贫乏:**地图明显微小、模糊、拉伸、反射、平铺，
尺度不一致；表面不是干净的 PBR 或粘土。
- **材质贫乏:**弥散/基色占主导地位。正常/位移，次表面，
层状织物/毛皮、透明涂层和逼真的反射模型都不存在。平面
哑光区域、异常发光的斑块和不一致的响应取代了一致的 PBR。
- **资源贫乏:**背景和重复物体明显来自一个非常小的
重复使用的库；详细的独特布景修饰失败。
- 朴素的照明:**照明直率、不均匀且简单，带有局部剪辑效果
高光、模糊斑块、基本硬阴影，且没有电影般的分离效果。
- **真实重建:**低质量源于几何形状、材料、重复，
灯光和渲染——不仅仅是模糊、噪声、像素化或分级。
- **不得添加发明:**不得添加未经请求的主题、道具、角、奶牛特征、字幕，
标志、界面、地标或天气变化。

## 评分检查

每个维度的评分为 0-2。只有在 20/26 或更高的情况下，当所有严格的检查都通过时才接受。

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| 宽锚 | 丢失 | 部分保留 | 清楚地保留 |
| 忠诚度上限 | 太精确了 | 混合 | 细节明显减少 |
| 拓扑预算 | 稠密/光滑 | 混合 | 极其稀疏的质量 |
| 比例 | 来源忠实 | 轻微修改 | 明显破损，但可读性强 |
| 姿势/支撑 | 自然 | 部分刚性 | 刚性且技术上失败 |
| 碰撞 | 完全干净或具有破坏性 | 微妙/不一致 | 本地可读剪辑 |
| 面孔/目光 | 精炼 | 部分僵硬 | 粗糙的说服力 |
| 纹理 | 干净/独特 | 有些粗糙 | 微小而重复 |
| 材料 | 连贯/PBR | 部分简化 | 仅扩散且不匹配 |
| 素材重用 | 丰富多样 | 一些重用 | 显然有限的图书馆 |
| 背景 | 详细 | 减少 | 稀疏且重复 |
| 灯光 | 电影 | 简单 | 天真的不均衡 |
| 捕捉约束 | 噱头 | 有些过度 | 次要而微妙 |

## 故障恢复

### 太忠实、太有吸引力或太精致

重试:“仅锁定计数/类型、布局、语义动作、摄像机、场景类别，
主要道具和大色块。释放精确的姿势、轮廓、解剖图和
清洁碰撞。摒弃细节相似性，减少拓扑结构、服装细节、独特性
素材和材料复杂度。”

### 多边形数量仍然太高

再试一次:“将每个头部、躯干、肢体、爪子、衣服和动物身体替换为
少量大型原始质量。移除小面和平滑轮廓的边缘
不要通过将其切割成许多三角形来重现光滑的源轮廓。

### 比例保持正确或令人满意

再试一次:“保留主题类型、身份锚定和语义行为，但释放
源轮廓。故意不匹配头部/身体比例、肢体长度、颈部，
躯干宽度、关节尺寸、口鼻、爪/蹄和动物体重。组装
笨拙的部位，而不是优雅的漫画化。”

### 姿势看起来仍然自然

再试一次:“只保留动作本身的意义。锁定躯干，旋转关节。”
一个粗糙的轴线，肩部抬高过高，弯曲肘部，伸直手腕，立足，
减弱平衡和接触，并移除对位姿势、重量转移和软变形。

### 衣服和身体保持无碰撞

用以下方式重试:“在源证明的接触处添加一到三个局部可见的交叉点
区域：袖子到肘部，上臂穿过肩膀或衣服，手进入袖子或
握住支撑物，将衣服穿过躯干，将皮毛穿过背带，或者将相邻的身体稍微交叉。
保持脸部和完整四肢可见；不要暗示受伤或暴露身体。

### 眼睛看起来仍然像专业动画

再试一次:“重复使用一个粗糙的眼睛模型。使眼睛大小稍微不均匀，瞳孔
偏离中心，目光聚焦不完美，眼睑僵硬，眉毛简单，表情
冻结。保持可读性和笨拙，不要怪诞或可怕。”

### 背景过于详细

再试一次:“删除临时布景。只保留必要的场景元素。”
多次重复使用两到三棵树/建筑/梁/柱子/岩石模型，保持最小
变化。不要有单独创作的杂乱或大气深度。

### 纹理过于干净或多样

重新尝试:“用微小模糊的扩散地图替换表面。制作瓷砖、接缝，
紫外线拉伸、镜像细节、尺寸不一致和重复使用清晰可见。
在多个兼容物体上重复使用相同的地图。

### 材料看起来仍然很高级

再试一次:“移除相干 PBR 材料响应。使用弥散/基色作为
只使用可靠的通道。删除正常、位移、次表面、透明涂层、分层
面料/毛皮和逼真的反射。使大面积区域完全平整，允许一些错误的区域。
发光斑块，并使附近物体对同样的光线产生不一致的反应。

### 照明太专业了

再试一次:“只改变照明。使用一个钝的头顶前方定向灯”
加上微弱的平面环境。创造出剪短的额头、鼻子、手、浑浊的眼窝和
颈部、硬的低分辨率阴影、微弱的接触和不均匀的附近曝光。移除
边缘、美丽、三点、弹跳、全局光源、体积、光晕和深度。

### 结果变得黑暗、恐怖或怪诞

恢复源引导色和可读曝光。保持笨拙的眼睛和粗糙的面孔
在普通风格内。去除恐怖分级、极端扭曲、深黑色
虚空、戏剧性的雾气和威胁性的光线。

### 广泛的构图漂移

重新设置主体数量/类型、近似坐标、相对比例、语义动作、摄像机高度，
地平线、前景遮挡和背景质量。说 “不重构，不重裁剪，
镜头运动、主题合并或重新排列。

### 结果看起来像个滤镜

说:“将每个对象重建为实际的原始 3D 素材。使多边形数量较少，
在添加任何捕获噪声之前，只能显示重复的地图、重复使用的模型和简单的可见阴影。

### 不需要的奶牛、角、说明或 UI

说:“技能名称不是内容说明。仅显示来源证明
内容。不要添加奶牛、角、动物特征、模因文本、字幕、水印、标志，
HUD 或新道具。

## 重试纪律

1. 在每次重试时重置所有宽锚定锁。
2. 仅改变失败的维度。
3. 宁可降低细节保真度，也不要削弱合成锁。
4. 两次重试后停止，除非用户要求继续。
5. 揭示剩余的硬故障，而不是将结果称为成功。
