# 角色提示词细节示例

此例展示用户要求的细节密度。沿用当前角色板的左右位置与区域占比，按“特写区域 / 全身三视图区域”分配以下要求，不从此例重新推导版式。阿渡、八头身、沙漏型、暖色炉火和超写实 CG 均为本例的具体设定，不是其他角色的默认模板。生成实际提示词时，替换成当前角色与本集已经确认的内容。

```text
真人漫剧电影级角色资产设定图，16:9，沿用既定角色板布局。特写区域为角色半身特写，保留完整五官、眼神、唇形、皮肤次表面散射与皮相气质，脸部不得遮挡；全身区域为同一角色三视图：正面、左侧面、背面，全身远景等比例站姿，中性灰背景。全身三视图的正面与左侧面不生成可识别五官，采用中性灰无五官面部处理，仅保留头型、发际线、下颌外轮廓、发型与体型，背面正常无五官。
本集风格：超写实CG质感，类似《爱死机》骑马人，整体暖色调，炉火橙红光打在人物侧面，皮肤有暖光反射，粗粝厚重的写实质感。
角色锁：阿渡，十七八岁少女，鹅蛋脸，丹凤眼，薄唇，疏离感中带着古灵精怪的眼神，冷白皮，月白色窄袖短褐袖口收利落，深褐皮腰带挂旧皮卷，深灰束口长裤小腿绑腿，短靴，高马尾深灰发带额前碎发，棕色行囊。
比例锁：女性八头身，头长=身高1/8，肩宽≈1.5头宽，腰宽≈1头宽，臀宽≈1.5头宽，腰臀比≈0.7，腿长≈身高1/2。
体型锁：女性沙漏型，比例绝对协调，不得比例失调。
人体锁：人物双手各五指，无多指，无少指，无手指融合，骨骼肌肉写实，四肢及关节结构完整自然。
风格：超写实CG，电影级，俊美，非大众脸，细节丰富，炉火橙红侧光，皮肤次表面散射，毛发细节，服装材质清晰。
负向：多指，少指，手指融合，六指，比例混乱，比例失调，比例不协调，五五分，头大身小，腿短腰粗，女性非沙漏，头身比错误，漫画感，二次元，大众脸，五官平庸，脸崩，身体畸形，服装变化，三视图不一致，文字水印，塑料皮肤，过度卡通。全身三视图出现完整五官，全身三视图生成眼睛鼻子嘴巴，全身三视图出现可识别脸，全身三视图脸部细节，半身特写无五官，半身特写面部遮挡，三视图头型或下颌轮廓与特写不一致，三视图面部遮挡改变下颌轮廓，三视图遮挡发型。
```
