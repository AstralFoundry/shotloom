# 角色板与三视图

只处理角色身份参考板，不负责剧本、分镜、连续视频或音频。用户要求角色版、角色三视图、角色转面、角色设定版、character sheet、人物设定图或角色模卡时使用本 Skill。

独立通过 `/character-board` 调用时，本 Skill 负责把角色板落成真实图片节点；用户要求实际图片且设置允许时启动生成，并核验真实结果。也可由剧本分镜或视频制作的主 Skill 在新建人物身份资产前作为辅助 Skill 加载；这时只提供人物外观、服装和角色板提示词规范，主 Skill 继续负责节点、生成执行与下游引用。

## 固定版式

- 横向 16:9 单张角色开发板。
- 左侧从左到右排列同一角色的正面、严格侧面、背面全身三视图；全身完整入画、同尺度、脚底对齐、间距清楚。
- 右侧放占比最大的正面脸部近景或半身正脸，清楚呈现五官、脸型、发型和身份锚点。
- 五官仅由脸部近景或半身特写承载：完整保留五官、眼神、唇形和皮相气质，不遮脸。全身三视图的正面与严格左侧面采用中性灰无五官面部处理，不生成可识别的眼睛、鼻子、嘴巴，仅保留头型、发际线、下颌外轮廓与发型；不得通过面罩、头发遮挡、裁切或模糊整颗头来实现。侧面头部和躯干同时转到 90 度；背面头部和身体同时背对镜头，不露五官，也不回头。三视图通过头部轮廓、发型、体型、服装和配饰与特写保持同一角色身份，不要求无五官面部复现特写的五官。
- 四个区域的体型、发型、服装、面料、配饰和固定识别点一致；侧面和背面要展示衣服结构，不用脸部特写替代。
- 背景使用干净的浅灰、米白或其他低干扰纯色，保留留白。
- 角色板只保留这四个主要区域：左侧正面、侧面、背面全身，右侧最大正脸。

“角色设定版”与“character sheet”默认指这套四区域版式，不等于带表情头像、装备拆解和色卡的扩展型概念板。除非用户明确写出“扩展角色板”并确认要增加区域，否则必须拒绝自行添加这些内容。

## 必须排除

不要生成单张半身海报、单人写真或无三视图的图片。不要加入额外头部角度、表情头像、服装配件拆解、装备特写、色卡、道具陈列、场景、装饰、网格、边框、参数表、长标签、水印、伪文字或重复人物。

## 提示词要求

沿用当前角色板的左右位置和区域占比，不因下面的提示词写法重新排版。先写既定构图与各区域的面部职责，再按“本集风格、角色锁、比例锁、体型锁、人体锁、风格、负向”的分段结构输出完整提示词。角色名可以放在角色锁中，但不能代替可见外观；各段须写成可直接交给图片模型的内容，不能只留下标签、占位符或泛泛的“高质量、保持一致”。

- **本集风格**：依据当前项目或本集已确认的视觉路线，写清媒介、写实程度、整体色温、光源方向、主辅光关系、光色反射和材质观感。作品类比须落到可见特征，不只写作品名。超写实 CG 可具体描述皮肤次表面散射、毛发、织物与皮革纹理；动画风格按其媒介写，不强套写实皮肤。带色侧光不得让不同视图的服装固有色、结构或轮廓不可辨。
- **角色锁**：写年龄阶段、性别呈现、脸型、眼型与眼神、唇形、肤色、气质、发型发色、发际线和碎发；再写服装每层的颜色、面料、领口、袖型和袖口、腰带、下摆、裤型、绑腿、鞋靴、配饰、携带物及佩戴位置。把人物气质落实为眼神、体态等可见设计，不以姓名或职业代替外观。
- **比例锁**：根据角色设定写明确、相互协调的头身比、肩腰臀宽度与腿长关系，确保三视图同尺度、头顶与脚底对齐。可量化为“头长=身高的某一比例、肩宽约几头宽”等，但不能把示例中的女性八头身、肩宽 1.5 头宽、腰臀比 0.7 当成所有角色默认值。已经明确的数字应原样保留并检查彼此关系；未指定的部分由模型依据年龄、体型和美术风格设计，区分设计推断与剧本事实。
- **体型锁**：写明角色实际的体型、肌肉脂肪分布和轮廓，正侧背保持一致、比例协调。仅在角色设定需要时使用沙漏型、纤细、壮硕等特征，不把所有女性写成沙漏型，不把少年、老人或非人角色套用同一人体模板。
- **人体锁**：常规人类角色四肢、关节与骨骼肌肉符合设定；双手各五指，无多指、少指、融合和畸形。非人角色或设定中的肢体差异按原设定保留。明确三视图站姿稳定、全身含鞋完整入画，不用“永远不会畸形”代替具体结构要求。
- **风格**：收束本集的画质、光线、皮肤或其他表面材质、毛发和服装细节；保持角色识别点，不凭空要求所有角色俊美或同一种脸。
- **负向**：同时覆盖人体错误、比例错误、服装发型漂移、三视图不一致、无关风格、文字水印，以及面部处理错误。必须区分特写与全身区域：排除全身三视图出现完整或可识别五官、眼睛鼻子嘴巴、脸部细节；排除特写无五官、脸部被遮挡；排除用遮挡改变下颌轮廓或遮住发型。不要全局写“无五官”或“禁止眼睛鼻子嘴巴”，否则会破坏特写。负向中的体型与风格限制须贴合该角色，不能复制与当前设定相反的“女性非沙漏”“漫画感”等词。

人物外观与服装细节必须依据当前剧本、用户参考、已生成资产和项目风格自行设计；不套用任何预设角色、朝代、配色或装饰。剧本只给“华服”“道袍”时，根据世界观补全具体设计，说明哪些是设计推断，不要把模糊词当成完整造型。

需要完整细节示例时读取 [references/detailed-prompt.md](references/detailed-prompt.md)。该示例展示阿渡的细节密度与约束写法，不替换当前角色，也不改变既定布局。

## 完成核验

完成前检查提示词是否写明具体服装、左侧正/侧/背全身、右侧最大正脸、特写保留完整五官、全身正面与左侧面为中性灰无五官、背面不露脸、纯色背景和身份一致性；缺少任一项就先修正提示词。生成后确认画面没有多余人物、装饰或文字，并且四个区域确实属于同一角色。全身正面或侧面生成可识别五官、特写无五官或被遮挡、下颌轮廓或发型被遮挡、背面回头露脸时，修正提示词或重做后再作为下游身份资产。

独立调用时，先核验画布已有资产并用 `inspect_model_catalog` 选择真实可用的图片模式，把完整提示词写入 `canvas_create_node` 创建的图片生成节点，并将 `artifactType` 设为 `character`。用户要求实际出图且设置允许时调用 `canvas_start_generation`，用 `inspect_tasks` 等到终态后再检查结果；只建节点时如实说明尚未出图。若本轮改动了画布或启动任务，根据真实回执报告结果。辅助调用时由主 Skill 执行这些画布步骤。
