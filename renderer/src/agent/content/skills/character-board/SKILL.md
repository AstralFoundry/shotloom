# 角色板与三视图

只处理角色身份参考板，不负责剧本、分镜、连续视频或音频。用户要求角色版、角色三视图、角色转面、角色设定版、character sheet、人物设定图或角色模卡时使用本 Skill。

独立通过 `/character-board` 调用时，本 Skill 负责把角色板落成真实图片节点；用户要求实际图片且设置允许时启动生成，并核验真实结果。也可由剧本分镜或视频制作的主 Skill 在新建人物身份资产前作为辅助 Skill 加载；这时只提供人物外观、服装和角色板提示词规范，主 Skill 继续负责节点、生成执行与下游引用。

## 固定版式

- 横向 16:9 单张角色开发板。
- 左侧从左到右排列同一角色的正面、严格侧面、背面全身三视图；全身完整入画、同尺度、脚底对齐、间距清楚。
- 右侧放占比最大的正面脸部近景或半身正脸，清楚呈现五官、脸型、发型和身份锚点。
- 只有正面视角呈现正脸：侧面头部和躯干同时转到 90 度，只见侧轮廓，不露另一侧眼睛或完整正脸；背面头部和身体同时背对镜头，不露五官，也不回头。正面全身的小脸与右侧大正脸为同一张脸。
- 四个区域的体型、发型、服装、面料、配饰和固定识别点一致；侧面和背面要展示衣服结构，不用脸部特写替代。
- 背景使用干净的浅灰、米白或其他低干扰纯色，保留留白。
- 角色板只保留这四个主要区域：左侧正面、侧面、背面全身，右侧最大正脸。

“角色设定版”与“character sheet”默认指这套四区域版式，不等于带表情头像、装备拆解和色卡的扩展型概念板。除非用户明确写出“扩展角色板”并确认要增加区域，否则必须拒绝自行添加这些内容。

## 必须排除

不要生成单张半身海报、单人写真或无三视图的图片。不要加入额外头部角度、表情头像、服装配件拆解、装备特写、色卡、道具陈列、场景、装饰、网格、边框、参数表、长标签、水印、伪文字或重复人物。

## 提示词要求

提示词先描述可见的人物内容：年龄阶段、性别呈现、身材比例、脸型五官、肤色、发型发色、体态；再把服装写到可复现的程度，包括内外层、每层颜色、面料、领口、袖型、腰带、下摆、纹样位置、鞋靴、配饰及其佩戴位置。剧本只给“华服”“道袍”时，根据世界观作具体设计选择，说明这是设计推断，不要把模糊词原样当作完整造型。再写风格、光线和配色，最后明确左侧三幅全身、右侧大正脸以及侧面/背面不露脸的排版。不要把“横向 16:9”“原创角色身份参考板”“角色名”“职业名”等任务元数据写成提示词开头；角色名和职业只有在能转化为可见外观时才写入提示词。参考图明确展示的版式优先于通用概念设计惯例。

人物外观与服装细节必须依据当前剧本、用户参考、已生成资产和项目风格自行设计；不套用任何预设角色、朝代、配色或装饰。把设计推断与剧本事实区分开，保持同一角色在后续节点中的身份一致。

## 完成核验

完成前检查提示词是否写明具体服装、左侧正/侧/背全身、右侧最大正脸、侧面与背面不露正脸、纯色背景和身份一致性；缺少任一项就先修正提示词。生成后确认画面没有多余人物、装饰或文字，并且四个区域确实属于同一角色。侧面出现两眼或背面回头露脸时，修正提示词或重做后再作为下游身份资产。

独立调用时，先核验画布已有资产并用 `inspect_model_catalog` 选择真实可用的图片模式，把完整提示词写入 `canvas_create_node` 创建的图片生成节点，并将 `artifactType` 设为 `character`。用户要求实际出图且设置允许时调用 `canvas_start_generation`，用 `inspect_tasks` 等到终态后再检查结果；只建节点时如实说明尚未出图。若本轮改动了画布或启动任务，根据真实回执报告结果。辅助调用时由主 Skill 执行这些画布步骤。
