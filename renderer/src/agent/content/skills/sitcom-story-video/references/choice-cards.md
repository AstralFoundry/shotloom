# 渐进式选择卡

使用这些卡片来引导用户从模糊的想法到锁定的情景喜剧制作简报。它们是以紧凑的 Markdown 形式呈现的对话卡片，而不是单独的应用程序界面。每次询问一张卡片，除非用户要求一次性设置。

主要技能的故障分类、共享预算、尝试上限和停止规则具有优先级。创意批准和执行授权是分开的；没有卡片会默默授权所有恢复阶段、额外变体、低规格探针、升级或混合错误后的视频再生。

## 卡片协议

- 在界面支持的情况下，将每张卡片渲染为交互式可选择选项卡；用户应该能够通过点击选项而不是键入来继续操作。
- 将每张卡片设置为 3-5 个选项外加`自定义`。
- 将推荐的选项放在最前面，并标记为`推荐`。
- 用一句简短的话说明实际后果，而不是一个功能教程。
- 将`A`、`B`、`默认`或自定义文本等非键入回复作为无可点击卡接口的备用选项。
- 仅接受当前显示的有界选项的`默认`。它不批准未指定的重试、输出计数、成本、模型/规格变更或后续恢复步骤。
- 仅当多张卡片同时显示时，才接受`A2, B1`等组合回复。
- 在每个答案之后，在一行中确认选择，然后继续。
- 不要询问不会改变故事、剪辑地图、提示语法或交付格式的信息。
- 保留一个可见的状态块:`模式 / 时长 / 画幅 / 喜剧引擎 / 视觉预设 / 切镜策略 / 音频 / 当前规格 / 授权产物与次数 / 已用及剩余预算`。

## 卡片 1:生产模式

```text
【1｜制作模式】
A. 概念开发（推荐）— 从一句话想法建立人物、场景和喜剧引擎
B. 分镜设计 — 已有故事，输出镜头表与画面提示词
C. H3 Prompt Pack — 已有分镜，直接写 H3 多镜头时间线提示词
D. 修改诊断 — 修复切镜、质感、连续性或节奏问题
E. 自定义：____
回复 A-E 或“默认”
```

## 卡牌 2:格式和交付

```text
【2｜规格】
A. 45-60 秒，16:9，横屏平台（推荐）
B. 20-30 秒，9:16，短视频平台
C. 75-90 秒，16:9，完整小剧场
D. 自定义：时长 / 画幅 / 平台 / 帧率
```

如果用户已经命名了 H3，请将`模型：MiniMax H3｜参考模式：全能参考`添加到状态中，而不是要求提供冗余的模型卡。

## 卡片 3:情景喜剧世界和漫画引擎

```text
【3｜喜剧世界】
A. 合租客厅：生活规则被误解（推荐）
B. 办公室：职位与能力错位
C. 家庭厨房：小事升级成灾难
D. 近未来服务空间：机器严格按字面执行
E. 自定义地点与关系：____
```

然后，如果用户还没有提供一张，则显示第二张紧凑型卡：

```text
【3B｜喜剧引擎】
A. 过度自信的计划不断升级（推荐）
B. 一本正经的字面误解
C. 所有人都看见、只有主角不知道的秘密
D. 关键道具故障并改变社交地位
E. 自定义：____
```

## 图像分辨率的选择

在第一次图像生成操作之前，始终显示这张交互式卡片，除非用户已经指定了图像分辨率。所选分辨率对于当前制作中的所有角色、场景、道具和分镜图像都是锁定的。

```text
【图片清晰度】
A. 1K（推荐）— 适合快速验证角色、场景和故事板，生成成本较低
B. 2K — 适合更清晰的角色细节和最终参考图，生成成本与资源消耗更高
```

在用户选择 A 或 B 之前，不要生成任何图像。

## 默认视觉预设

视觉预设会自动锁定为原始的 20 世纪 90 年代末/21 世纪初的温馨室内电视情景喜剧风格。不要显示视觉纹理选择卡。如果用户明确要求其他视觉风格，请记录该请求并将其用作覆盖。

## 卡片 4:切换和摄像机策略

```text
【4｜切镜策略】
A. 经典覆盖：主镜建立 + 两人镜 + 反应近景，动作切为主（推荐）
B. 快节奏喜剧：1.0-2.0 秒短镜，反应切与视线切密集
C. 表演长镜：较少切镜，推拉/横移跟随表演，关键处插入反应镜
D. 混合：A 建立、B 交互、C 反应，按笑点密度调整
E. 自定义：镜头数量 / 节奏 / 转场____
```

所选策略必须成为真实的剪辑地图。每个生成的提示仍然需要准确的时间码、镜头 ID、取景、镜头、镜头运动、动作峰值、剪辑类型和连续性切换。永远不要只输出样式描述。

## 卡牌 5:音频和对白

```text
【5｜声音】
A. 有对白：短句、可见说话者、对白下压环境音（推荐）
B. 少对白：以动作和反应为主，保留关键一句
C. 无对白：只用同步拟音、环境声和停顿
D. 自定义：语言 / 口型要求 / 音乐许可____
```

当用户选择不使用对话时，不要添加无声对话或生成字幕。当选择对话时，将每一行都绑定到一个可见的说话人，并为每一行和每一个反应预留足够的屏幕时间。

## 卡 6:H3 生成策略

仅当选择了 H3 或用户请求特定于 H3 的提示时，才显示此卡：

```text
【6｜H3 生成方式】
A. 多镜头时间线：一条 prompt 写完整时间码、切点与运镜（推荐）
B. 关键镜头优先：主镜/反应镜/道具镜分别写，后期按 cut map 组装
C. 混合：可稳定的镜头写在同一时间线，复杂镜头拆分生成
D. 自定义：____
```

不要将选项 B 视为强制性限制。所选模式仅改变包装；在所有模式下，切割地图、精确摄像机方向和连续性锚点仍然是强制性的。

## 完成卡

在撰写昂贵的提示文字之前，请显示：

```text
【已锁定】
模式：...
规格：...
喜剧世界 / 引擎：...
视觉预设：暖色复古室内情景喜剧（默认锁定）
切镜策略：...
声音：...
H3 生成方式：...

A. 确认并执行已列明范围
B. 返回修改某一项
```

在 A 之前，列出准确的可交付成果/产出计数、模型/规格、批准的操作类别、尝试、成本暴露和停止条件。对于仅提示模式，A 只生成文档，而不生成媒体。对于媒体生产，A 只授权显示的批次。在 B 之后，只重新审查相关选择，并保留其余选择。在剩余余额内重复使用精确的先前授权，而不是要求两次。

## 范围回收卡

首先显示执行/内容/音频后分类、证据、受影响的镜头/文件、保留素材、当前与建议的规范/引用/内容、准确的新输出、已使用/保留尝试、成本估计或 “未知” 以及停止条件。默认范围为每个列出的产物一次操作；共享的三代总数上限仍然适用。针对性的执行重试也尊重主文件的至少一次默认执行重试限制。

```text
【局部恢复方案】
A. 执行已列明的一次修复 — 仅处理上述镜头/文件与操作
B. 先修改方案 — 暂不生成媒体
C. 保留当前待审版本或补交素材 — 不追加生成
D. 停止并交接已有结果
E. 自定义：范围 / 次数 / 预算____
```

当配额用尽、工作状态未知或拟议操作更改未经批准的约定时，不要建议或执行 A。无限期的 “继续” 并非扩展提案的许可。

## 低规格测试和目标规格决策

解释测试是真正的额外生成。指定其分辨率/方面/持续时间/计数和成本；显示剩余预算以及是否包括后续的目标规范操作。提供仅限测试、特定有限的测试加条件目标计划、保留锁定规范或停止。不要假设选择低成本分辨率意味着允许两个版本。

在测试后的任何下一步之前，请确定它是确定性放大/转码还是生成性高规格重建。只有精确的现有条件授权才能跳过新的确认。成功的测试会消耗一次尝试，不会重置三次尝试的上限，也不能证明最终的目标版本将通过。

## 音乐生成与混音授权

BGM 计划必须说明生成的片段计数、生成尝试、混音/输出计数、任何有限的纠正混音余量和成本暴露。混音修复只授权对现有图像和声音进行列出的确定性操作，而不是新的视频渲染或自动新的 BGM。如果 BGM 片段包含禁止的内容，建议将其排除在外或用其自身的生成范围替换该音乐片段。不同的图像缺陷需要不同的视频修复授权。

## 后期 BGM 提供

在最终视频成功组装并通过基本 QA 后，始终在任何 BGM 工作之前显示以下交互式卡片：

```text
【成片声音选择】
A. 添加器乐 BGM（推荐）— 先分析成片节奏，再确认配乐方案
B. 仅保留原始声音 — 直接交付当前成片，不添加新音乐
```

选择 A 允许分析和准备 BGM 方案，但尚未生成音乐。只有在方案的具体输出/尝试/成本范围得到批准后才能生成/混音。选择 B 提供原始音频最终视频并关闭声音分支。千万不要从通用情景喜剧风格的请求中推断 BGM 授权。
