## 1.确认可视化 Format

在生成之前，向用户提出一个问题，并附上一个建议：

- 格式:**
  - **多面板分镜:**一个或多个多面板图像按镜头顺序排列，一目了然地展示整个视频;
  - **单帧:**每个镜头一张图像，单独生成且无标签，适合仔细检查构图和颜色，可用作视频生成的视觉参考。
  - 或者两者兼而有之：首先是用于概述的分镜脚本，然后是用于关键镜头的单帧画面。
- **数量:**每个图像包含多少个分镜图像和面板；多少个单帧以及它们涵盖哪些镜头。

当用户已经说明了格式和数量后，不用再问就按照他们说的做。

## 2. 多画面分镜脚本：显示整个视频

1. 首先分析故事情节和参考资料:* 通读分镜脚本，理解视频的弧线以及每个镜头的关键视觉效果和情感变化；然后回顾人物、产品、场景和风格参考资料，说明每个参考资料提供了什么（身份、风格、空间、艺术风格），以及哪些内容不需要传达。
2. 规划网格：
   - 按时间顺序覆盖分镜脚本中的每个镜头。每块板最多 25 块 (5×5);当镜头数量较多时，将它们分成几块，按照发生单元或通道分组，这样它们仍然可以组成完整的电影。
   - 每个面板都匹配最终的宽高比；将整个图像的宽高比设置为最接近 “面板比×列÷行” 的标准比率，而不是重复使用面板比，这样行和列就不会被挤压变形。
   - 确定面板数量、行和列，以及优先阅读顺序，每个面板一个镜头。
3. **按照阅读顺序为每个面板写一个总体描述:**描述每个面板的镜头尺寸、主角动作、光线和色彩，并说明整个系列共享的角色、产品、场景和艺术风格。镜头编号和一行描述可以放在每个面板的旁边或下方；保持文字简短，不要出现在图像中。
4. **同时生成多个面板:**每个面板直接基于原始参考和相同的共享设置，彼此独立；永远不要将前一个面板的输出作为后一个面板的参考，这样漂移就不会逐个面板累积。在整个集合中保持字符识别、风格、光色逻辑和艺术方向的一致性。

## 3.单帧：检查关键镜头

并非每个镜头都需要帧。在用户确认的帧数范围内，确定优先级：

- 电影和每个世代单元的开场画面;
- 英雄镜头、产品特写，以及风格或情感上的转折点;
- 难以用语言描述的图像，最值得及早确认。

单帧图像是没有网格、数字或标签的干净图像，与最终的宽高比相匹配。

## 4. 在生成图像之前仔细思考

对于每个分镜面板或单帧画面，决定这个瞬间应该让观众理解什么，然后决定如何拍摄：

- 图像状态：取一个稳定、可读的时刻——动作完成后的姿势、镜头运动落地的位置，或转场前后的清晰图像；将摄像机路径、速度变化和声音留给视频提示。
- 观看关系：观众站在哪里，他们能看到什么和不能看到什么，以及眼睛如何进入、移动和落地。
- 空间层：前景、中景和背景各自的作用，其中一个主要张力来源，如遮挡、空白空间、深度或明暗分割。
- 一个动作，一个线索：一个主要动作加上一个暗示因果关系的细节，而不是堆砌道具和效果。
- 光和色彩有来源：光来自具体的光源和方向；色彩来自天气、建筑、服装、材料或实用灯具。

## 5.生成图像

- 将这些决定融入每一个图像描述中：场景、主题和关系、观众位置和注视、光源、材料和颜色源、负空间，以及任何必须准确的产品或文本。
- 附上人物、产品或场景的参考资料，这些资料必须在不同镜头之间保持一致，并说明每个人物、产品或场景提供了哪些内容，以及哪些内容不需要保留。
- 没有一致性约束的图像（纯粹的氛围、环境、抽象意象） 可以优先考虑审美质量。

## 传递和交接

提交分镜或单帧画面，注意每个面板或帧所属的镜头。当用户调整面板或帧时，只重现受影响的图像。获得批准后，单帧画面可以作为他们镜头的视觉参考，用于编写视频生成提示；分镜主要支持审查整体节奏和视觉流程。
