# 镜头设计：信息、表演、空间与切点

## 事件节拍与时间

先确定观众在段落开始知道什么、结束多知道什么，以及人物做了什么选择。将“紧张”“压迫”“迟疑”落成可见事实：出口被堵、对手逼近、手伸到一半收回、目光从人移到物。镜头围绕信息变化组织；一个节拍可以在同一镜内完成，也可以由几个视角共同交代。

动作按准备、发生、结果、反应安排覆盖。镜尾给后果可读的停留；需要长镜时让人物、视线或空间关系持续变化。时长服从内容和用户要求，不为填满时间拉长一个跳跃，也不按句子或固定秒数强行切镜。已经发生的持物、离座、受阻和位置变化应进入后续状态。

## 景别与表演

- 近景让视线、停顿、头部与手的细小变化承载信息；当前素材没有面部能力时，用可表达的头身朝向与动作传达，并说明细节近似。
- 中景保留重心、手势和人与物的关系；全景交代完整动作、行进方向、支撑点和障碍。
- 表演可沿“刺激到达→注意力转移→身体反应→行动选择→镜尾状态”展开。多人收到信息的时机不同，反应可以错开；反应时差服务事件，不机械让所有角色同时转头。
- 接触动作要看清发起者、接触点、受力者、支撑变化、惯性和恢复。物体移动、身体动作与根路径分别承担自己的职责。

## 构图选择

构图术语只是手段。先决定观众该看谁、看什么关系，再从真实场景里选择可用的画面组织：

| 叙事需要 | 可选画面组织 | 核验重点 |
| --- | --- | --- |
| 对峙、谈判或关系变化 | 双人同框、过肩、远近位置差 | 人物左右、视线、距离和关键手势可读；前景肩部不挡脸 |
| 发现与选择 | 视线留白、道具插入、注意力从人移到物 | 先理解谁发现什么，再揭示细节；插入镜有空间归属 |
| 压迫、隔离或窥视 | 负空间挤压、门窗框景、前景遮挡 | 使用真实墙体、门窗和在场人物，保留关键表情与动作可见区 |
| 空间与威胁距离 | 前中后景、引导线、纵深追逐 | 各层元素确实存在，终点和通行方向可辨；远处威胁仍可读 |
| 秩序、权力或脆弱 | 中轴、重复结构、仰视或俯视 | 角度与人物关系一致，避免透视畸变破坏身份与比例 |
| 动作爆发与后果 | 对角动线、运动方向留白、余势收镜 | 动作不被裁断；接触后保留失衡、落地、喘息或收手 |
| 段落收束 | 远景、背影离场、空空间停留 | 观众能读到关系的最终状态，停留仍有叙事信息 |

竖屏优先用纵深和上下层次容纳关系，检查脸、手、持物与脚的裁切。换画幅后重新取帧；不为套构图比例添加剧情没有的家具、群演或天气。门缝、倒影、雨夜、剪影等设计依赖实际场景与渲染能力，不能仅写名词便视为实现。

## 光影与色彩

先找场景成立的光源：窗、门、灯具或太阳，再决定世界方向、软硬、强弱和冷暖。反拍改变机位时，光源仍留在同一空间；主光不能随镜头无故换边。用亮暗与背景分离引导注意力，保留脸和关键道具的信息。

环境亮度、单灯强度和曝光是不同控制：抬高环境亮度可能抹平阴影；改曝光影响整幅画面。按目录的真实范围设置，观察阴影、接触阴影、反光和高光是否支持空间关系。随时间的变化要有叙事或光源依据。景深拉焦、体积光、雨幕或声音只有当前工具明确支持并实际执行，才能作为交付事实。

## 镜头运动与跨镜连续性

把主体速度、机位速度、焦距变化和播放时间分开设计。推近是机位位移，变焦改变视角；两者透视关系不同。摇摄改变观察方向，不要求机位漂移。根据镜尾需要的景别、可通行空间和事件时长倒推运动，检查途中和终点。

先判断相邻画面是同事件连续、换视角、跨时空，还是保持同镜更清楚，再选切点：

- 动作匹配：A 镜尾与 B 镜首的动作相位、方向、速度及持物手连续。
- 视线匹配：先建立人物看向哪里，再给对应对象；反打保持既有轴线和屏幕方向。需要越轴时通过可读的连续运动或空间重建解释变化。
- 图形、遮挡或甩镜衔接：明确哪一物体、形状或运动触发切点，检查两侧，不让遮挡掩盖叙事必需的接触过程。
- 声音桥与叠化：可以描述意图，但当前导演台切镜只切换机位。需要声音或后期转场时，交给真实支持这些操作的后续流程，并分别核验；写入 cuts 不代表这些效果已完成。

切镜继承人物身份、左右关系、持物手、动作相位、行进速度、光源与结果状态。用 `render_preview_sheet` 查看切点两侧和动作关键时刻；几何测量与时间线结构只提供辅助证据。
