# 相机、朝向与动作的控制关系

以下说明当前导演台的采样行为。写入仍通过当前工具合同；从 `director_desk_catalog` 查询真实 patch 字段、素材能力与格式，不把原生工程对象直接当批量输入。

## 机位、观察点与焦距

- 自由机位 `mode:"free"` 使用实体位置或路径。`aim:"manual"` 使用实体基础旋转；`aim:"target"` 朝向观察点。机位位置固定并不表示构图固定：人物或观察点移动仍会改变画面。
- 跟随 `mode:"follow"` 且目标存在时，以目标根位置加 `offset` 重算机位，覆盖自由位置路径；要执行声明的位置路径，先改为自由机位。`inheritRotation:true` 会让偏移随目标朝向旋转，掉头时可能绕到另一侧或穿过障碍。需要保持世界方向偏移时设为 false 并核验。
- 在需要计算观察点的模式中，优先级为 `targetPath`，其次为存在的 `targetId` 加 `targetHeight`，最后为固定 `target`。只改 `target` 不会消除遗留观察点路径或目标绑定。改为固定观察点时，明确设置 `targetPath:null`、`targetId:""` 及目标坐标。
- 主观机位 `mode:"pov"` 有效绑定目标时根据角色头部或根变换计算位置和视线；它不是自由摇摄，也不能用固定 target 替代角色视向。
- `focalKeys` 存在时按时间采样焦距，否则使用 `focal`。批量只设置静态 `focal` 会清除旧焦距关键帧；同时设置 `focalKeys` 则保留。焦距关键帧直接为 `[{time:0,value:35},{time:2,value:50}]`，不同于光影数值动画的 `{keys:[...]}` 外壳。
- 改焦距不等于移动机位或改变对焦距离。以目录支持的参数表达效果，不编造光圈、对焦距离或音频混合字段。

`targetPath` 是视线落点的路径，实体 path 才是机位路径。做固定位置的摇摄时，使用自由机位、目标瞄准和观察点变化；保留的位移路径或旋转动画仍可能改变画面，应一起核对。

## 坐标与写入格式

- 世界位置单位米、时间单位秒，水平面为 XZ、Y 向上，角色正面以局部 +Z 为基准。
- 批量 `rotationDegrees` 是度；原生工程 `rotation` 与路径 heading 是弧度；姿态关节角是度。这些字段不能互换。批量 `set_path` 的点使用 `{position:[x,y,z],timeSec}`，当前该操作不接收原生 heading。需要其他朝向控制时先查询真实命令，不把额外字段塞进路径。
- `scale` 可用正数表达等比缩放，回执会说明展开；位置与旋转仍须三元数组。真实尺寸优先使用素材参数，按目录范围和 choices 设置，不能以零值表示关闭某个尺寸。

## 朝向、动作与路径

原生采样先考虑路径显式 heading，再考虑面向目标或沿路径方向，最后为基础旋转。显式 heading 相对基础 yaw 叠加；已完成的 turn 片段还会累计转角。避免把同一次掉头同时编码为路径转向、基础旋转和 turn，造成重复旋转。路径停住并不会自动决定角色该看谁，检查停止和离开后的方向。

路径负责根位移，动作片段负责步态或动作过程，pose/poseKeys 是叠加姿态。它们需要共同满足支撑、接触和节奏；路径把模型送到目标不代表走路、抓握或碰撞已经发生。追加姿态要从已有动作基线求差，而非把最终关节角当增量。

连续同速同动作的路段尽量沿用同一片段，不因换机位或新增路点重新 start。拆分会影响步态相位；以当前可写字段保留相位并检查接缝。静态低姿态不自动产生蹲行，跳跃动画不替代越障根路径。动作结束后的保持姿态也要核对，不能假定所有动作都会恢复待机。

全局动作目录不等于每个素材都支持全部动作。以具体资产 capabilities 为准；动物路线不等于动物步态，外部模型动画名也不能当作内置动作 ID。当前工具无法表达的表演应注明近似，保留用户要求并说明缺口。
