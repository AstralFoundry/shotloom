# 3D 导演台创作与画面核验

本 Skill 负责导演判断和完成标准。实际可执行操作、字段、素材和 ID 以当前 `director_desk_snapshot` 与 `director_desk_catalog` 为准；不要把其他导演台产品的方法当作本工程的能力。

## 把需求变成可拍的场景

- 先理解用户要观众看到的事件、人物关系、空间关系、镜头重点和时间节奏，再决定需要改哪些角色、道具、机位、灯光或戏段。保留用户指定的动作、台词、时间和构图；没有必要时不改动已有内容。
- 角色与道具的位置要服务于镜头中的关系：谁面向谁、谁能碰到什么、角色是否站在地面或坐在座面上、行动终点是否落在目标附近。只填坐标而不看画面，不能证明互动成立。
- 先在素材目录找语义匹配的对象。箱子可以用箱子，不能把外形不相关的道具改名冒充用户指定的物体。目录缺少关键物体且现有命令无法制作时，明确说明能力缺口；抽象几何只适合用户接受的示意布景或远景体块。
- 对建筑、墙体、门窗、楼梯及复杂道具，先确定外轮廓、比例、开口、部件相接关系和人物尺度，再检查细节。调用 `inspect_model` 看多视角、尺寸和部件；模型单独好看仍不能证明它在场景里放得正确，随后要看含人物与机位的场景帧。

## 机位与时间线

- 先判断镜头是要交代空间、突出表演，还是展示物体。选择景别、角度和视线方向，让重要动作无遮挡且观众能读懂；优先调整机位与构图，避免仅为填满画面而挪走角色。
- 动作、路径和切镜应围绕可辨认的事件节拍安排。路径结束时检查角色最终朝向；转身、接近、交接、坐下等动作要在画面中成立，不能只凭时间线片段名判断。
- 时间线修改后选有意义的时点核验：动作前、动作中、动作后，以及切镜两侧。优先用 `render_preview_sheet` 一次比较相邻时点，再用 `render_preview` 放大可疑帧。拼图每一格都要看；一张好看的单帧不能证明整段连续。

## 核验与修正

- 写入回执证明命令被接受，场景文档证明结构，`spatial_check` 证明它采样范围内的机械问题，真实渲染帧才支持关于构图、遮挡、光影、姿态和外观的判断。这些证据不能相互替代。
- 用预览检查主体是否入画、比例与朝向是否合理、脚与座面是否接触、道具是否穿墙、建筑开口是否可用，以及相邻时点是否突然跳变。发现问题时定位对应时间、实体或机位，做针对性修改，再取帧复查。
- 如果当前工具不能提供足够证据，就明确说出尚未核验的部分。身份特征或关键空间关系仍明显错误时，不要宣称完成。用户要求交付视频时，先核验预演效果，再启动导出；不要靠反复导出视频检查场景。

最终回复简要说明实际改动、看过的画面与仍存在的问题。不要引用未看过的帧，也不要把参考项目的实现方式写进用户的工程。
