# 人物引用

为后续图像和视频建立可重复使用的外观参考。当现有角色图像覆盖所需视角并保持一致外观时，可以重复使用；一次性角色图像不需要单独的角色表。只能听到声音的角色，例如一直在打电话的母亲，不需要外观参考。

- 默认为 16:9 景观参考图像，除非用户指定其他宽高比。其宽高比与最终视频的宽高比无关；保持方向描述和生成参数一致。
- 一般角色表包括正面、侧面和背面全身视图，以及面部特写，清晰地展示面部特征、身材、侧面轮廓、背面服装和携带物品。
- 视角显示同一个人转身，身份、体型、发型和当前穿着保持一致。全身视角可以分享站立姿势和角色身高，而特写镜头则为面部特征提供了足够的空间。不对称的细节，如皮带和配件，遵循摄影机投影，而不是通过镜像反射来改变侧面。
- 精确指定视图，例如全身左侧面或背面视图，这样它们就不会都变成相似的四分之三视图。当需要完整轮廓时，在头部上方和鞋子下方留出空间。根据视图计数和下游参考功能，在约定的宽高比范围内选择布局，无需固定的面板网格或左右比例。
- 对于一般的身份识别大师，可以使用干净的背景，甚至是灯光，以及自然的姿势。强烈的情感、手持物品、伤害或特殊的灯光可以有独立的故事状态参考；当它们是当前要求的一部分时，保留它们。
- 在后续场景中引用纸张时，请指明它提供了角色的外观，而不是将其多人物布局导入镜头。

对于新的通用特征表，请说明约定的观点以及必须匹配的身份和外观细节。如果用户报告缺失观点或不一致，请补充或修改受影响的观点。在重复使用参考素材时，只添加下游镜头实际需要的缺失角度或关键外观细节。
