# 标准化镜头表规范（v1.1——音频模式感知）

## 第 5 步：标准化镜头表视频提示词（七列，v1.1）

角色卡和场景卡锁定后，将标准化视频提示输出为镜头信息表。这个步骤是强制性的，不能与分镜或视频生成交换。创建一个名为`标准镜头信息表`或`standard-shot-table`的画布表节点或标记表。

**v1.1 变更**:表现在有**七列**（以前是六列）。新的第七列是**`Audio Mode`**。现有的**`Audio & Dialogue Track`列被升级为每秒强制**`Mouth State`**字段。这两个新增的内容是防止 AI 角色混淆唇同步错误的最重要的防御措施。

表格必须正好有七列，顺序如下：

| 拍摄 ID 和持续时间 | 连续性接力 | 参考锚（空间 + 身份） | 钩子类型 | 镜头描述（每秒指令） | 音频和对话轨道（带口型状态） | **音频模式 (v1.1)** |
|---|---|---|---|---|---|---|

栏规则：

- 拍摄 ID 和持续时间：拍摄次数加上计划的持续时间，例如`S03 / 6s`。
- **连续性接力**:这个镜头如何自然地从上一个镜头的结束画面、道具位置、眼线、角色姿势、声桥或情绪状态中延续，以及它如何构建下一个镜头的开场。这就是交叉拍摄的连续性脊柱。
- 参考锚（空间 + 身份）:四个子字段，都是强制性的。
  - `Fixed Landmarks`——场景卡上精确命名的地标，以及它们与屏幕的相对位置（例如`door-frame: right third`、`kitchen-island: center bottom`）。
  - `Character Positions (camera view)`——对于镜头中的每个角色，需要说明其与银幕的相对位置（左/中/右、顶/中/底、前景/中景/背景）、面向方向和初始姿势。
  - `Exited Character Status`——对于任何在上一个镜头中但不在这个镜头中的角色，请说明他们在屏幕外的位置和原因（例如`Mia — exited frame-left, last seen holding apple basket at door-frame`）。
  - `Lighting Baseline`——从场景卡继承的键/填充/边框方向，加上每个镜头的任何修饰符（例如`key: warm overhead, fill: cool bounce right, modifier: window-backlit silhouette`）。
  - 加上身份绑定：准确的批准角色卡名称和准确的批准场景卡名称。
  - **v1.1 add**:对于`dialogue`行，`Character Positions`块必须在屏幕上说话者的行旁边显式标记`SPEAKER`，而对于其他所有屏幕角色，则必须标记`non-speaker mouth: closed`。
- 钩子类型：来自受控受控词表的一个简短标签，例如`visual-joke`、`reversal`、`suspense`、`tender`、`chase`、`reveal`、`callback`、`expression-beat`。用于每集钩子分布自检。
- 拍摄说明：镜头尺寸、摄像机运动、荷兰角设计、性能风格、SFX、负提示、视频模型生成说明（默认为 H3;如果显式选择了其他模型，请在检查功能后调整其提示），以及所需的`Per-Second Directives`子部分。子部分必须将镜头分解成秒级指令，如`0–1s`、`1–2s`、`2–3s`;对于亚秒级关键节拍，使用`2.0–2.5s`风格标记。每秒指令必须涵盖所有所需的六个元素（v1.1 添加了元素 6）:
  1. 动作/姿势/表情（压缩/伸展、预期、超拍、适用时的后续动作）
  2. 镜头运动（推/拉/平移/倾斜/手持摇晃/锁定/轨道）
  3. 空间位置（人物在哪里，他们拿着什么，画面中有什么地标）
  4. 音频提示（旁白/对白/SFX/呼吸/沉默——或`silent`，如果是有意为之）
  5. 切换到下一秒或下一个镜头（这一秒锁定了下一个镜头的哪种状态）
  6. **v1.1:口型状态**——对于每个屏幕角色，标记`mouth: open/closed`，以及哪个角色是此刻的说话者（例如`mouth: Mia open (speaking), Grandma closed (listening)`）。对于叙述秒，每个屏幕角色的口型必须是`closed`，而且屏幕上的说话者（如果有的话） 根据定义是在倾听，而不是说话。
- **音频和对白轨道**（v1.1 升级版）:镜头的完整音频脚本，按时间顺序排列，与每秒提示分开。字段：
  - `Narration`——带时间范围的旁白文本（如果没有旁白，则省略；当行的音频模式为`narration`时为强制性）。
  - `Dialogue`——行、说话人、音色、时间范围。`speaker`字段必须使用角色卡中的准确批准角色名称。
  - `SFX`——按键音效，时间锚定。
  - `Performance Note`:
    - **v1.1: `narrator-mouth-closed: true`**——对于`Narration`所涵盖的任何一秒钟，都是强制性的。根据定义，旁白者是在屏幕之外的；屏幕上的角色在这几秒钟内必须保持闭口，只有表情变化（眉毛、眼睛、下巴紧绷） 才能反映叙述。
    - **v1.1:`expression-path`**——对于每一秒的旁白，列出屏幕角色的表情节拍（例如`0–1s: brows relax, eyes drift; 1–2s: brows knit, jaw tightens; 2–3s: lips press, gaze drops`）。这是音频对的视觉部分，可以防止屏幕角色在旁白时看起来死气沉沉。
    - 对于屏幕对白秒，列出每一句带有`eye-line`和`body-action`变化的对白（已在 v1.0 中，保留在 v1.1 中）。
    - **v1.1: `speaker-binding`**——对于对话秒，显式声明此秒哪个角色卡是说话者；视频模型使用这种方式进行提示绑定。
- **音频模式 (v1.1 NEW):每行四个值中的一个，从受控词表中选择：
  - `narration`——画外音承载镜头；屏幕上的嘴巴保持闭合。
  - `dialogue`——银幕角色说话；适用单声道规则和反应切换模式。
  - `mixed`——旁白和银幕对白都出现在这个镜头中（罕见；通常意味着主角对白伴随开场/结尾旁白；将其视为`dialogue`，以便快速塑造，并添加`mixed-segment`音符）。
  - `silent`——没有旁白和对白；只有 SFX 和环境音频。

全面规则：

- 每个镜头必须自然地通过`Continuity Handoff`列继承上一个镜头的图像状态，并在同一列中设置下一个镜头。
- 每一行镜头必须包含每秒的指令，涵盖从第一帧到最后一帧的整个镜头持续时间，包括动作、姿势、表情、摄像机运动、空间位置、声音提示、口型状态 (v1.1)**和连续性切换。
- 每秒指令必须足够具体，以直接生成分镜面板；避免模糊的时间安排，例如没有身体、摄像机或道具细节的 “继续移动”。
- 表演必须夸张而富有弹性，要符合迪士尼风格的挤压和拉伸、预期、过度拍摄、后续、重叠、弧线、快速姿势变化和清晰的喜剧轮廓。
- 镜头尺寸必须在特写/极度特写和其他必要的取景之间切换；避免重复取景。
- 荷兰角倾斜的构图必须设计成追逐、不平衡、突然或滑稽的节奏。
- 只有在用户明确要求的情况下才能使用对话语言；否则，请使用最小的非语言特定反应，或将对话标记为可选/待确认。
- 对于包含旁白或对话的镜头，角色说话的每一秒都必须记录下嘴巴是张开还是闭合；默认情况下，对于屏幕外的旁白是闭合的，对于屏幕上的对话是开放的。*v1.1 规定这是强制性的，不是可选的。*
- 一个离开画面的角色必须在`Exited Character Status`中至少被跟踪一个镜头，然后在他们连续两个镜头明确离开舞台后被删除。

### v1.1 口型同步安全规则（适用于所有行，无论音频模式如何）

这些是防止角色混淆的核心防御措施。违反其中任何一条都是自我检查的严重失败。

1. **对话行的单声道规则**:每一行`Audio Mode = dialogue`或`mixed`中最多可以有一个屏幕角色在任何给定的秒钟内张着嘴**。如果两个角色需要以相同的节奏说话，可以将它们分成两个单独的镜头，中间用`Continuity Handoff`剪切——不要将它们塞进同一行。
2. **反应行的单声道规则：在一个反应行（没有人说话的场景） 中，允许多个角色出现在屏幕上，但他们的嘴巴在整个行中都必须保持`closed`。
3. **非说话者口头禁止规则**:在任何包含`Audio Mode = dialogue`或`mixed`的行中，每个屏幕上的非命名说话者角色必须在该行的每一秒都保持`mouth: closed`。视频提示必须强制执行此规则（参见`model-selection.md`）。
4. **说话人绑定规则**:对于任何`dialogue`行，`Reference Anchors > Character Positions`块必须在说话人行旁边标记`SPEAKER`,`Audio & Dialogue Track > Performance Note > speaker-binding`字段必须以准确的角色卡名称命名说话人。这两者都是必需的。
5. **反应切换模式 (v1.1)**:任何包含`reveal`/`reversal`/`expression-beat`钩子的`dialogue`行必须是:(a) 说话者的单声道特写，或 (b) 说话者 + 听众组合，其中说话者位于前景/中心，而听众位于中景/背景。首选是说话者 - 肩膀 - 听众 (OTS) 框架。反向镜头（听众的反应） 自动成为后续行，包含两个角色的`Audio Mode = reaction`和`mouth: closed`——永远不要将反应与对话放在同一行。
6. **旁白表达路径规则**:每一行`Audio Mode = narration`必须在`Performance Note`中包含一个`expression-path`，用于描述旁白中屏幕角色的面部表情。根据定义，屏幕角色并不说话；他们的面部表情是旁白情感的唯一渠道。
7. **一秒钟内没有重叠的音频 (v1.1)**:没有一个每秒指令可以同时包含`Narration`和`Dialogue`。如果脚本需要重叠，将优先级较低的第二个指令（通常是对话） 推送 0.3-0.5 秒，并使用`Handoff`字段标记切换。
8. **没有跨角色声音流失**:`narration`秒从不使用任何银幕角色的声音，`dialogue`秒也从不使用旁白的声音。这些是最终混音中的不同音频通道。

### v1.1 音频模式分发规则（适用于整个表）

在步骤 0 中选择的音频模式强制实现整个表格的目标分布。如果实际分布发生漂移，自我检查将失败。

**v1.1.1 注释**:对于 3D 动画短片，**两种主要模式是`silent`和`dialogue-led`**。`narration-led`是一种罕见的主动选择方式。如果用户未经询问就选择了`narration-led`，请在继续之前显示确认卡——大多数 3D 动画项目使用`silent`或`dialogue-led`效果更好，而真正需要在整个短片中使用第一人称旁白者的项目应该使用`half-narrated-short-drama`技能。

| 音频模式（第 0 步） | `narration`行 | `dialogue`行 | `silent` 行 | `mixed` 行 |
|---|---|---|---|---|
| `silent`（视觉 3D 动画的主要、推荐默认值） | 0% | 0% | 100% | 0% |
| `dialogue-led`（初级，建议在需要进行语音对话时使用） | ≤ 20% | ≥ 50%（建议 60%） | ≤ 20% | ≤ 20% |
| `narration-led`（罕见的主动选择，谨慎使用） | ≥ 50%（建议 60%） | ≤ 40%（建议 30%） | ≤ 20%（建议 10%） | ≤ 10% |

如果用户对建议分布的覆盖违反了规则，请在继续之前显示一张选择卡。

然后显示用户选择卡：

- 批准表格并进行自我检查（推荐）
- 调整镜头连续性
- 让动画更加夸张
- 调整特写/极限特写节奏
- 调整荷兰角设计
- **v1.1:重新平衡音频模式发布**（仅在发布偏离目标时显示）

## 步骤 5.5:镜头表自检关卡（强制，v1.1 = 七次检查）

在转到分镜脚本之前，请检查已批准的镜头表和记录通过/失败/未经验证/不适用于受影响的行和证据。检查失败是一个发现，不允许无休止地修改文本或生成任何图像/视频。仅在用户批准的文本编辑范围内进行局部更正，然后重新检查一次；未解决、模糊或范围变化的问题需要报告和决定，然后才能进行进一步工作。

**v1.1:自我检查有七个必要的检查**（以前是六个）。新的第七个检查强制执行音频模式和口型同步安全规则。

1. **钩子密度**:每个镜头都有一个`Hook Type`;每三个连续的镜头中至少有一个使用`reveal`/`reversal`/`callback`;开始镜头和结束镜头都带有强钩 (`visual-joke`/`reversal`/`reveal`/`suspense`/`tender`)。
2. **单次拍摄持续时间**:每次拍摄不得超过 15 秒。如果一个节拍需要更长时间，请将其分割。
3. **每个镜头的角色计数**:没有一个镜头包含超过三个重要角色（定义为具有屏幕动作或对白的角色）。**v1.1:对于`dialogue`行，屏幕上的说话角色计数最多为 1。**
4. **空间锚继承**:对于每个包含两个或更多镜头的室内场景，下一个镜头的`Fixed Landmarks`和`Lighting Baseline`必须与前一个镜头相匹配，或者包含显式的连续性音符（例如`door-frame moves from right third to center as camera orbits left`）。
5. **每秒指令覆盖**:从`0s`到拍摄持续时间的每一秒都由`Per-Second Directives`条目覆盖，每个条目都包含所有**六个必要元素 (动作/姿势/表情、摄像机、空间、音频提示、**口型状态 (v1.1)**、切换)。允许使用`2.0–2.5s`等亚秒级节拍，但不得留下任何时间间隔。
6. **交叉镜头连续性**:逐行阅读`Continuity Handoff`列会产生一个连续的链条——没有一个镜头从与前一个镜头结尾相矛盾的状态开始。任何镜头如果改变了眼线、角色位置、道具状态或灯光，都必须明确标记这个改变（例如`HARD CUT — time skip: 2h`）。
7. **v1.1 新增内容：音频模式 + 口型同步安全检查**——以下七项检查的结合。任何失败都是严重的失败。
   - **7a. 音频模式发布匹配步骤 0 选择**（参见上面的发布表）。
   - **7b. 每一行都有一个来自受控词表的有效`Audio Mode`值**。
   - **7c.每行每秒的`Mouth State`与其`Audio Mode`**一致：
     - `narration` 行：每个屏幕角色每秒都有一个 `mouth: closed`;该行包含一个 `expression-path` 演奏音符。
     - `dialogue` 和 `mixed` 行：每秒最多只有一个屏幕角色具有 `mouth: open`，而这个角色就是指定的说话者。
     - `silent` 行：每个屏幕角色每秒都有 `mouth: closed`。
   - **7d. 每个`dialogue`行在`Performance Note`**中设置了`speaker-binding`，在`Character Positions`中设置了`SPEAKER`标记。
   - **7e. 每个带有`reveal`/`reversal`/`expression-beat`钩子的`dialogue`行都使用单说话人或 OTS 帧**，反应（如果有） 将在后续行中处理。
   - **7f。没有每秒指令同时包含`Narration`和`Dialogue`。**
   - **7g。如果步骤 0 音频模式为`narration-led`，则旁白秒数为非零，如果步骤 0 音频模式为`silent`或`dialogue-led`，则为零。**对于 3D 动画短片，旁白秒数应该很少见；如果选择了`narration-led`，请在批准前再次检查该选项。

如果所有七个都通过，请在画布表节点的顶部放置一个`shot-table self-check: passed`印章，并显示用户选择卡：

- 通过自我检查并绘制分镜（推荐）
- 显示自我检查细节
- 审核失败的检查
- 重新运行自检

如果任何必要的检查失败或未经验证，请不要将表表示为已通过或启动依赖媒体生成。列出受影响的行、影响和证据；保留当前表和所有未受影响的已批准素材。提供本地文本修复、范围修订、明确标记的仅审核交付或停止。通过自我检查不代表授权进行额外的图像/视频尝试。

对于修订，更新仅限于受影响的行、匹配的分镜部分以及实际无效的切换。重新检查相邻的过渡和受影响的全局约束，默认情况下不重写整个表。拆分行、更改持续时间/播放/音频模式或更改所需的节拍需要明确的范围审批。如果现有剪辑可能受到影响，请先进行比较，并在`fallback-policy.md`下仅提出必要的针对性工作；不要自动重新生成它们。文本编辑和镜头拆分不会重置同一问题的累积尝试记录。

在授权的本地变更后停止仅文本修复，如果问题仍然存在，或者在用户暂停前、证据不足或需要的范围变更，则重新检查一次。提交剩余的问题，而不是循环检查，直到所有七次检查都通过。保留 main-Skill 项目锁定；遗留示例不授权修复时更改音频模式。
