# 短剧剧本精修

先读当前草稿，圈定用户要求修改的集数、场景、人物或问题。诊断只针对文本中的具体证据，指出问题出现的位置及其造成的阅读或拍摄后果，再修改。不要因为一个通用规则就把有效的安静场、长句或留白一律删掉。

## 逐项核对

1. **因果**：冲突是否来自人物既有目标和限制？反转前是否已有可回看的线索？
2. **推进**：每次对抗是否产生新信息、新行动或新代价？同一件事是否换说法重复争论？
3. **可见性**：动作能否拍到，重要证据是否在画面或对白中清楚出现？不要用“眼神复杂”“气氛骤变”等空描述代替事件。
4. **台词**：不同角色是否有自己的立场和说话方式？已知背景是否被生硬复述？关键利害是否足够直白，让观众能跟上？
5. **连续性**：人物知情范围、地点、关系、道具和世界规则是否与前文一致？
6. **交付**：如果用户要求分场剧本，产物是否仍只是剧情梗概；如果要求局部精修，是否误改了其他段落？
