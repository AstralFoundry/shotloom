# 单集正文写法

## 从分集要点到场景

写前确认该集开始时的人物状态、这一集的具体目标、主阻力、至少一次导致局面变化的行动，以及结尾留下的结果或问题。缺少既有大纲时可以直接据用户设定写作，不把“先做全剧圣经”当作开写门槛。

每个场景回答：谁主动做什么、另一个人如何阻止或借力、观众能看见什么证据、结束时谁的处境改变了。相邻场景要在信息、关系或代价上递进；只换地点重复同一争论的场景应压缩或重写。

## 可拍摄正文

可沿用用户格式；没有格式时使用简洁排版：

```text
第 X 集
场景 1｜地点｜日/夜｜内/外
出场：……
△ 能拍到的动作、物件变化或人物反应。
人物：台词。
△ 另一方采取行动，局面发生变化。
```

- 动作写镜头和演员能够表现的事实，抽象心理要落到可观察的选择、停顿、物件或关系行为。
- 台词承担争取、隐瞒、试探、逼迫或反击；如果只是替观众讲设定，优先改成可见事件与角色之间的利害。
- 专业术语、世界规则和关键证据要让观众理解它们对人物的具体后果；保留题材语言，但别让悬念依赖未解释的黑话。
- 开头与结尾依剧情功能处理。悬念可以是即将发生的选择、已揭示信息的后果，或一个尚未解开的矛盾；不强制每集停在半句话。
- 时长只在用户要求时估算，并说明依据；剧本字数不能单独保证实际成片时长。

多集连写时，写完一集先核对已发生事件，再写下一集。分批 `append` 到草稿时保留原文和集数顺序；全部请求范围写完后才宣告完成。
