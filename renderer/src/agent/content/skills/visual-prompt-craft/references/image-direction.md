# 图片提示词导演方法

为人物在剧情中的画面、场景参考、道具参考、跨镜头分镜页、分镜静帧或动作宫格写图片提示词时读取。人物身份板的四区域版式由 `character-board` 决定；本文件不改变该版式。先弄清这张图要交给后续哪个镜头、负责固定哪些事实，再写完整画面。

## 把字数花在决定画面的事实上

先写最能改变成像结果的选择：主体的可辨认外形、正在呈现的动作姿态、摄影机与主体的关系、场景中几个稳定地标及它们的相对位置、项目媒介和真实光源。年龄、发型、衣服、配饰若决定身份，就写到后续视角仍能辨认；不靠姓名、职业或“华服”让模型自行猜造型。剧本未规定的细节可以设计，但设计后应作为该角色或场景的稳定锚点供下游复用，而非下一节点重新设计。

单格图片节点描述一个能同时看见的时刻。从剧本制作视频时，单镜时间板与单镜镜头板各是一张多格图：前者逐格写动作时间状态，后者逐格写观众获得的新信息、视觉焦点和构图；两板不能共用同一节点或同一提示词。先给格数、布局与顺序，再写每格的具体时刻，不把整页压成一幅画。跨镜头总览页只在用户明确要求时制作。人物手与道具的接触、身体朝向、视线目标、所在通道和背景地标必须在同一空间成立。场景参考用稳定结构、材料和陈设建立空间；多视角场景板的各格共享同一平面布局。

## 让参考图各司其职

写提示词前查看实际可连接的图片与它们的可见内容。人物图提供脸、发型、体型和服装身份；场景图提供建筑、入口、物件位置及光向；道具图提供形状、材质与状态；已有镜头图提供某个确定姿态和构图。提示词交代当前画面从每张参考继承什么、哪些剧情状态可以改变，以及新机位应如何看到同一对象。参考图未连接或尚未生成时，把它写成待验证的设计约束，不能声称模型已收到。

画风先取项目已定的媒介、线条或成像方式、色彩、材质和光影。同一项目的人物、场景、道具和分镜使用兼容的视觉语言；“设定板”“电影感”“高细节”只说明用途或质量，不能把二维画风改成真人摄影或三维渲染。用户给出的参考图确定了媒介时，优先描述需要延续的可见特征，不再叠加相冲突的风格词。

## 交给生成节点前

完整成品 prompt 应让读者仅凭文字和实际连接的参考图就知道：画面中的谁或什么、外形和服装要保留什么、人物与场景地标如何相对、相机从哪里看、当前动作停在哪个姿态、光从哪里来，以及哪项特征绝不能漂移。排除项只针对本图的风险，例如错误视角露脸、重复道具、门窗换位或故事板格线；不要让长串通用负面词取代正面描述。模型的画幅、分辨率和参考槽位按目录配置，不能只写在 prompt 里。

写入前先形成简短的 `reference_manifest`：按真实输入边顺序记录人物、场景、道具和用途；提示词只引用实际可见的职责，不用姓名或手写 `@` 代替图片。人物板必须写清正面、侧面、背面和脸部近景各自承担的身份信息；侧面和背面不凭空补脸，服装、发型轮廓和配饰位置要跨视角固定。场景板必须固定门窗、入口、主要地标、光源和可走通道。

图片节点的成品文本按“媒介与画幅 → 参考职责 → 全局身份/空间锁定 → 当前单一时刻或格序 → 光线与材质 → 针对性排除项”组织。每格只画一个可见姿态；多格板写清格数、布局、阅读顺序和相邻格的具体增量，不能只给抽象的“动作推进”。输出前核对参考数量、格数、画幅和模型输入容量，缺素材或超容量写入待修信息，不把一张单图当作板已完成。
