# 剪辑完成与视觉核验清单

报告剪辑任务完成前必须：

1. 调用 `video_project_diagnostics`。空隙、片段重叠、缺失媒体等错误级问题必须为零；有意保留的例外要在结果中说明。
2. 在改动位置调用 `video_project_frame` 或 `video_project_view` 并实际查看返回画面。转场要查看接缝，字幕要查看文字可见帧，调色和特效要查看代表性时刻。
3. 调用 `video_project_view` 将播放头停在最能展示结果的位置，让用户可以直接核验。
4. 报告实际修改和新的项目时长；如果工具回执包含不可撤销操作或未写入项，必须明确告知。

没有渲染并查看，就不能声称视觉结果已经检查。
