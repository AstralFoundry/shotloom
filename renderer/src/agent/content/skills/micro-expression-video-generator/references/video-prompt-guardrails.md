# 视频提示护栏——视频中的微表情表现

每当确认的性能提示包转换为视频生成提示时，都可以使用这个文件。这些防护措施可以防止常见的漂移：不想要的剪辑、意外的微笑、过度表演、身份漂移和情感极性的变化。

## 1.镜头连续性锁定

对于来自静止图像的微妙微表情视频，默认为单个连续镜头。然而，当用户明确要求更改摄像机、多个镜头、场景转换、反应切换，或者当创意任务明显需要镜头运动或镜头变化来表达表演时，镜头变化是允许的。

默认的单镜头措辞：

- 默认全程单镜头，一镜到底。
- 默认不切镜，不换景别，不转场，不插入反打，不改变机位。
- 默认保持原图特写构图，只允许面部、眼神、呼吸、头颈和必要的轻微身体微动。

覆盖规则：

- 如果用户明确要求镜头变化、运镜、切镜、反打、转场、多镜头，或任务本身明显需要镜头变化来完成表演表达，可以设计镜头变化。
- 发生镜头变化时，必须说明每个镜头的新信息：新的情绪阶段、新的视线关系、新的身体反应、新的空间关系或新的叙事反馈。
- 不要为了凑时长而切镜；镜头变化必须服务表演。

当使用单个镜头时，不要写`镜头1 / 镜头2 / 镜头3`;在同一个镜头中写入时间节拍：起始状态→微泄露→压回→收束。当使用多个镜头时，要清楚地说明为什么每个镜头的变化对表演都是必要的。

## 2. 情绪极性锁定

在制作视频之前，要识别并保护目标的情感极性。

例如：

- 失恋的冷静=悲伤 + 镇定 + 麻木的清醒。这不是解脱，不是宽恕，不是温柔的幸福，不是苦乐参半的微笑。
- 爱而不得=渴望 + 克制。这不是调情或害羞的甜蜜，除非有人要求。
- 强装镇定=控制背后的焦虑或悲伤。这不是自信。
- 笑容崩溃=微笑作为失败的面具。这种微笑必须破裂或变得不稳定；它不是温暖的喜悦。

如果目标包含悲伤、分手、失落、背叛、后悔、麻木或克制，绝不要让结局变成温暖、宽慰或微笑，除非用户明确要求。

## 3. 口角安全规则

口语表达是高风险的，因为视频模型经常将模棱两可的口角语言转换为微笑。

请避免使用这些短语来表达悲伤/克制，除非用户想要微笑：

- 嘴角撑住
- 温和
- 体面微笑
- 苦笑
- 淡淡笑
- 礼貌笑
- 释然
- 嘴角微微上扬
- 微笑、浅笑、温和的微笑、柔和的微笑、苦乐参半的微笑

更安全的替代品：

- 唇线维持平直
- 嘴角不上扬
- 嘴角不笑也不明显下垂
- 口周肌肉轻微收紧后恢复中性
- 下颌一侧轻轻绷住
- 双唇保持闭合，只有极轻的压力变化

对于损失/悲伤提示，明确说明:`嘴角全程不上扬，不出现微笑、苦笑、释然笑或礼貌笑。`

## 4.微表情时序结构

对于微妙的表演，在一个镜头中使用四个节拍：

1. **基线**——保留源图像的表情和取景。
2. 泄露——一个非常短暂的可见线索：迟来的眨眼、眼皮沉重、目光涣散、吞咽、呼吸急促、下巴紧绷。
3. 恢复——人物抑制了这个暗示：眉头舒展，嘴唇恢复平静，呼吸变得浅薄。
4. **后状态**——面部恢复中性，但感觉变了：更安静、更空洞、更疏离、更戒备。

后状态必须与情绪保持一致。对于分手/悲伤：更安静、更空虚，而不是更温暖。

## 5. 消极引导纪律

仅在真实风险中使用负面指导，但在转换为视频时也要包含，因为模特往往会夸大行为。

对于有约束的分手提示，包括：

- 不哭，不流泪，不皱眉，不张嘴，不微笑。
- 不切镜，不转场，不改变脸型、发型、服装、背景。
- 不出现明显戏剧化动作，不低头崩溃，不摇头。

## 6. 前代自我检查

在调用视频模型之前，请检查：

- 当用户想要一个连续的微表情时，我是否不小心写了多个编号镜头？
- 我是否包含了可以解读为微笑的词语？
- 最后一拍是否保留了预期的情感，还是逐渐变得轻松/柔和？
- 我是否保留了源图像的身份、构图、姿势、服装和背景？
- 可见线索是否足够小，以适应所选的强度水平？
- 如果缺失，我是否询问了持续时间和宽高比？

如果任何答案都不安全，请在生成之前重写视频提示。
