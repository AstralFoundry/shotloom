# 高潮重置模式——高压微表情结构

使用此参考文件进行情感强烈的特写表演，用户需要强烈的紧张感，而不需要依赖大幅度的肢体动作。不要编码任何武器、战术、伤害或现实世界中的暴力指令。此文件仅捕捉可转移的动作和视频提示结构。

## 核心模式

一个高冲击力的特写镜头可以这样构建：

1. **压缩基线**——面部静止，下巴微微收紧，屏住呼吸。
2. 第一次开口——一个微小的非自主信号：目光颤抖，迟来的眨眼，眉毛抽搐，嘴角抽搐。
3. 内心冲突——目光游离，嘴巴开始说话但又停住，喉咙吞下了话语。
4. 身体泄露——眼睛湿润，下眼睑紧张，呼吸变得急促，下巴或下嘴唇颤抖。
5. 高潮重置——眼睛突然或短暂闭上，呼吸急促，眼皮颤抖；重新睁开时显示出情绪状态的变化。
6. 余震抑制——嘴唇紧闭，下巴稳定，眼睛保持湿润，情绪被控制而非释放。

## 10-12 秒特写的 2 秒密度结构

- 0-2 秒：建立静止基线并控制呼吸。
- 2-4 秒：第一次可见的裂缝，非常小且非自主的。
- 4-6 秒：目光移动，话语被吞回/意图被打断。
- 6-8 分：湿度、呼吸不稳定、下巴/嘴唇/下巴泄露。
- 8-10 拍：闭合/重置拍——眨眼/闭眼 + 呼吸 + 重新睁开。
- 10-12 拍：余震，情绪被控制在脸上，而不是表现出来。

对于 6-7 秒的片段，将相同的逻辑压缩成 5-6 拍：

- 基线→崩溃→冲突→泄露→重置→余震。

## 有用的行动提示

- 眼神一颤 / gaze tremor
- 焦点飘移后被强行拉回 / focus drifts then is forced back
- 眉心浅蹙后展开 / shallow brow pinch then release
- 唇角短促抽动 / brief lip-corner twitch
- 嘴唇微张欲言又止 / lips part as if to speak, then stop
- 喉咙轻滚 / throat swallow
- 下眼睑绷紧 / lower eyelids tense
- 眼眶发湿但不立刻流泪 / eyes moisten without immediate tears
- 猛然闭眼不到半秒/眼睛紧闭不到半秒
- 眼皮轻颤 / eyelids tremble
- 睁眼后情绪状态改变/重新睁开揭示情绪状态的变化
- 唇线压住/嘴唇按压以抑制情绪

## 提高纪律性

- 使用定时节奏，而不是笼统的情绪标签。
- 保持最小的宏观动作；在眼睛、呼吸、喉咙、嘴唇、下巴和眨眼的时机上注入密度。
- 高潮并不总是尖叫或崩溃；它可能是短暂的闭眼和呼吸重置。
- 余震应该将情感向前推进。不要过快地重置为中性。
- 永远不要包含任何来源片段中有害的操作细节。只翻译表演节奏和情感结构。
