# 后台 Dreamcore

当用户想要运行 “我的后台/梦核心测试/将这个角色或场景转换为后台/生成我固有的阈值空间” 流程时，可以使用这项技能。核心可交付的是一个个性化的后台创作包:**参考图像 +4 个沉浸式答案 + 后台 0 级语法**，它可以生成空间文件夹卡片、AI 图像生成简短、可选的 BGM 方向，并根据用户请求可选地继续生成图像或视频。

目标不是心理诊断，也不是一般的恐怖意象。而是要创造一个真实、廉价、空洞、重复、褪色、过滤过的、克制而荒谬的个性化空间切片。

## 范围

当以下情况触发：
- 用户上传一幅肖像、人物、宠物或物体图像，并希望 “这个主题的后台/固有空间/梦想核心空间”。
- 用户上传一个房间、街道、商店、校园或办公场景的图像，并希望将其设置为后台化或 dreamcore 化。
- 用户说 “测试我的密室/我的阈值空间/固有空间/梦想核心测试”。
- 用户要求提供档案卡、AI 图像简介、BGM 方向或直接图像/视频生成。

不要触发以下操作：
- 纯后台学习问答，例如 “什么是第 0 级”。
- 通用恐怖怪物图像或血腥场面。
- 未经测试、参考图像或个性化输入的普通后台图像。

## 第 0 步：确认图像输入

这个技能需要一张上传的图片：肖像/人物/宠物/物体/场景。

如果用户还没有上传图片，请在开始测试之前用自然语言询问一个：

> 请先上传一张图片：一个人、一个角色、一只宠物、一个房间、一条街道、一家商店或任何场景。我将使用它和 4 个问题来创建你的个性化后台空间。

上传后，对图像进行分类：
- **角色图像**:包含一个人、动物、虚拟角色、宠物或清晰的肖像主体。目标是 “该主体进入或对应的后台空间”。
- 场景图像：房间、街道、商店、校园、办公室、公共空间。目标是 “将原始场景转换为等级 0”。
- 混合图像：包含人物和场景。如果用户尚未指定重点，请问一个关键问题:“优先处理人物还是场景？” 如果用户已经指定，请直接继续。

图像读取规则：
- 如果可用，请重复使用可靠的现有媒体说明；否则，请自行分析参考素材。
- 保持分析专注于这项任务：对于人物图像，提取身份轮廓、姿势、衣着剪影和可转移的情绪；对于场景图像，提取空间结构、关键物体、材料、门窗、走廊、光源和 0 级可适应元素。
- 不要阅读与任务无关的颜色细节；颜色已经由参考图像本身携带。

## 步骤 1:4 个沉浸式问题

在一次分组互动中准确地提出 4 个问题，而不是逐个打断。每个问题都提供 A/B/C/D 选项。

保持 5 个内部维度：
- `boundary`:负面=开放，正面=封闭
- `time`:negative = 冰冻，positive = 流动
- `presence`:negative = 孤立，positive = 痕迹
- `light`:negative = 自然，positive = 人为
- `order`:negative = 有序，positive = 混沌

如果用户说 “跳过问题/直接生成/你来决定”，不用问就切换到快速模式。

### Q1:入口

提示：您上传的图像开始感觉不对劲。在背景的某个角落，出现了一条不应该存在的走廊。灯亮着，但里面没有声音。您将——
- A. 走进去看看它通往哪里:`boundary -2, time +1`
- B. 站在门口长时间观察:`boundary +2, order -1`
- C. 在入口处留下一些东西作为标记:`presence +2, order -1`
- D. 进入前关闭附近的灯:`light +2, order +1`

### Q2:重复

提示：走了一段时间后，你注意到墙壁、地毯和天花板开始重复出现。虽然不完全相同，但足够相似，让你怀疑自己回到了起点。你的反应是——
- A. 加快速度打破循环:`time +2, boundary -1`
- B. 停下来寻找模式:`order -2, boundary +1`
- C. 接受它，继续慢慢走:`time -2, presence -1`
- D. 在墙上留下只有你能认出的记号:`presence +2, order +1`

### Q3:光

提示：前方有两种光。一种像古老的荧光灯管——扁平、暗淡、嗡嗡作响。另一种像是从远处门口漏出的光——一个出口，或许是个陷阱。你靠近——
- A. 荧光灯——至少它是真实的:`light +3, order -1`
- B. 门口的光——也许那里有什么变化:`light -1, boundary -2`
- C. 都不要；留在阴影里:`presence -2, boundary +1`
- D. 先找到灯的开关:`order -2, light +1`

### Q4:保留什么

提示：你意识到这个 Backrooms 是根据你上传的图像生成的。它不会完全复制原件——它只会保留最重要的一件事。你想让它保留——
- A. 主题本身：人物、角色、宠物或物体:`presence -1, boundary +1`
- B. 场景结构：房间、走廊、门、空间关系:`order -2, boundary +1`
- C. 情绪：图像给人的感觉:`time -2, light -1`
- D. 细节：一个物体、姿势、轨迹或角落:`presence +2, order +1`

## 步骤 2:合成后台化方案

在 4 个问题之后，将维度得分相加，并结合图像类型，生成后台化方案。

### 人物 - 图像计划

保存：
- 主体身份、轮廓、姿势、衣着或关键肢体语言。
- 默认模式：主体可能出现在后台空间内，看起来就像真的在那里拍摄的一样。不是动画海报或商业角色海报。
- 如果用户请求 “后台怪物/实体/追逐/恐怖化”，主体可能会转化为后台实体，但保留原始轮廓、姿势、衣服触感或可识别的来源。
- 如果用户不希望主体出现在屏幕上，可以在没有主体的情况下创建 “对应于该主体的固有 Backrooms 空间”。

生成方向：
- 主体或转化后的实体坐在一个零级风格的空间中，就像被监视器、旧数码摄影机或意外拍摄的快照所捕捉到的那样。
- 微调空间的五个维度：封闭/开放、冻结/流动、孤立/痕迹、自然/人工、有序/混沌。
- 即使在怪物模式下，空间仍然是画面的主要主题；避免过度夸张的生物海报能量。

### 场景图像设计

保留：
- 原始场景的空间结构、关键物体或主要情绪。
- 将原始元素转换为级别 0:图案墙纸、低矮地毯、天花板网格瓷砖、荧光灯面板、重复的隔断墙、空白迷宫布局。

生成方向：
- 原始场景看起来像是被吞噬进了后厅 0 级。
- 优先考虑摄影现实主义；不要成为概念性说明。
- 1-2 个最容易辨认的原始元素可能会被保留为不协调的异常。

## 第 3 步：后台 0 级视觉语法

每个生成的图像必须首先建立 0 级，然后将其嫁接到用户图像元素上。

核心语法：
- 复古图案的墙纸，低矮的商业地毯，矿物纤维天花板网格瓷砖。
- 隐藏式矩形荧光灯面板，单光源荧光色彩投射。
- 沉重的矩形柱子或隔墙在整个空间中重复出现。
- 空无一人，或者只有一个孤立的主体。
- 墙壁直接与地板和天花板相连，没有普通的门、窗户、通风口或家具。
- 深远的视角、遥远的角落或低矮的门廊暗示着无限的延伸。
- 感觉像是一张真实的照片，一台老式数码摄影机，或者仍然是监控。

后台过滤器：
- 黄色/绿色荧光偏差，低动态范围，老式摄影机白平衡漂移。
- 压缩废弃物，监控/VHS 颗粒，轻微过度曝光，潮湿的霉菌空气。
- 廉价的室内装饰——平凡却令人不适。

克制的荒谬性：
- 出口逻辑消失了。
- 门或走廊的位置不合逻辑。
- 房间里的轻微比例误差。
- 墙壁、柱子或隔板重复出现的时间过长。
- 日常物品孤立地出现——一把折叠椅、一本空白的书、上传图片中的一个小物件。

避免：
- 概念插图、奇幻建筑、魔法能量、过度电影化的感觉。
- 让像 “图书馆/游泳池/购物中心/课堂” 这样的主题超越等级 0。
- 图像上的文字、标题、字幕、标志。

## 步骤 4:输出空间文件夹卡

首先输出一个简短的结果卡，然后询问用户是否继续进行图像生成。如果用户已经说 “只需要生成/制作图像/制作视频”，跳过确认直接进行生成。

建议的卡片结构：

```text
═══════════════════════════════
       Y O U R   B A C K R O O M S   S L I C E
═══════════════════════════════

RM-XXXX ▸ Space name
English codename

Source image type: character / scene
Kept core: subject / structure / mood / detail

Space description: 3-5 sentences
Backrooms filter: 1 line
Anomalies: 1-2 lines

"Short tagline"
═══════════════════════════════
```

同时输出：
- AI 图像生成简介：用自然语言描述；不要将其视为固定模型提示词。
- 可选 BGM 方向：例如低频荧光嗡嗡声、暖通空调管道噪音、远处的脚步声、梦核环境床。
- 五维趋势的总结。

将卡片作为可审阅的文本提交，标题为 “后台切片文件夹”。

## 第 5 步：图像生成

当用户请求一个图像时，从自包含的创意简介中生成它。保留上传图像的传输形状，除非用户确认其他平台或帧形状。当用户选择的模型能够满足简介时，尊重它；否则，选择一个当前可用的模型，它具有相同的可见功能，并在切换之前解释材质差异。

创意简报必须包括：
- 任务是创建新图像还是转换参考资料
- 确认的交付形状
- 上传的引用，标记为人物/场景/混合
- 4 个问题的答案和 5 维倾向
- 0 级视觉语法、后台过滤、约束荒谬性规则
- 人物形象：保留主体身份/轮廓，但首先保留空间；如果怪物化，则保留原始特征
- 场景图像：保留场景结构或关键物体，并使其符合 0 级标准
- 最终图像必须看起来像一张真实的照片，而不是插图
- 用户的原始请求或解决后的自包含版本

## 第 6 步：视频生成

当用户请求视频时，请根据批准的参考资料和后台简报生成视频。将明确选择的模型、质量目标、持续时间或帧形视为已确认的需求。在更改任何可能明显影响结果的需求之前，请检查当前功能并提出请求。

后台追逐视频模板——可用于 “角色后台 - 怪物化/实体追逐” 请求：
- 视角：第一人称视角、手持视角、运行视角或类似监控的视角——而非第三人称视角的电影预告片。
- 场景：后台 0 级廉价的室内迷宫——复古墙纸，低矮地毯，天花板网格，荧光灯阵列，重复的隔断墙和柱子。
- 怪物：从上传的角色图像转变而来，保留原始轮廓、姿势感觉或服装线索，但变成了一个后厅实体。
- 动作：摄像机快速沿着走廊倒退或旋转并奔跑，实体从远处或拐角处逼近，在短片中形成清晰的追逐节奏。
- 图像质量：老式数码摄影机、VHS、监控画质、低动态范围、荧光色彩投射、压缩感、轻微运动模糊。
- 声音：如果所选视频模型支持原生音频，将环境声音、荧光嗡嗡声、脚步回声和空间压力描述为该生成的一部分。不要为相同目的创建重复的语音或音乐轨迹。
- 禁止字幕、图像文字、标志、电影海报感觉或过度夸张的生物闪烁能量。

## 快速模式

当用户说 “跳过问题/直接生成/你来决定” 时：
- 仍然需要上传图像。
- 默认答案为混合状态:Q1=B、Q2=C、Q3=A、Q4=auto（按图像类型）;默认 A 用于角色图像，B 用于场景图像，C 用于情绪特别强烈的情况。
- 直接从图像生成 “0 级化后台切片”。
- 如果用户明确要求直接生成图像或视频，请跳过中间确认。

## 输出

- 所有面向用户的内容都使用用户的语言。
- 将空间档案卡作为可重复使用的文本资源提交。
- 使用清晰的标签呈现一次生成的图像或视频；不要在最终响应中重复使用相同的资源。
- 如果生成了多个资源，请按档案、图像候选和视频输出对它们进行分组。

## 质量条

- 首先是 0 级语法；用户图像元素轻微移植。
- 真实、廉价、空洞、重复、褪色。
- 没有医学、个性或命运的判断。
- 结果应在社交媒体上分享，但不能看起来像商业海报。
- 生成的输出不得包含字幕或图像文本。
