# 主播口播制作

主播人像是必需素材，商品图片可以没有。若无法可靠区分人物与物品，必须先澄清，绝不能把商品图误作主播身份依据。

## 制作顺序

1. 内容策划：确定主播定位、受众、平台、传播目标、核心信息、表达方式、情绪节奏和场景方向。
2. 出镜形象：只连接原始人像，固定五官、脸型、发型、肤色及辨识点，仅调整取景、姿态、服装整洁度、照明和清晰度。
3. 空间方案：规划空间类型、背景陈设、主播位置、商品展示位、光线、色温与机位。
4. 口播镜头表：每个 Shot 写明时长、逐字台词、景别、构图、表情、视线、手势、商品动作、运镜和衔接。
5. 空镜场景：一处空间对应一个节点，不出现人物，不凭空加入商品，并预留主播区域。
6. 镜头总览：结合镜头表、人像、场景和商品素材，确保各格为同一主播、同一商品和相应空间。
7. 高清定帧：每个 Shot 单独建立图片节点，连接对应文本和构图锚点。
8. 连续口播镜头：等待所需高清帧、人像、场景或商品图片完成，再按 Shot 建立视频节点。逐镜高清图负责构图；身份特写、商品展示和重要空间分别保留可靠依据，只有经核验融合完整的低风险关键帧才能单独输入。提示词逐项映射参考职责，并安排台词口型、表情、手势、运镜与时长；内部输入适配由运行时自动完成。
9. 画布收束：全部片段完成后按 Shot 顺序排布。当前实现没有待剪辑时间线或汇总入口，不创建虚构节点，也不使用无语义连线表达顺序。

## 连续性要求

- 人物身份高于美化，服饰、配件和妆容必须跨镜连续。
- 台词应自然可说并严格对应脚本，口型、表情和手势服务语义。
- 商品包装、颜色、比例、标识与细节忠实于素材。
- 场景光向、色温、陈设及透视保持一致。
- 参考数量由 Shot 的身份、产品和空间风险决定，不固定为一张，也不能为了填满模型上限堆图；每项输入都要在提示词中说明约束职责。
- 默认考虑 9:16，但最终服从用户要求和能力快照，不硬编码模型。
- 所有节点按上表加载对应 Recipe 并填写 `recipeId`。

完成前评估：主播身份稳定，台词口语自然，表演可信，商品和场景连续，镜头表可执行，片段排列完整。
