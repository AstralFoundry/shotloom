# 时装展示规划师

当用户想要一个可重复的时装展示工作流程，而不是一次性的提示时，可以使用这项技能。该工作流程将服装参考或服装概念转化为一个锁定的 Final_Video_Spec、结构化服装分析、逐步服装确认、场景选择、分镜装订、六个面板的分镜预览、每件服装一个完整的 30 秒时装短片、匹配的背景音乐和最终装配。

## 第 0 步：锁定最终规格

首先创建`Final_Video_Spec.md`，并在任何下游生成之前锁定这些决策：

- 标题/项目名称
- 长宽比
- 目标持续时间和长度意图
- 视觉基调
- 输出语言
- 镜头路线:`Runway`或`Lifestyle`

此锁定对当前轮是永久性的。后续步骤不得重新决定路线。

### 路线锁定规则

从服装类型和用户意图中选择路线：

- **Runway**:高级定制服、正式服装、概念时尚、强烈的展示语言、克制的姿势、受控的表达
- 生活方式：休闲服、便装、日常服装、暖和服装、民族/传统外观、自然互动

如果路线模糊，就在这里解决它。不要把这个判断推迟到后面的阶段。

## 第一步：分析服装素材

如果用户提供服装图像或参考视频，提取并记录结构化信息，用于后续的分镜脚本和动作规划：

- 剪影：领子、袖子、下摆、裤子或裙子的形状
- 面料：纹理、光泽、透明度、重量、悬挂
- 颜色：主色、次色、图案色相/饱和度
- 运动物理学：面料如何下落、摆动或抵抗运动

将分析写成紧凑的结构化形式，以便后续步骤可以重复使用，而无需重新翻唱。

## 第 2 步：分阶段确认服装

每次进行一个子步骤。在每个子步骤之后，停下来等待明确的用户确认，然后再继续。

### 第 2A 步：生成技术服装单

创建一个水平的三面技术服装表，仅包含正面、侧面和背面视图。在这一步中，使用 2K 版 NanoBanana Pro，除非用户明确要求使用其他图像模型。

规则：
- 无模型
- 无背景场景
- 纯服装结构展示
- 强调接缝、封口、图案布局和施工细节
- 使用第 1 步中的服装分析作为视觉锚点

然后暂停并等待用户回复确认或修改请求。

### 第 2B 步：生成模型着装卡

只有在服装单确认后，才能根据它生成模型着装卡。在这个步骤中，使用 2K 版 NanoBanana Pro，除非用户明确要求另一个图像模型。

规则：
- 水平布局
- 左侧面板：面部特写/上半身肖像，用于识别身份和化妆
- 右侧面板：全身正面/侧面/背面视图
- 保护面料物理特性和服装挂饰
- 保持背景中性

对于多套服装或多个角色，按 A/B/C 顺序为每套服装生成一张卡片。

然后暂停并等待用户确认模型外观和面料保真度。

### 第 2C 步：仅以文本形式呈现场景候选方向

确认模型卡后，用纯文本提供 3 个场景候选说明。此处不要生成图像。

每个候选场景应包括：
- 场景类型
- 氛围
- 建议的照明方向/色温
- 为什么它适合服装和路线

如果用户已经指定了场景，请直接按照该方向操作，而不是提供候选场景。

然后暂停并等待用户选择候选人或提供自定义场景方向。

### 步骤 2D:生成空场景图像

确认场景方向后，为每个场景生成一个空场景图像。使用 2K 版 NanoBanana Pro 进行此步骤，除非用户明确要求使用其他图像模型。

规则：
- 无人
- 不准穿衣服
- 仅限环境
- 水平宽边框
- 保留光照、景深和负空间需求

对于多个场景，为每个场景生成一个锚图像。

然后暂停并等待用户确认场景外观和灯光，再进入分镜脚本。

## 第 3 步：设计分镜脚本并绑定资源

### 第 3A 步：宣布分镜约定

在生成任何预览图像之前，请写下关键元素和镜头列表。

关键元素必须包括：
- 要素特征：面部特征、肤色、化妆风格、头发以及其他必须与模特卡匹配的可见身份细节
- 元素服装：轮廓、面料、光泽、重量、关键构建细节、装饰、图案或特殊纹理
- 元素场景：确认的空间结构、光线方向、色温、对比度和负空间逻辑
- 元素道具：任何实际影响图像的配件或道具

还要定义镜头列表，包括镜头尺寸策略、运动类型和音频层需求。

### 第 3B 步：注册并绑定素材

在生成预览分镜之前，将已确认的模型装备卡和场景图像资源绑定到分镜元素。

规则：
- 将模型装备卡绑定到`element character`
- 将每个空场景图像绑定到相应的`element scene`
- 在绑定完成之前不要继续

### 第 3C 步：生成六面板分镜预览

使用绑定的角色和场景资源，生成单个六面电影分镜预览。使用 2K 版 NanoBanana Pro 进行此步骤，除非用户明确要求使用其他图像模型。

规则：
- 垂直 9:16 构图
- 3 行×2 列
- 每个面板代表一个核心拍摄节拍
- 保持所有面板与锁定角色、服装和场景一致
- 使用电影音色和清晰的镜头进度

然后暂停并等待用户确认构图、场景配对和拍摄节奏。

## 第 4 步：生成视频

确认六格式分镜后，生成一个完整的 30 秒时尚短片。使用MiniMax H3 作为默认视频模型，除非用户明确要求另一个视频模型。

规则：
- 使用六面预览作为主要参考
- 重复使用绑定的服装、角色和场景资源作为连续性锚。
- 除非用户之后明确要求，否则不要将视频分割成单独的镜头生成任务。
- 一套服装产生一个独立的视频单元

### 服装轮换规则

一轮等于一套服装 + 一个场景 + 一个分镜 + 一个 30 秒的视频。

如果用户后来更改了场景，请从步骤 2C 重新开始，并在现有的着装卡仍然合适时保留它。
如果用户后来更改了服装，请从 STEP 2A 重新开始，重新完成整个流水线。

## 第 5 步：生成 BGM 并组装

生成与服装风格和路线匹配的 BGM。

- Runway:室内爵士乐、管弦乐，或类似受控的高时尚评分
- 生活方式:Nu-jazz、lo-fi 嘻哈，或类似轻松的日常生活评分
- 传统/民族风格：使用民族乐器的当代编排
- 概念/技术外观：适合工业、极简或黑暗环境纹理时

然后将视频与批准的音乐和任何其他最终元素组合在一起。

## 步骤 6:返回结果并询问下一轮

清楚地按轮次和服装名称提交最终资料。每轮完成后，询问用户是否想要更改场景或下一轮的服装。

## 一致性规则

- 在第 0 步之后，永远不要重新决定Runway与生活方式。
- 绝不要在模型卡片和场景绑定完成之前生成分镜。
- 永远不要跳过步骤 2A、步骤 2B、步骤 2D 和步骤 3C 之后的用户确认暂停。
- 将所有参考素材都保存在同一套装备中，并与其他装备分开。
- 如果存在多套服装，将它们作为独立的轮次进行处理，并且只有在用户要求合并最终成品时，才在组装阶段进行合并。
