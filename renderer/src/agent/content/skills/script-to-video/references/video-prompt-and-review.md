# 单镜视频提示词与生成核验

编写视频 Prompt Draft、连接参考输入或复核已生成镜头时读取本文件。画面和动作写法按 `short-drama-video-prompt` 的相关 references，H3 格式按 `short-drama-video-prompt/references/h3-routing.md`，其他模型按当前目录能力与已确认协议；这里约束镜头事实、表演与参考使用，不固定某个厂商的占位符或输入数量。

## 单镜 Prompt Contract

每个 `shot_id` 先在内部形成一份可核对的 Prompt Contract，再写入视频节点。至少包含：

- `shot_id`：只对应一个连续镜头；真实切镜、换场或时间跳跃必须拆成新的镜头和新的视频节点。
- `input_mode`：来自 `inspect_model_catalog` 的真实视频模式、参考图容量、声音能力和时长档位。
- `references`：按真实输入边顺序记录 `{nodeId, type, purpose, order}`。`purpose` 至少区分角色、场景、道具、时间板和镜头板。
- `prompt`：只写本镜必须稳定的身份、空间、动作链、对白、摄影机和镜尾状态；它必须能脱离节点标题独立执行。
- `duration`：按台词、停顿、动作先后和模型实际档位估算，不能整批复制默认 5 秒。
- `continuity`：`start_state`、`end_state`、出入画边、屏幕方向、持物和轴线。
- `errors`：缺参考、容量不足、时长不适配或协议不明时记录具体问题；`errors` 非空只能配置待修镜头，不能声称已通过。

进入视频制作的镜头按风险选择视觉输入；默认使用角色图、场景图和单镜关键画面，不强制生成多格板。只有动作或构图存在独立风险时才创建图片板：

1. **时间板（time board）**：同一连续镜头的起势、路径、接触、反应和收束，按格序表达动作随时间如何变化。
2. **镜头板（shot board）**：同一镜头的观众信息优先级、主体关系、视线、景别、前后景、空间锚点和构图理由。

两张板如果同时需要，必须是两个真实 imageGeneration 节点、两个独立提示词和两个独立 `referenceImage` 输入；不能用一张图、一个多格节点或文字摘要冒充另一张。两板都是普通参考图，不能接 `firstFrame`/`lastFrame`。如果模型容量只允许传入其中一张，保留高风险板的真实输入，并把另一张的已确认事实完整编译进 prompt，同时在 `errors` 中说明降级。未明确指定格数时，不自动生成 3×3。

视频 Prompt 只能编译**当前一个镜头**。不要把多个 `shot_id`、多个地点或多次切机位塞进一条“剧情总提示词”；需要多个镜头就创建多个视频节点，并用 `continuity` 连接镜尾和镜首。

## 从真实参考写到可执行表演

先逐项核对实际连接的角色、场景、道具、时间板和镜头板节点及其真实输出，把每项输入的职责写进工作项与视频提示词。角色参考锁可见身份、妆发、服装及允许的状态变化；场景参考锁建筑、入口、地标和光向；时间板只说明动作的时间顺序、走位与视线变化；镜头板只说明观众应先看到什么、主体关系和构图重点。没有真实连接的输入不得写成“模型已参考”，输入容量不足时保留与本镜风险最相关的独立资产，并把不能传入的可见约束写进提示词；关键身份或空间无法保持时如实报告限制。

逐镜从已确定的进入状态写到离开状态。对每个可见人物交代本镜主要动作、注意对象、触发反应的台词或事件，以及暂不参与时在做什么。多人不因同一句“众人反应”同时转头、起步或重复手势；按剧情先后分配视线与反应延迟。身体运动写可见的支撑、重心转移、接触点、作用对象、加减速与完成结果；头发、衣摆和道具只对已存在的运动、风、重力或接触作小幅滞后反应。近景可写眼睑、唇角等低幅变化，中远景以姿态、距离、停顿和走位表达情绪，避免把心理标签或“自然、电影感”当作动作。指令过载、多个独立接触或演员归属不清时拆镜。

口头对白逐字核对说话者与原文；听者也要有可见注意和反应。`os` 不让画内人物对口型，`vo` 不凭空安排说话者入画。按当前模型真实声音能力决定是原生对白、仅指导口型的后配镜头，还是单独声音工作项；没有已生成音频时不声称声音完成。对白、动作、停顿与结束状态共同决定镜头时长，从模型目录的实际档位选择，放不下时拆镜或调整声音交接，不删原词。

有时间板和镜头板作为普通参考时，明确告诉视频模型：时间板的格序只代表同一镜头的动作时间顺序，镜头板只代表构图和叙事重点；成片须是一张铺满画幅的连续画面，不出现宫格、分屏、格线、编号、箭头、故事板纸张、标注、对白气泡或参考图标签。两板都不接 `firstFrame`/`lastFrame`；若该模式确实需要首帧，只连接与镜头零时刻一致的无标注干净画面。画风从成片规格与人物/场景资产取得，不继承故事板纸张或线稿媒介。未经剧情指定的字幕、标题、Logo、UI 和随机可读文字不生成；剧情必需的精确屏幕文字按当前模型能力处理，无法可靠生成则留给后期图形层。

## 生成与复核

启动前读回视频节点的最终 `prompt`、模型模式、时长、真实输入边及各上游任务状态；草案与节点不一致时更新节点。`plan_write`（`executionMode: plan_only`）可以在图片尚未完成时配置下游视频节点，但启动视频生成前必须复核已经产出的参考图，并修正与图像事实冲突的提示词。

若同一批镜头共享新场景、复杂多人站位或高风险动作，且一个共同错误会让后续多镜重做，可先运行其中能暴露该风险的代表镜并检查真实结果，再继续同类镜头；已通过相同参考与模型组合的镜头不为形式重复试产。用户只要求配置画布、节点运行权限关闭或镜头互不依赖时，不把试产变成额外暂停或审批。失败只修复受影响镜头，避免重放已有成功 task。

检查真实视频是否保留人物身份与服装、正确人数和持物、地标与光向、前后镜状态、动作接触及结果、说话者口型与声音策略，并确认没有格线箭头烧录、意外分屏、文字或画风漂移。工具回执只能证明任务状态；需要画面或声音质量结论时查看可访问的实际媒体，无法查看则只报告已生成，不能称为已审片。
