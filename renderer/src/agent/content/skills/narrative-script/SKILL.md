## 故事大纲

使用现有信息提出一个简短的创意大纲，包括标题、一句话故事、主要转折和结尾方向。用户确认后，在约定范围内写出剧本。

## 脚本格式

- 将脚本结构化为`# Script — <project/scope>`、`## Basic information`、`## Synopsis`、`## Characters (identity/goals/relationships)`和`## Scene-by-scene script`。只包含已确认的规格，如片段数量和持续时间。
- 在每个场景中使用`### Scene <number> | <time> | <location> | <characters>`。描述可见的动作和周围环境；给出角色名称和逐字对白。根据需要添加情感和时机注释。

## 脚本写作

根据已确认的大纲，使用以下方法开发详细的剧本。

- 情节：使用四个阶段。开场打破现状，引入主人公的目标和核心问题，并设置线索或陷阱。上升行动将选择转化为新的障碍，并在关键选择或信息变化处设置相关问题和线索。风暴将早期的线索和成本一起带入危机或逆转。最终对抗通过人物行动实现预设，并达到结局。
- 人物弧线：确立主人公的目标和内心冲突。让他们在关键事件中犹豫、选择并承担后果。将结局与通过行动展现的开场进行对比，以展现变化和成长。
- 场景和对白：每个场景都有一个目标、阻力、行动和结果，这些结果会改变信息、关系或风险，并驱动下一个场景。对白表达了人物的意图和关系，而不重复已知的背景，并符合说话者的个性。
