# 时尚的 3D 社交应用卡片

使用这项技能将用户上传的照片转化为社交媒体界面合成：一个类似社交应用的邮框，其中包含一个受照片启发的酷炫 3D 角色虚拟形象。这项技能首先生成一张静止卡片，然后，如果用户想要动作，它会引导后续视频，包含手指交互，如滑动、点击、心形颗粒和角色空闲动作。

核心价值是一种可重复使用的视觉格式：上传的照片→低聚合可收藏小雕像标识→极简主义社交卡片→可选的交互式动画短视频。

## 步骤 1:输入和所需问题

确认用户已提供至少一张人像、自拍、角色照片、服装照片或其他适合角色转换的图像。

如果没有可用的照片，请要求用户上传一张照片后再继续。

始终在生成前询问所需的输出大小/宽高比。建议将**3:4**作为默认值，因为这为界面帧、字符和后续视频交互提供了足够的空间。

建议问题：

- “你想要什么尺寸？对于社交帧 3D 卡，我推荐 3:4。你也可以选择 1:1、3:4、4:5、9:16 或 16:9。”

不要询问字幕。这项技能是视觉优先的；除非用户明确要求，否则字幕将处于关闭状态。

## 第 2 步：分析上传的照片

在生成卡片之前，检查上传的图像作为角色来源。只提取可重复使用的角色证据：

- 主体数量以及哪个人物应该成为主要 3D 角色;
- 发型、面部表情、眼镜、帽子、珠宝或其他身份信号配件;
- 服装轮廓和主要服装结构;
- 用户想要保留的姿势或态度;
- 无论来源是肖像、全身像、宠物、物体吉祥物还是多人合影。

让图像直接传达颜色信息。除非用户用文字说明，否则不要编造颜色描述。

如果出现了多个人，而用户没有指定目标主体，请询问应该变换哪个人。

## 第 3 步：静止卡片生成

在生成之前，锁定参考视频的优先级：

- 脸部应该兼具可爱和酷炫：大头，圆脸，略长的窄眼睛，上挑的外眼角，以及冷静自持的表情;
- 这套服装应该给人一种酷炫的手工制作玩具的感觉：头饰或发型轮廓分明，配饰粗犷，领口结构厚实，外衣形状坚硬;
- 构图应保持接近参考视频逻辑：正面、中心、胸部特写为主，在肖像社交框架内设置方形媒体区域;
- 媒体区域的背景应该保持最小化和干净，而不是装饰性的，这样人物看起来就像一个高端的 3D 雕塑展示;
- 卡片应该默认设置为已经点赞的状态，这样在任何互动视频之前，社交外壳都能感受到活力。


生成一个最终静止图像，除非用户明确要求多个变体。

静止卡片应包括：

1. **类似社交应用的界面 shell**
   - 明信片布局，包括顶部个人资料行、用户名/位置占位符、媒体窗口、点赞/评论/分享图标、说明区域和转盘指示器（如果有用）;
   - 界面元素应该给人一种社交应用原型的感觉，而不是一个精心设计的虚构社交卡界面;
   - 使用中性占位符显示个人资料、位置、标题和反应细节。

2. **酷炫的 3D 角色虚拟形象**
   - 将上传的主题变成一个卡通酷炫的高端 3D 小雕像/设计师玩具/收藏版角色虚拟形象，拥有更强的手绘玩具能量和略带叛逆的酷炫态度;
   - 保留照片中主角的主要身份和着装线索;
   - 强调坚实的造型、超大的富有表现力的眼睛、有趣的头身比例和时尚配饰细节;
   - 包括微妙的闲暇准备姿势：轻微的头部倾斜，手臂放松，富有表现力的面部表情。

3. **参考视频酷炫规则**
   - 将化身塑造得超越简单可爱的肖像：使用更锐利的风格化面部轮廓，超大且富有表现力的眼睛，自信的眉毛，玩具般的头部体积，以及更时尚前卫的态度;
   - 如果源照片没有任何流行配件，可以添加一些看似合理的流行配件，例如耳机、眼镜、帽子、贴纸、补丁、别针或小型可穿戴技术，除非用户要求完全简洁。
   - 媒体窗口背景应该保持最小化和整洁，就像工作室产品拍摄背景一样；冷静应该来自 3D 雕塑的脸部、配件、材料和态度，而不是来自繁忙的背景;
   - 默认情况下，喜欢的图标应该已经处于喜欢的状态，角色周围应该有微妙的心跳/反应暗示，因为参考卡上显示已经参与。

4. **卡片构成**
   - 角色应作为主角主体坐在媒体区域内;
   - 在角色周围留出足够的视觉空间，以便可能的后续手指互动和漂浮的心脏颗粒;
   - 保持用户界面在选择的宽高比下可读性和平衡性;
   - 如果用户未指定尺寸，默认为 3:4 的垂直卡片呈现，其中社交帖子填充框架，如参考视频所示。

推荐的静止图像提示结构：

```text
Transform the uploaded photo subject into a trendy 3D collectible chibi character inside an social-app-like social post card. Preserve the subject identity, main facial/accessory cues, and outfit silhouette from the uploaded photo. Build a clean social media interface frame with profile row, media window, reaction icons, caption area, and carousel-like details. The character is the hero inside the media window, posed like a premium designer toy with expressive oversized eyes, solid 3D modeling, fashion details, and enough surrounding space for future tap / swipe interaction. Chosen aspect ratio: <confirmed ratio; default 3:4 when unspecified>.
```

根据上传的照片和用户期望的尺寸调整提示词。保持提示词为阳性。除非用户报告特定故障，否则不要过度限制阴性清理文本。

## 低多边形默认规则

当用户提到低聚合 3D 模型、玩具小雕像，或者说生成的卡片不够近时，默认应用以下规则：

- 面部比例：避免使用逼真的椭圆形肖像比例。使用双头 Chibi/低多边形小雕像比例，大头、短圆脸、宽额头、低面部特征位置、丰满脸颊和短圆下巴。
- 眼睛：避免逼真的人类眼睛。使用大型玩具眼睛，形状为扁平的半椭圆形或柔和的扇形，上眼睑略微下垂，外眼角向上，硬边眼线，大瞳孔，可见的玩具眼高光，以及可选的点状下睫毛。这种表情应该让人感到冷静、慵懒或自制，而不仅仅是可爱。
- 配件：配件必须被视为具有厚度、接触阴影和模型边缘的实体玩具零件。耳机、帽子、耳环、贴片、绷带贴纸、别针或可穿戴科技元件应看起来像附加的 3D 组件，而不是打印装饰品。除非用户明确要求，或者源照片已经包含眼镜，否则不要添加眼镜。
- 服装造型：减少逼真的布料褶皱。使用简化的低聚/软乙烯基服装款式，配有加厚的下摆、粗大的领子、斜角袖、分层领口、硬质外套面板，并清除接缝处的环境遮挡物。
- 材料：优先考虑柔性乙烯基/哑光塑料/半抛光可收藏雕塑材料，圆润的低聚合边缘，宽阔的柔和高光，以及柔和的接触阴影。避免平面 2D 虚拟形象滤镜。
- 背景：保持背景极简，但不要默认为灰白色。使用干净的非灰色纯色或柔和渐变的工作室背景，在小雕像下方留下轻微的接触阴影。背景应该能够支持玩具展示的感觉，而不会变成装饰性的杂乱。
- 社交框架：除非用户另有要求，否则默认情况下要保持这张类似社交应用的卡片已被点赞。

- 卡片边缘：在社交邮件框架周围保持可见的左右呼吸空间。框架不应接触或几乎接触画布边缘；保持干净的边缘，使用户界面感觉优雅而有意图。
- 眼妆平衡：眼睛可能比源照片更加程式化，有更强的眼线、眼睑阴影、玩具眼高光和小型图形化的下睫毛标记，但它们仍然必须保持源人平静的目光、眉形印象和可辨识的面部特征。不要用普通的娃娃脸来替代身份。


## 视频方向菜单

在接受静止卡片后，在生成视频之前提供一个简短的交互方向菜单。保持摄像机固定，并在整个运动过程中保持外部卡片帧。不要让边框消失。背景可以保持最小，但它可以获得简单的表现力叠加，如表情符号般的面孔、浮动的形状、反应符号或图形爆发，当它们支持所选择的交互时。

推荐选项：

1. 脸部戳刺反应——用手/手指戳或轻拍角色的脸，角色会做出眨眼、倾斜、撅嘴、脸红或惊讶的表情。
2. **社交框架舞蹈**——角色在框架内跳舞或弹跳，同时卡片保持固定，外部边界保持可见。
3. **握手/伸手**——用户的手伸进去，角色伸回来，场景创造出一种突破框架的感觉，同时保持卡片边缘的存在。
4. 滑动/交互式反应——手指滑动或点击，角色或用户界面会以有趣的反馈做出反应。
5. 自定义互动——用户描述他们想要的任何其他互动。

当询问用户时，请保持问题简洁，并清晰地展示选项。如果用户选择自定义，请只要求简短的描述。

## 第 4 步：审核和可选视频分支

生成静止卡后，告诉用户他们可以继续进入交互式视频。

只询问他们是否表现出兴趣，或者是否已经请求了视频：

- 你想让我把这个变成一个像参考素材那样的互动视频吗？用手指划过卡片，轻点，像浮动的心脏，3D 角色的反应，或者用户从菜单中选择的任何互动？

如果用户说不，请在静止卡片后停止。

如果用户同意，请确认持续时间和平台比例（如果尚未锁定）。建议对单次交互使用 5-8 秒的短片段，或对滑动 + 点赞 + 角色反应使用 10-15 秒的短片段。

## 第 5 步：交互视频生成

使用已接受的静止卡作为主要视觉锚。保留其角色特征和界面布局。

视频应遵循参考交互模式：

1. **开机保持**
   - 社交明信片上的正面固定摄像头;
   - 角色表现出非常细微的无意义动作：微小的头部动作，眨眼，像呼吸一样的微小动作。

2. **手指动作**
   - 一个逼真的前景手指进入画面;
   - 手指在媒体区域进行水平滑动或点击类似图标;
   - UI 对手势做出响应。

3. **界面反馈**
   - 滑动：内部媒体窗口水平滑动，带有弹性缓冲;
   - 像点击一样：类似的图标会带着小的弹跳弹出;
   - 心脏或反应粒子在角色周围向上漂浮，然后消失。

4. **角色反应**
   - 3D 角色会眨眼、倾斜、挥手、微笑，或者以一种可爱又顽皮的方式做出反应;
   - 保持足够小的动作，使卡片布局保持稳定。

5. **结束暂停**
   - 卡片被固定在一个干净的英雄框架中，适合循环播放或发布。

推荐的视频提示结构：

```text
Animate the accepted social-frame 3D character card into a short interactive social UI video. Keep the same character identity, same card layout, and same front-facing composition. A realistic finger enters in the foreground, interacts with the card by <swipe or tap>, and the interface responds with elastic motion. The 3D chibi character performs subtle idle animation, blink, head bob, and a cute reaction. Add floating heart particles after the like tap when requested. Keep the motion beat-synced, playful, fixed-camera, frame-safe, and loop-friendly. The outer social card border should remain visible unless the user explicitly asks for a border-break effect.
```

## 第 6 步：失败处理

如果生成的照片仍然需要更强的主体保存效果：

- 强化照片中的身份线索：脸型印象、发型轮廓、配饰、服装结构和姿势;
- 保留源图像作为主动角色参考;
- 不要通过添加不相关的风格词来解决身份失败的问题。

如果界面变得杂乱无章：

- 简化 UI shell 以配置行、媒体窗口、反应图标、字幕行和旋转点;
- 减少装饰性文本，避免使用无法阅读的小标签。

如果视频手指交互污染了角色或遮挡了面部：

- 指定手指保持在前景边缘区域，永远不要覆盖角色的脸；保留卡片边缘，即使在交互过程中也要保持帧清晰可读;
- 每个片段使用一个清晰的互动，而不是使用太多手势。

如果用户想要多个角色：

- 询问他们是想要一张合并的群组卡还是每个人单独使用的卡;
- 对于单独的卡片，为每个主题生成一个 silent，并保持文件名不同。

## 第 7 步：交付

对于只有静止图像的请求，提交生成的卡片资源，并提及可以使用视频续集。

对于视频请求，提交最终的视频资源。如果静止卡和视频都是同时生成的，请在画布上用简洁的标签将它们分组，例如 “潮流 3D 卡片”。
