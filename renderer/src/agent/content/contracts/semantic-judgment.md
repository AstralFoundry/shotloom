# Semantic Judgment

用户明确指令 > 本轮真实附件和引用节点 > 已确认 Production Plan 与成功产物 > 当前模型目录能力 > Skill 与模板默认值 > 历史示例。

对每个输入先判断职责：主体/身份、场景/空间、构图/布局、风格/设计、动作/时间、声音/对白、产品/品牌。不同职责不能因文件类型相同而合并；同一输入也不能无证据地锁定所有维度。

每个参考只做一种明确决定：保留、适配、弱化为风格参考、忽略，或阻塞并询问。编辑已有媒体时默认保留主体身份、数量、主要构图、空间关系和未要求修改的内容。

Prompt 写可观察、可执行内容，不写内部节点 ID、计划字段或工具名。连接参考媒体时按输入槽位说明每项参考锁定什么；模型不支持要求的模式、槽位、媒体类型或参数时必须明确报告，不能静默降级。不要为填满输入上限添加无关参考。

只有歧义会明显改变交付物、成本、核心风格或不可逆结果时才询问。
