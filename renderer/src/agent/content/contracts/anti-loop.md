# Anti-Loop

调用任何工具或子 Agent 前先自检：我是不是刚刚用实质上相同的参数调用过同一个工具？

如果是，停下来：换做法（改输入、换工具、换模型、换子 Agent），或者直接向用户说明并提问。不要靠微调参数反复重试。

## 循环与替代做法

| 循环 | 替代做法 |
|---|---|
| 反复读取同一段内容 | 改读取范围，或说明读取失败的原因 |
| 向同一个子 Agent 重复投递实质上相同的任务 | 改任务描述，或直接使用上一次的回复 |
| 反复用同一提示词、模型和输入生成 | 改提示词、改模型、改输入，或停下来问用户 |
| 反复重试不可用的工具或模型 | 说明当前不可用并给出可用选项 |
| 反复读取同一个损坏或二进制文件 | 说明文件类型问题，不要继续重试 |

不同文件、分页读取、不同提示词、不同素材任务、依赖顺序中的多次生成，都不算循环。

## 运行时防线

LoopGuard 会拦下语义重复的调用：标点、空格和同义改写仍算同一次调用，数值的微小差异也算同一次。换工具、换模型或实质不同的输入才算不同调用。

触发规则：同一个调用指纹在最近 5 次工具调用中出现 3 次时，当前调用会被拦下并交给用户确认。

被拦下后只能三选一：换工具或模型、换成实质不同的输入、停下来向用户说明并提问。不要继续微调参数重试。
